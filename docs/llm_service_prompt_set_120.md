# LLM 서비스 시나리오별 프롬프트 세트

대학생, 대학원생, 직장인을 대상으로 Chat, Document, Slide, Image Generation 기능을 평가하기 위한 총 120개의 프롬프트 세트이다. 각 프롬프트는 단순한 표현 변형보다 서로 다른 과업과 능력을 평가할 수 있도록 구성했다.

| 사용자 | Chat | Document | Slide | Image Generation |
|---|---:|---:|---:|---:|
| 대학생 | C-U01~10 | D-U01~10 | S-U01~10 | I-U01~10 |
| 대학원생 | C-G01~10 | D-G01~10 | S-G01~10 | I-G01~10 |
| 직장인 | C-W01~10 | D-W01~10 | S-W01~10 | I-W01~10 |

| C-G09 | Reviewer 대응 | Reviewer가 “baseline이 충분하지 않다”고 지적했다. 어떤 추가 실험과 설명이 필요한지 제안해줘. |

## 5. 대학원생 × Document: 논문·연구문서

| ID | 시나리오 | 프롬프트 |
|---|---|---|
| D-G01 | Abstract | 다음 연구 내용을 바탕으로 컴퓨터 시스템 분야 논문의 abstract를 200단어 이내로 작성해줘. |
| D-G02 | Introduction | 다음 문제 정의와 연구 기여를 바탕으로 논문의 Introduction 초안을 작성해줘. |
| D-G03 | Related Work | 제공한 논문들을 기반으로 Kubernetes runtime security 관련 Related Work를 주제별로 분류해서 작성해줘. |
| D-G04 | Methodology | 다음 시스템 아키텍처를 논문의 System Design 섹션에 적합한 학술적 문체로 설명해줘. |
| D-G05 | Evaluation | 다음 실험 환경과 측정 결과를 기반으로 Evaluation 섹션을 작성해줘. 결과를 과장하지 말고 데이터가 뒷받침하는 범위에서 해석해줘. |
| D-G06 | 논문 교정 | 다음 논문 문단을 의미와 기술적 내용을 유지하면서 자연스럽고 간결한 academic English로 교정해줘. |
| D-G07 | 논리 개선 | 다음 Introduction의 논리적 흐름을 분석하고 Problem → Gap → Approach → Contribution 구조가 명확해지도록 다시 작성해줘. |
| D-G08 | 리뷰 작성 | 첨부한 논문을 학술 논문 reviewer 입장에서 평가하고 Summary, Strengths, Weaknesses, Questions 구조의 리뷰를 작성해줘. |
| D-G09 | Rebuttal | 다음 reviewer comment와 실험 결과를 바탕으로 정중하고 설득력 있는 rebuttal을 작성해줘. reviewer의 지적에 직접 답변하도록 해줘. |
| D-G10 | 연구계획서 | LLM을 활용한 Kubernetes 보안 정책 자동 생성이라는 주제로 연구계획서를 작성해줘. 연구 배경, 문제 정의, 연구 목표, 방법론, 평가 계획, 기대효과를 포함해줘. |

## 활용 방법

- 총 프롬프트 수: 120개
- 사용자군: 대학생, 대학원생, 직장인
- 기능 유형: Chat, Document, Slide, Image Generation
- 권장 공통 평가 항목: 과업 충족도, 사실 정확성, 구조와 논리, 표현 품질, 지시 준수, 입력 자료 충실도
- 이미지 생성 평가 항목: 프롬프트 정합성, 구도, 시각적 완성도, 텍스트·여백 처리, 스타일 일관성, 다이어그램 정확성, 원본 보존성

실제 벤치마크에서는 각 프롬프트에 입력 자료, 기대 출력 조건, 채점 기준, 기준 답안을 결합해 평가 데이터셋으로 확장할 수 있다.
