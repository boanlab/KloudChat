# 영어회화 · OPIc 지침 보완 검증

## 범위

- 기준 main: `db0d4f6aa7567b1404fa7cca2e940ca2079f8a13`.
- 실제 검증한 지침: `9f290bc0b32d48df13d09d00004dca60fa383805`.
- 기존 영어회화의 매 턴 질문·교정 의무와 OPIc의 매 답변 등급 기준 피드백을 기본 연습 방식으로 한정함. 질문만·교정만 요청과 출력 언어·길이 제한을 우선하도록 명시함.
- 문장 교정에서 학습자의 사실을 보존하고, 짧은 텍스트의 실제 등급·발음 판정과 근거 없는 공식 기준 설명을 제한함.
- 모델·도구·Skill·권한·라우팅 설정은 변경하지 않음. 지침 조립 회귀 테스트는 모델 답변 정확도를 보장하지 않음.

## 코드 검증

- 새 지침 계약 테스트는 기존 코드에서 실패함을 확인한 뒤 추가함.
- 전체 API: 2,324 통과 / 1 건너뜀 / 기존 경고 11개. Ruff 통과함.
- 카탈로그 갱신 시 기존 프롬프트가 그대로인 설치본은 갱신하고, 프롬프트를 직접 편집한 설치본은 보존하는 기존 계약을 두 Agent에서 검증함.
- 안내문만 편집한 설치본의 보존까지 보장하는 변경은 아님. 카탈로그 갱신은 기존 관리자 로그인·갱신 경로를 따름.

## 실제 응답 비교

- `local/qwen3.6-35b` 모델과 합성 개인 Agent를 사용함. 도구·Skill·웹 검색은 비활성화함.
- 실제 서버의 공용 카탈로그를 교체하지 않고 기준·후보 소스의 지침을 임시 Agent에 정확히 복사해 비교함.
- 첫 비교는 6과제 × 기존/1차 후보 × 2턴 = 앱 요청 24회, 최종 후보는 같은 6과제 × 2턴 = 12회임. 앱 요청 수를 내부 completion/hop 수로 해석하지 않음.
- 앱 credit delta는 두 실행 모두 0임. 카탈로그 경계는 hybrid이므로 물리적 로컬 실행이나 제공자의 무료 청구를 증명하지 않음.

| 버전 | 목표 2턴 통과 | 두 턴 모두 통과 |
| --- | --- | --- |
| 기존 | 1/6 | 0/6 |
| 1차 후보 | 5/6 | 3/6 |
| 최종 후보 | 4/6 | 3/6 |

- 같은 모델의 각 1회 순차 실행이므로 일반 정답률·통계적 유의성·최종 후보의 1차 후보 대비 우월성을 주장하지 않음.
- 최종 후보에서 질문 중복·교정만 요청에 추가 질문·음성 없는 실제 등급 판정은 관측되지 않았음. 모든 요청 제약 준수나 허위 내용 방지의 완료를 뜻하지 않음.
- 최종 잔여 문제는 짧은 질문 요구에 긴 예시 질문(영어 1턴), 도서관 특성을 방문 이유로 바꾼 because 추가(OPIc 2턴), 판단 한계 설명에 근거 없는 시험 평가요소 단정(OPIc 2턴)임.
- 시험 기준은 제공된 자료에서 근거가 없다는 판정이며 외부 자료로 거짓을 입증한 것은 아님.
- 첫 최종 후보 실행은 임시 Agent slug 중복으로 생성 전 차단되어 앱 요청 0회임. 고유 slug로 다시 실행한 12회 결과만 위 표에 포함함.

## 실제 화면

- 1440×900 및 390×844에서 실제 저장 답변·새로고침 유지 12개, 안내문 표시 4개를 확인함.
- 화면 검사 중 생성 요청·외부 요청·페이지 오류·대화 가로 넘침은 0임. 이 결과를 내용 정답률에 합산하지 않음.
- 첨부 화면은 임시 합성 Agent의 실제 안내와 답변임. 사용자 데이터나 모델 gateway 설정은 포함하지 않음.
- 최종 판정은 **지침 충돌 완화 및 제한 요청 보완 / 모델 응답 품질 문제 잔존**임.
