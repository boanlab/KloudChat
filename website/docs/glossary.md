# 용어

| 용어 | 뜻 |
|---|---|
| 화면(챗·보고서·슬라이드·이미지·오디오/동영상) | 홈에서 선택하는 화면. 관리자가 켜고 끔 |
| 대화 | 한 작업의 기록. 사이드바의 한 줄 |
| 아티팩트 | 대화에서 만들어진 문서·슬라이드·차트 등. 오른쪽 패널과 갤러리 |
| 템플릿 | 아티팩트의 구조(구성 규칙·조판·점검 항목). 이 대화 내내 유지 |
| 테마 | 아티팩트의 모양(색·서체·문체). 에이전트·프로젝트에 붙이고 설정 › 테마에서 관리 |
| 프로젝트 | 자료·지침·대화를 묶는 작업 공간 |
| 에이전트 | 지시·진행 과정·도구·자료가 정해진 도우미. 입력창의 **+** → **에이전트**로 시작 |
| 진행 과정 | 에이전트가 일하는 순서. 바로 답하기 · 기본 과정에서 시작 · 직접 구성(고급) |
| 기본 과정 | 기본 에이전트(개조식 보고, 회의록 등)의 일하는 순서. 이미 그 과정에서 시작한 에이전트만 씀 |
| 묶음 | 에이전트가 쓰기 전후에 하는 일을 묶은 것. 에이전트 설정의 「추가로 할 일」에서 체크 |
| 스킬 | 대화에 켜 두는 작업 방식. 입력창에서 최대 3개, 에이전트의 「항상 적용」으로 6개까지, 고르지 않은 스킬은 모델이 필요할 때 꺼내 씀. 템플릿·검사·빠진 정보 질문을 함께 가져옴 |
| 공식 스킬 | 관리자가 모두에게 공개한 스킬. 회의록·개조식 보고 같은 일을 하며, 입력창에서 고르면 내 스킬에 추가됨 |
| 숨김 | 목록·스토어·고르기 창에 보이지 않지만 지우지 않은 기본 스킬·템플릿·테마·커넥터. 묶음과 그 항목을 쓰던 대화에서는 그대로 동작하고, 관리자는 「숨김 포함」으로 봄 |
| 커넥터 | 모델이 쓰는 외부 도구(MCP). 계정 전체에서 켜고 끔 |
| 메모리 | 대화를 넘어 기억하는 사실. 설정 › 메모리 |
| strict-local | 외부로 나가지 않는다고 확인된 모델 표시 |
| Auto | 요청에 따라 모델을 바꾸는 대화 모드(품질 우선·비용 절약) |
| 크레딧 | 사용량 단위. 무료 모델은 쓰지 않음 |
| 작업 단계 | 답변 위의 "작업 완료 · N단계". 참고한 항목을 표시 |
| 턴 | 질문 하나와 그에 대한 답변. 화면에는 "이전 턴 첨부"처럼 표시 |
| 이미지 · 그림 · 도식 | 첨부하거나 생성하는 이미지 파일 · 문서에 넣는 그림(UI 라벨) · 텍스트 모델이 그리는 흐름도와 구조도 |
| 개요 카드 | 보고서·슬라이드를 쓰기 전 구성을 확인하는 카드 |
| 마스킹 | 개인정보를 자리표시자로 바꿔 보내는 것 |
| 챗봇 | 다른 사람이 물어볼 수 있게 공개한 에이전트. 구성원·링크·외부 공개 |
| 문의·신고 | 관리자에게 보내는 오류 신고·기능 요청·문의 |
