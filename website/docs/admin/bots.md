# 공개 챗봇 승인

구성원이 에이전트를 챗봇으로 공개하면 다른 구성원은 바로 씁니다. 로그인하지 않은 사람에게 여는 **링크 공개**와 **외부 공개**는 관리자가 승인해야 열립니다. 계정 메뉴의 **관리** → **공개 챗봇**에서 다룹니다. 승인을 기다리는 요청이 있으면 메뉴에 숫자가 붙습니다.

## 검토하는 것

요청을 열면 승인하면 답하게 될 판의 내용이 보입니다.

- 지시, 담당 부서·연락처, 첫 인사, 쓰는 도구와 검사, 답하는 내부 모델
- 자료 목록과 자료에서 개인정보로 보이는 값의 개수
- 공개한 사람, 하루 최대 크레딧, 지금까지의 기록(요청, 결정, 새 판)

**승인**하면 요청한 범위와 그 판이 함께 열립니다. **반려**에는 사유를 적어야 하고, 사유는 공개한 사람의 관리 화면에 보입니다. 반려해도 챗봇은 그 전 범위로 계속 답합니다.

로그인하지 않은 사람에게 열린 챗봇에 새 판이 올라오면 같은 방식으로 다시 검토합니다. 승인 전까지는 승인된 판이 답합니다.

## 채널 요청

외부 공개·링크 공개 챗봇의 공개한 사람은 **다른 사이트에 넣기**, **API**, **MCP** 채널을 요청할 수 있습니다. 요청은 같은 승인 대기 목록에 「채널 요청」으로 보이고, 검토 화면에 요청한 채널과 넣을 사이트 주소가 나옵니다.

- **승인**하면 요청한 채널이 열립니다. 다른 사이트에 넣기는 승인한 사이트 주소에서만 대화창이 보입니다. 사이트를 더하는 것도 다시 승인을 거칩니다.
- **외부 공개 닫기**는 다른 사이트·API·MCP 채널도 함께 닫습니다. 그 뒤로는 사이트의 대화창, API, MCP 모두 바로 거부됩니다.
- 열린 채널은 검토 화면 오른쪽 **열린 채널**에서 봅니다.

## 대화 열람

검토 화면의 **대화 열람**은 남용 신고를 확인할 때만 씁니다. 사유를 적어야 대화 목록과 내용이 열리고, 개인정보는 가려서 보입니다. 열람한 날과 사유는 감사 기록과 공개한 사람의 관리 화면(**관리자 열람 기록**)에 남습니다. API·MCP 키로 온 대화는 「API·MCP 키」로 표시됩니다.

## 닫기와 중지

| 동작 | 결과 |
|---|---|
| 외부 공개 닫기 | 구성원 공개로 돌립니다. 로그인하지 않은 방문자는 다음 요청부터 챗봇을 열 수 없습니다 |
| 일시 중지 / 다시 열기 | 모든 방문자가 질문할 수 없게 멈추거나 다시 엽니다 |
| 챗봇 닫기 | 공개한 사람 외에는 아무도 열 수 없습니다 |

모든 동작에는 사유를 적고, 감사 기록에 남습니다. 공개 챗봇의 대화를 남용 확인 목적으로 열람할 때도 사유가 필요하며 기록됩니다.

## 운영 참고

- 로그인하지 않은 방문자는 브라우저 쿠키로 구분하고, 접속 주소별 분·하루 한도와 하루 새 방문자·대화 수 한도로 남용을 막습니다. 주소는 서버 앞단 프록시가 보낸 `X-Forwarded-For`로 판단하므로, 웹 컨테이너의 `KCHAT_TRUSTED_PROXIES`를 실제 프록시 주소로 좁혀 두어야 합니다.
- 기관 전체에서 동시에 답하는 공개 챗봇 질문은 상한(기본 16개) 안에서 처리하고, 넘치는 질문은 잠시 기다렸다가 차례가 오지 않으면 「질문이 몰려 있습니다」로 돌려보냅니다.
