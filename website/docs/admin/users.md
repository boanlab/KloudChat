# 사용자와 크레딧

관리 메뉴의 **사용자 · 크레딧** 화면입니다. 상단에 전체 사용자 수, 승인 대기 건수, 이번 달 사용량과 배정량, 다음 리필 일자가 요약되며, 하단에 상태별 탭(전체, 승인 대기, 활성, 정지)과 이름·이메일 검색이 제공됩니다.

## 가입 승인

가입 방식이 **승인 후 사용**이면 새 계정이 승인 대기로 쌓이고 계정 메뉴에 "승인 대기 N건"이 뜹니다. 행의 **승인**을 누르면 기본 플랜 크레딧으로 바로 승인되고, 이때 모델 게이트웨이 사용자와 키가 만들어집니다. 승인하지 않을 계정은 **반려**로 처리합니다. 메일 인증을 완료하지 않은 계정에는 **메일 미확인** 배지가 표시되며, 승인하면 인증을 완료한 것으로 처리합니다. 일괄 선택은 지원하지 않으므로 계정마다 개별 승인해야 합니다.

## 사용자별 관리 항목

| 버튼 | 하는 일 |
|---|---|
| 크레딧 | 월 한도 변경. 게이트웨이 예산에도 여유분만큼 반영 |
| 모델 제한 | 이 계정이 쓸 수 있는 모델. 비우면 전체. API 키에도 적용 |
| 정보 수정 | 이름·이메일, **비밀번호 초기화**(임의 생성, 저장하면 모든 로그인 해제) |
| 키 관리 | 게이트웨이 키 재발급(기존 키 즉시 폐기)·교체, 사용자가 만든 API 키 목록·삭제 |
| 정지 / 정지 해제 | 되돌릴 수 있고 기록이 남음 |
| 삭제 | 대화·프로젝트·결과물·메모리·크레딧 기록·게이트웨이 키 삭제. 업로드한 파일과 생성된 이미지·영상 파일을 디스크에서 삭제할지 선택 |

## 크레딧 정책

승인된 계정의 크레딧은 매월 1일 배정량으로 초기화되며 이월되지 않습니다. 무료 모델만 운영하는 환경에서는 크레딧이 소모되지 않으며, 외부 모델이나 이미지·영상 기능을 활성화한 경우에만 한도가 실질적으로 적용됩니다.

## 계정 정리

검증이나 부하 테스트 목적으로 생성한 계정은 사용 후 삭제하십시오. 삭제하지 않으면 사용량 집계에 함께 반영됩니다.
