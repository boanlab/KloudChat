# 정책과 라우팅

개인정보 보호 수준, 감사 기록, 모델 자동 전환(Auto)을 설정합니다.

## 정책 설정

| 항목 | 뜻 |
|---|---|
| 개인정보 마스킹 | 모든 요청에서 주민번호·카드·전화·이메일을 항상 가리고, 가려진 채 저장. 원문 전송 불가 |
| 외부 모델 개인정보 보호 | 챗·비교에서 외부로 나갈 수 있는 모델에 개인정보가 감지되면 사용자에게 선택을 물음 |
| strict-local 안전 모델 | "안전한 로컬 모델로 전환"이 보낼 모델. 게이트웨이가 strict-local로 선언한 챗 모델만 후보. **비워 두면** 사용자에게 안전 모델이 없다는 안내가 뜸 |
| 원문 외부 전송 허용 | 사용자가 경고를 무시하고 보낼 수 있게 할지. 마스킹 정책이 켜져 있으면 불가 |
| 의도 기반 필터 + 차단할 주제 | 해당 요청을 크레딧 없이 거절하고 감사 로그에 남김 |
| 유휴 자동 로그아웃 | 분 단위. 0이면 끔 |
| 대화 보존 기간 | 일 단위. 지나면 본문 삭제(소급 적용, 지운 건수 표시). 기록·사용량은 남음 |

서버가 정책을 조회하지 못하면 안전을 위해 챗, 모델 비교, 보고서, 슬라이드의 전송을 차단합니다(503).

모든 모델을 기관 서버에서 운영하는 환경에서는 **외부 모델 개인정보 보호**의 실효성이 낮습니다. strict-local로 선언되지 않은 기관 모델은 외부 전송 가능 모델로 취급되어 경고가 표시되므로, 게이트웨이에서 strict-local을 선언해 안전 모델로 지정하거나 보호 기능을 비활성화하십시오.

## 감사 로그

시각·계정·행위·대상·접속 위치. 로그인·실패·승인·정지·권한 변경·설정 변경·키 발급·폐기·비밀번호 재설정·토큰 재사용 감지 등을 계정·행위·IP로 검색합니다. 화면에서 수정·삭제할 수 없습니다.

## Auto 라우팅

- **Auto · 비용 절약** — 켜기, 난이도 분류 모델(무료 strict-local만), 절약 모델 최대 3개(우선순위). 절약 모델은 사용자가 고른 품질 모델보다 출력 단가가 낮고, 데이터 경계가 더 넓지 않으며, 컨텍스트 길이가 충분한 경우에만 적용됩니다. 모든 모델이 무료인 환경에서는 절감 효과가 없어 동작하지 않습니다.
- **Auto · 품질 우선** — 켜기, 상향 모델 최대 3개.
- **구성 단계 모델** — 보고서·슬라이드 개요를 잡는 모델. 비우면 작성 모델과 같음.

화면별 기본 모델은 관리자 설정이 아니라 **각 사용자의 설정 → 환경설정**에 있습니다. 관리자는 사용자별 허용 모델만 제한합니다.
