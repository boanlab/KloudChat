# 정책과 라우팅

개인정보 보호 수준, 감사 기록, 모델 자동 전환(Auto)을 설정합니다.

## 정책 설정

| 항목 | 뜻 |
|---|---|
| 개인정보 마스킹 | 모든 요청에서 주민번호·카드·전화·이메일을 항상 가리고, 가려진 채 저장. 원문 전송 불가 |
| 외부 모델 개인정보 보호 | 챗에서 외부로 나갈 수 있는 모델에 개인정보가 감지되면 사용자에게 선택을 물음 |
| strict-local 안전 모델 | 우선순위 목록. 화살표나 끌어서 순서를 정함. 내부 자료 때문에 strict-local로 옮길 때는 고른 모델의 strict-local 판을 먼저, 없으면 이 목록의 첫 번째 모델을 씀. 개인정보 확인 창의 "안전한 로컬 모델로 전환"은 체크된 모델 중 하나를 사용자가 고르게 함(처음엔 첫 번째). 게이트웨이가 strict-local로 선언한 챗 모델만 후보. **비워 두면** 사용자에게 안전 모델이 없다는 안내가 뜸 |
| 내부 자료는 strict-local로만 | 첨부 파일·프로젝트 파일·메모리가 들어간 요청은 같은 모델의 strict-local 판으로 답하고, 그 대화는 이후 외부 모델로 넘어가지 않음. 쌍이 없으면 안전 모델, 그것도 없으면 전송 거절 |
| 원문 외부 전송 허용 | 사용자가 경고를 무시하고 보낼 수 있게 할지. 마스킹 정책이 켜져 있으면 불가 |
| 의도 기반 필터 + 차단할 주제 | 해당 요청을 크레딧 없이 거절하고 감사 로그에 남김 |
| 유휴 자동 로그아웃 | 분 단위. 0이면 끔 |
| 대화 보존 기간 | 일 단위. 지나면 본문 삭제(소급 적용, 지운 건수 표시). 기록·사용량은 남음 |

서버가 정책을 조회하지 못하면 안전을 위해 챗, 보고서, 슬라이드의 전송을 차단합니다(503).

모든 모델을 기관 서버에서 운영하는 환경에서는 **외부 모델 개인정보 보호**의 실효성이 낮습니다. strict-local로 선언되지 않은 기관 모델은 외부 전송 가능 모델로 취급되어 경고가 표시되므로, 게이트웨이에서 strict-local을 선언해 안전 모델로 지정하거나 보호 기능을 비활성화하십시오.

## 감사 로그

시각·계정·행위·대상·접속 위치. 로그인·실패·승인·정지·권한 변경·설정 변경·키 발급·폐기·비밀번호 재설정·토큰 재사용 감지 등을 계정·행위·IP로 검색합니다. 시각·행위·대상·접속 위치 머리글을 누르면 서버에서 그 순서로 정렬합니다. **CSV 내보내기**는 지금 조건과 정렬로 모든 쪽을 받으며(최대 5만 건), 내보낸 일 자체도 감사 로그에 남습니다. 화면에서 수정·삭제할 수 없습니다.

## Super Agent

- **켜기** — 모델 선택기에 Super Agent 두 항목을 보일지.
- **분류 모델** — 규칙으로 가리지 못한 질문만 짧게 보내는 무료 strict-local 모델.
- **작업 종류별 표** — 작업 종류마다 Super Agent 모델, strict-local 모델, 추론 강도. 「다시 요청·빈 답 뒤」 줄은 다시 해 달라는 요청과 빈 답을 맡습니다. **표를 기본값으로**는 평가로 정한 기본 표로 되돌립니다.
- **「내부 자료 작업」 줄** — 첨부 파일, 프로젝트 지식, 에이전트 파일을 다루는 질문(간단한 질문·보고서·다시 요청 제외)을 이 줄의 모델로 보냅니다. **작업 종류의 모델 그대로**로 둔 열에서는 원래 줄을 따릅니다. 기본값은 strict-local 열만 DeepSeek V4 Flash입니다. strict-local 열에서 Qwen3.8 Flash가 아닌 모델이 실패하거나 4분 동안 아무것도 내지 않으면 같은 답 안에서 Qwen3.8 Flash가 이어 쓰고, 실패한 모델은 잠시(바쁨 1분, 그 밖 5분) 고르지 않습니다.
- **구성 단계 모델** — 보고서·슬라이드 개요를 잡는 모델. 비우면 작성 모델과 같음.

화면별 기본 모델은 관리자 설정이 아니라 **각 사용자의 설정 → 환경설정**에 있습니다. 관리자는 사용자별 허용 모델만 제한합니다.
