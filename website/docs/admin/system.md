# 시스템 설정

관리 메뉴의 **시스템** 화면은 일곱 개 탭으로 구성됩니다.

## 프록시

모델 게이트웨이(LiteLLM) 주소와 마스터 키(암호화 저장, 다시 보이지 않음), **연결 테스트**(모델 n종 확인), **모델 목록 새로고침**, 환경변수 값으로 되돌리기. 가격 정보가 없어 숨긴 모델 목록이 보이면 게이트웨이의 모델 가격 설정을 입력하십시오.

## 라우팅

라우팅 설정은 [정책과 라우팅](policy#auto-라우팅)에서 설명합니다.

## 기능

- **사용할 기능**: 보고서 · 슬라이드 · 이미지 · 오디오/동영상 켜기/끄기. 챗은 항상 켜져 있습니다. 비활성화하면 메뉴에서 사라지고 서버도 새 대화를 거부합니다. 이미지·영상은 게이트웨이에 그 모델이 있어야 실제로 동작합니다. 모델이 없는 상태로 활성화하면 사용자 화면에 생성 불가 안내가 표시됩니다.
- **기능 연동**: 기능 서버 주소 하나, 또는 기능별 주소(웹 검색 · 문서 가져오기 · 코드 실행 · 심층 조사 · 음성 전사 · 자료 검색). 개별·전체 **연결 테스트**. 음성 전사 주소를 설정하면 말로 쓰기와 음성·영상 파일 읽기가 활성화되고, 자료 검색(색인) 주소가 있으면 에이전트 자료와 대화 첨부를 벡터로 검색합니다(없으면 낱말 검색만).

웹 검색의 안전 검색 수준과 차단 도메인은 검색 서버에서 설정합니다. 자세한 내용은 백엔드(KloudChat-LLM) 문서를 참고하십시오. 기본값은 안전 검색이 비활성 상태입니다.

## 공용 템플릿

모든 사용자의 **작업 시작하기** 갤러리에 표시할 **시작점**을 등록, 수정, 삭제합니다. 등록 항목은 화면, 이름, 설명, 분류, 입력 항목, 예시, 필요한 기능, 숨은 지시문, 양식 파일입니다. 결과물의 형식을 정의하는 서식은 제품에 내장되어 있어 이 화면에서 생성하지 않습니다.

## 브랜딩

서비스 이름, 문의 주소(대기 화면의 메일 링크. 비우면 첫 관리자), 로고(PNG·JPG·WebP 2MB 이하, SVG 불가, 기본으로 되돌리기). 서비스 이름을 변경하면 브라우저 탭 아이콘도 해당 이니셜로 바뀝니다.

## 메일

SMTP 호스트·포트·보안·계정·보내는 주소, 서비스 주소(메일 링크용, **현재 주소 넣기**), **테스트 발송**. 설정되면 로그인 화면에 비밀번호 재설정 링크가 생기고 이메일 인증을 켤 수 있습니다.

## 회원 가입

- **가입 방식**: 승인 후 사용 / 바로 사용 / 받지 않음. 환경변수 `SIGNUP_MODE`가 있으면 그쪽이 우선.
- **가입 가능한 이메일 도메인**: 쉼표로 여러 개. 하위 도메인은 따로 적어야 합니다.
- **이메일 인증**: 메일 서버가 없으면 무효.

## 시스템 탭 외의 관리 항목

- **사용량** 화면: 기간별 차트, 모델·화면·사용자별, CSV 내보내기, 저장 공간(디스크 사용량, 고아 파일 정리, 가득 차면 오래된 것부터 자동 정리).
- **디자인**: 관리자는 디자인 시스템을 **모든 사용자에게 제공**(공용, 읽기 전용)할 수 있습니다.
- **스토어**: 관리자 계정이 공개한 에이전트·스킬에는 **공식** 배지가 붙습니다.
- 신뢰할 프록시 범위와 파일 크기 한도 등은 화면이 아닌 환경변수로 설정합니다. 저장소의 `docs/configuration.md` 를 참고하십시오.
