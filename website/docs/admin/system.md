# 시스템 설정

관리 메뉴의 **시스템** 화면은 여덟 개 탭으로 구성됩니다. 저장하면 재시작 없이 바로 적용됩니다.

## 프록시

모델 게이트웨이(LiteLLM) 주소와 마스터 키(암호화 저장, 다시 보이지 않음), **연결 테스트**(모델 n종 확인), **모델 목록 새로고침**, 환경변수 값으로 되돌리기. 가격 정보가 없어 숨긴 모델 목록이 보이면 게이트웨이의 모델 가격 설정을 입력하십시오.

## 모델

사용자가 모델을 고르지 않았을 때 어떤 모델이 어떤 일을 맡을지 정합니다. 서버 설정 파일(`.env`)의 값은 처음 설치할 때 한 번만 쓰이고, 그 뒤에는 여기서 저장한 값이 우선합니다.

- **화면별 기본 모델**: 대화 · 보고서 · 발표 자료 · 그림 · 오디오 · 동영상. 대화와 그림은 반드시 골라야 합니다. 보고서와 발표 자료는 비워 두면 대화 기본 모델을 따르고, 오디오·동영상은 비워 두면 가장 싼 모델을 씁니다. 사용자가 고른 모델이 있으면 그 모델이 우선합니다.
- **보조 작업 모델**: 제목·기억·요약 모델, 코드 작성 모델과 그 대체 모델. 대화 내용을 읽는 작업이라 이 인스턴스가 직접 운영하는(자체 호스팅) 모델만 고를 수 있습니다. strict-local 대화에서는 고른 모델의 strict-local 판이 맡습니다.
- **생각**: 자체 호스팅 모델과 외부 모델이 답하기 전에 추론할지 정합니다. 켜면 판정이 정확해지지만 호출마다 수십 초에서 수 분이 더 걸립니다. 기본은 둘 다 끔.

보고서·슬라이드의 구성과 판정을 맡는 **구성 단계 모델**과 Auto의 **난이도 분류 모델**은 **라우팅** 탭에 있습니다.

### 기본 설치의 자체 호스팅 모델

기본값은 기관이 직접 운영하는 두 모델을 씁니다. 게이트웨이에는 각각 두 이름으로 등록됩니다. `local/`은 기관 서버에서 먼저 처리하지만 장애 때 외부 대체 모델이 답할 수 있어 데이터 경계 밖으로 다루고, `strict-local/`은 밖으로 나가지 않는 판으로 내부 자료를 처리할 수 있는 유일한 경로입니다.

| 모델 | 맡는 일 |
|---|---|
| `qwen3.8-27b` | 보고서·슬라이드 기본 모델, 코드 작성 모델 |
| `qwen3.8-flash` | 대화 기본 모델, 구성 단계 모델(보고서·슬라이드의 구성과 판정), 제목·기억·요약, Auto 난이도 분류와 비용 절약 모델, 글자 읽기 비전 모델, 코드 작성 대체 모델 |

모두 이 탭과 **라우팅**·**기능** 탭에서 다른 모델로 바꿀 수 있습니다.

## 라우팅

라우팅 설정은 [정책과 라우팅](policy#auto-라우팅)에서 설명합니다.

## 기능

- **사용할 기능**: 보고서 · 슬라이드 · 이미지 · 오디오/동영상 켜기/끄기. 챗은 항상 켜져 있습니다. 비활성화하면 메뉴에서 사라지고 서버도 새 대화를 거부합니다. 이미지·영상은 게이트웨이에 그 모델이 있어야 실제로 동작합니다. 모델이 없는 상태로 활성화하면 사용자 화면에 생성 불가 안내가 표시됩니다.
- **기능 연동**: 기능 서버 주소 하나, 또는 기능별 주소(웹 검색 · 문서 가져오기 · 코드 실행 · 심층 조사 · 음성 전사 · 자료 검색 · 글자 읽기(OCR)). 개별·전체 **연결 테스트**. 음성 전사 주소를 설정하면 말로 쓰기와 음성·영상 파일 읽기가 활성화되고, 자료 검색(색인) 주소가 있으면 에이전트 자료와 대화 첨부를 벡터로 검색합니다(없으면 낱말 검색만).
- **글자 읽기(OCR)**: 스캔한 PDF 쪽과 문서 사진의 글자를 읽습니다. 켜기·끄기, 읽는 방식(OCR 엔진 + 비전 모델 · OCR 엔진만 · 비전 모델만), 비전 모델, 문서 하나에서 읽는 최대 쪽 수(기본 300)를 정합니다. 비전 모델은 그림을 읽는 strict-local 모델만 고를 수 있고, 그 밖의 모델은 저장되지 않습니다. 둘 다 쓰면 엔진이 먼저 읽고 점수가 낮은 쪽과 표가 있는 쪽만 비전 모델이 다시 읽으며, 두 결과가 다르면 「확인 필요」로 표시합니다. OCR 엔진 주소가 없으면 PDF 쪽은 읽지 못하고 사진만 비전 모델로 읽습니다. 읽은 쪽 수는 사용량에 「n쪽 글자 읽음」으로 남습니다(크레딧 0).

웹 검색의 안전 검색 수준과 차단 도메인은 검색 서버에서 설정합니다. 자세한 내용은 백엔드(KloudChat-LLM) 문서를 참고하십시오. 기본값은 안전 검색이 비활성 상태입니다.

## 브랜딩

서비스 이름, 문의 주소(대기 화면의 메일 링크. 비우면 첫 관리자), 로고(PNG·JPG·WebP 2MB 이하, SVG 불가, 기본으로 되돌리기). 서비스 이름을 변경하면 브라우저 탭 아이콘도 해당 이니셜로 바뀝니다.

## 메일

SMTP 호스트·포트·보안·계정·보내는 주소, 서비스 주소(메일 링크용, **현재 주소 넣기**), **테스트 발송**. 설정되면 로그인 화면에 비밀번호 재설정 링크가 생기고 이메일 인증을 켤 수 있습니다.

## 회원 가입

- **가입 방식**: 승인 후 사용 / 바로 사용 / 받지 않음. 화면에서 고른 값이 환경변수 `SIGNUP_MODE` 보다 우선합니다.
- **가입 가능한 이메일 도메인**: 쉼표로 여러 개. 하위 도메인은 따로 적어야 합니다.
- **이메일 인증**: 메일 서버가 없으면 무효.
- **새 계정의 월 크레딧**: 가입하거나 승인될 때 주는 월 크레딧. 승인할 때 계정마다 바꿀 수 있습니다.

## 커넥터 카탈로그

사용자가 **사용자 지정** › **커넥터**에서 설치할 수 있는 MCP 서버 목록입니다. **항목 추가**로 이름, 슬러그, 연결 방식(명령 실행 stdio·HTTP·SSE), 명령이나 주소, 환경 변수, 쓸 화면을 적습니다. 기능 연동 주소는 `${TOOLS_STT_URL}` 같은 자리표시로 적습니다. **게이트웨이 키를 넣을 변수**를 고르면 그 변수가 고른 도구의 주소일 때만 `TOOLS_GATEWAY_KEY`가 들어갑니다(YouTube 전사가 이렇게 음성 전사를 부릅니다). 저장한 값은 다시 보이지 않고, 바꿀 때만 새로 적습니다. 명령으로 실행하는 서버는 여기서만 추가할 수 있습니다. **목록에 보이기**를 끄면 사용자 목록에서 빠지지만 설치는 그대로 되고, 이미 설치한 것도 계속 동작합니다(관리자 목록에는 「숨김」으로 표시). **사용**을 끄면 새로 설치할 수 없습니다. **기본 제공**을 켜면 활성 사용자 모두에게 바로 설치되고, 이후 가입하거나 승인되는 사용자에게도 설치됩니다(관리자 목록에는 「기본 제공」으로 표시). 사용자는 기본 제공 커넥터를 끌 수는 있지만 지울 수는 없습니다. 사람마다 자격증명을 받아야 하는 항목은 기본 제공할 수 없습니다. 시간, YouTube 전사, 심층 리서치가 기본 제공 항목입니다.

## 시스템 탭 외의 관리 항목

- **사용량** 화면: 기간별 차트, 모델·화면·사용자별, CSV 내보내기, 저장 공간(디스크 사용량, 고아 파일 정리, 가득 차면 오래된 것부터 자동 정리).
- **테마**: 관리자는 테마를 **모든 사용자에게 제공**(공용, 읽기 전용)할 수 있습니다.
- **스토어**: 관리자 계정이 공개한 에이전트에는 **공식** 배지가 붙고, 스킬은 공개한 사람의 이름이 붙습니다. 기본 스킬은 처음 관리자 계정의 스킬로, 모두에게 공개된 채 시작합니다. 관리자는 **사용자 지정** › **스킬**에서 다른 스킬처럼 고치거나 공개를 끌 수 있고, 고친 스킬은 새 버전으로 덮어쓰지 않습니다(고치지 않은 스킬과 사용자의 고치지 않은 사본은 새 버전을 따라갑니다). 목록에서 숨긴 기본 스킬(부품으로만 남긴 것)은 관리자에게 **숨김 포함**을 켰을 때만 보입니다.
- **성능 모니터링** 화면: 모델별 첫 토큰·전체 응답 지연과 오류율, 진행 중 턴, API 복제본·호스트·GPU 지표를 보고 기준을 넘은 항목을 주의·과부하로 표시합니다. 기준값은 API 환경변수 `PERF_*`로 바꿉니다.
- 신뢰할 프록시 범위와 파일 크기 한도처럼 배포에 딸린 값은 화면이 아닌 환경변수로 설정합니다. 어떤 값이 어디에 속하는지는 저장소의 `docs/configuration.md` 의 「배포 설정과 제품 설정」을 참고하십시오.
