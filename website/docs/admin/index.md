# 관리자 가이드

관리자 계정으로 로그인하면 계정 메뉴에 **관리** 항목이 생깁니다. 최초로 가입한 계정이 관리자 권한을 갖습니다.

| 화면 | 하는 일 |
|---|---|
| 사용자 · 크레딧 | 가입 승인·반려, 정지, 정보 수정, 월 크레딧, 허용 모델, 키 관리 |
| 사용량 | 기간별·모델별·사용자별 사용량, CSV, 저장 공간 |
| 보안 · 감사 | **정책** 탭(개인정보 보호, 안전 모델, 차단 주제, 유휴 로그아웃, 보존 기간)과 **감사 로그** 탭 |
| 시스템 | **프록시 · 라우팅 · 기능 · 공용 템플릿 · 브랜딩 · 메일 · 회원 가입** 탭 |

## 초기 설정 순서

1. **시스템 → 프록시**: 모델 게이트웨이 주소와 마스터 키를 입력하고 연결을 확인합니다. 이 설정이 없으면 사용할 모델이 표시되지 않습니다.
2. **시스템 → 기능**: 사용할 기능을 활성화하고 기능 연동 주소(웹 검색, 문서 가져오기, 코드 실행, 심층 조사, 음성 전사, 자료 검색)의 연결을 확인합니다.
3. **시스템 → 회원 가입**: 가입 방식과 허용 이메일 도메인을 설정하고, 메일 서버가 있으면 이메일 인증을 활성화합니다.
4. **시스템 → 메일**: 비밀번호 재설정과 인증 메일이 필요한 경우 SMTP를 설정합니다.
5. **시스템 → 브랜딩**: 서비스 이름, 로고, 문의 주소를 설정합니다.
6. **보안 · 감사 → 정책**: strict-local 안전 모델을 지정하고 개인정보 보호 방식을 결정합니다.
7. **시스템 → 라우팅**: Auto 모드 사용 여부를 결정합니다.
8. **사용자 · 크레딧**: 승인 대기 계정을 처리합니다.

각 항목의 상세 내용은 [사용자와 크레딧](users.md), [정책과 라우팅](policy.md), [시스템 설정](system.md)을 참고하십시오.
