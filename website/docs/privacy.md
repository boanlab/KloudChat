# 개인정보 보호

입력한 내용과 첨부 파일이 어디에 저장되고 어디까지 전송되는지, 개인정보가 감지되면 어떻게 처리되는지 설명합니다.

## 데이터 저장과 전송

| 데이터 | 저장 위치 | 외부 전송 | 삭제 시점 | 관리자 열람 |
|---|---|---|---|---|
| 대화와 답변 | 기관 서버 | 모델의 데이터 경계에 따릅니다. **외부 제공**과 **외부 전환 가능**은 해당 서비스로 전송되며 **strict-local**은 전송되지 않습니다. | 사용자가 삭제하거나 관리자가 설정한 보존 기간이 지났을 때 | 대화 내용을 조회하는 화면은 제공하지 않습니다. |
| 첨부 파일과 프로젝트 지식 | 기관 서버 | 대화와 동일합니다. | 파일, 대화, 프로젝트를 삭제할 때 | 저장 용량만 확인할 수 있습니다. |
| 메모리 | 기관 서버 | 요청과 함께 모델로 전송됩니다. | 사용자가 삭제할 때 | 열람할 수 없습니다. |
| 웹 검색어 | 저장하지 않습니다. | 검색 모드가 켬 또는 자동일 때 검색 엔진으로 전송됩니다. | 해당 없음 | 열람할 수 없습니다. |
| 이미지·영상 요청문 | 기관 서버 | 선택한 모델의 데이터 경계에 따르며 대부분 외부 서비스로 전송됩니다. | 결과물을 삭제할 때 | 열람할 수 없습니다. |
| 사용량과 접속 기록 | 기관 서버 | 전송되지 않습니다. | 관리자가 설정한 정책에 따릅니다. | 열람 가능합니다. 토큰, 크레딧, 로그인, 정책 적용 내역이 포함되며 탐지된 개인정보의 값은 기록되지 않고 종류와 건수만 남습니다. |

모델마다 다른 **데이터 경계**는 모델 목록에 표시됩니다. [모델 선택](chat/models)

## 개인정보 감지

전화번호, 주민 식별번호, 결제 카드번호, IP 주소, 개인키, 이메일 주소를 탐지합니다. 이름과 주소는 탐지 대상에서 제외합니다.

### 챗과 모델 비교

관리자가 **외부 모델 개인정보 보호**를 활성화했고 선택한 모델이 외부로 전송될 수 있는 경우, 전송 전에 **"개인정보가 포함된 요청입니다"** 창이 표시됩니다. 탐지된 종류와 건수를 안내하며 값 자체는 표시하지 않습니다.

| 선택 | 뜻 |
|---|---|
| 안전한 로컬 모델로 전환 | 관리자가 지정한 strict-local 모델로 이번 요청을 전송합니다. |
| 가린 뒤 기존 모델 사용 | 개인정보를 자리표시자로 바꾸어 전송합니다. |
| 원문을 외부 모델로 전송 | 원문을 그대로 전송합니다. 관리자가 허용한 경우에만 표시됩니다. |
| 편집으로 돌아가기 | 전송하지 않고 입력창으로 돌아갑니다. |

매번 선택하지 않으려면 설정 → 환경설정의 **개인정보 감지 기본 처리**에서 기본 동작을 지정하십시오.

### 보고서·슬라이드·이미지·API

보고서와 슬라이드 작성, 이미지 생성, API 호출에서는 확인 절차 없이 탐지된 개인정보를 마스킹해 전송합니다.

### 상시 마스킹 설정 시

모든 요청에서 개인정보를 마스킹하며 **대화 기록도 마스킹된 상태로 저장**됩니다. 이후 다시 열람해도 자리표시자만 표시되고 원문 전송은 허용되지 않습니다. 답변 하단에 "기록에는 가려진 채 저장됩니다"가 표시됩니다.

## strict-local 모델

외부로 전송되지 않는 것이 확인된 모델입니다. 선택하면 웹 검색, 페이지 읽기, 커넥터가 비활성화됩니다. 모델 비교에서 선택하면 비교가 취소되고 해당 모델 하나로 답변합니다. 이름이 `local` 로 시작한다고 해서 strict-local인 것은 아니므로 목록의 표시를 확인하십시오.

## 공유 링크

공유한 대화는 설정한 범위에 따라 로그인한 사용자 전체 또는 링크를 아는 모든 사람이 열람할 수 있습니다. [공유](write/share)
