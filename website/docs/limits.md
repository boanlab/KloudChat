# 제한 사항과 문제 해결

서비스가 허용하는 한도와 화면에 표시되는 오류 문구별 대처 방법을 설명합니다.

## 한도

| 항목 | 한도 |
|---|---|
| 파일 하나 | 200MB |
| 이미지 | PNG·JPG·GIF·WebP, 4MB 이하, 이미지 인식을 지원하는 모델일 때 |
| 음성·영상 파일 | 25MB, 음성 전사가 연결된 경우 |
| 슬라이드 장 수 | 최대 50장 (안 적으면 5~12장) |
| 보고서 절 수 | 3~12절 |
| 스킬 | 요청당 3개 |
| 모델 비교 | 2~3개 |
| 메모리 | 요청당 40건까지 전달 |
| 시작 문장(에이전트) | 6개 |
| API 키 | 계정당 10개 |
| 슬라이드 그림 업로드 | 5MB |
| 한 대화에 넣는 파일 분량 | 모델 창의 약 35% (최대 약 15만 자). 넘으면 관련 부분만 |
| 답변 길이 | 상한 없음. 같은 말이 되풀이되면 자동으로 멈춤 |

## 처리 시간 제한

- 하나의 요청은 최대 15분까지 처리되며, 초과하면 오류로 종료됩니다.
- 모델이 3분 동안 응답을 전송하지 않으면 오류로 종료됩니다. 이 경우 **다른 모델로** 를 사용하십시오.
- 보고서와 슬라이드는 절 또는 장 단위로 순차 작성합니다. 20장 분량의 발표자료는 수 분이 소요되며, 영상 생성은 그보다 오래 걸리고 진행률이 표시됩니다.

## 오류 문구별 대처

화면에 표시된 문구를 그대로 검색하십시오.

| 화면의 문구 | 뜻 | 대처 |
|---|---|---|
| 이번 달 크레딧을 모두 썼습니다 | 월 한도 소진 | 다음 달 1일 리필까지 대기. 무료 모델은 영향 없음 |
| 이번 달 크레딧이 부족합니다 | 남은 크레딧이 이 요청의 예상 비용보다 적음 | 옵션(장수·길이)을 줄이거나 무료 모델로 |
| 모델 서버에 연결할 수 없습니다 | 모델 게이트웨이 장애 | 잠시 후 재시도. 계속되면 관리자에게 문의 |
| 모델 서버 오류로 답변을 받지 못했습니다 | 게이트웨이가 거절(파일·대화가 모델 창을 넘은 경우 포함) | 새 대화에서 파일을 다시 올리거나 질문을 좁힘 |
| 모델이 응답하지 않아 요청을 중단했습니다. 다른 모델로 다시 생성해 보세요 | 3분간 글자가 오지 않음 | **다른 모델로** |
| 모델 서버의 요청 한도를 넘었습니다 | 게이트웨이 속도 제한 | 잠시 후 재시도 |
| 모델 서버가 인증을 거부했습니다 | 게이트웨이 키 문제 | 관리자에게 문의 |
| 모델 서버에 이 모델이 없습니다 | 모델 목록이 바뀜 | 다른 모델 선택. 관리자가 목록 새로고침 |
| 이 계정에 허용되지 않은 모델입니다 | 관리자가 제한한 모델 | 다른 모델 선택 |
| 이 모델은 지금 이 화면에서 쓸 수 없습니다 | 화면(보고서 등)과 모델이 안 맞음 | 모델 바꾸기 |
| 지금 사용할 수 있는 모델이 없습니다 | 게이트웨이 미연결 | 관리자에게 문의 |
| 개인정보 검사기를 사용할 수 없어 요청을 보내지 못했습니다 | 보호 장치 장애 | 관리자에게 문의. 안전을 위해 전송 차단 |
| 관리자 정책이 이 요청을 막았습니다 | 차단 주제에 해당 | 요청 내용 확인 |
| 답변이 중간에 끊겨 여기까지만 남았습니다 | 연결이 끊김(탭 닫힘·네트워크) | **다시 시도** 선택. 처음부터 다시 생성 |
| 첨부 파일을 찾을 수 없습니다. 다시 첨부하세요 | 파일이 지워짐 | 다시 첨부 |
| 선택한 스킬을 이 요청에 적용할 수 없습니다 | 스킬 조건(도구·모델) 불충족 | 스킬을 빼거나 모델 바꾸기 |
| 이 에이전트는 지침을 원본에서 읽는데, 원본이 지워졌거나 공개가 풀렸습니다 | 내용 비공개 에이전트의 원본 소실 | 다른 에이전트 |
| 이 대화의 에이전트가 꺼져 있어 보낼 수 없습니다 | 에이전트 비활성·삭제 | 새 대화 |
| 마이크를 쓸 수 없습니다. 브라우저의 마이크 권한을 확인해 주세요 | 마이크 없음·권한 없음 | 브라우저 권한 |
| 이 파일에서는 글자를 읽지 못했습니다 | 스캔본·미지원 형식 | 글자가 있는 파일로 |
| 로그인에 다섯 번 연속 실패해 15분 동안 잠겼습니다 | 잠금 | 15분 후 재시도 |
| 지금은 회원가입을 받지 않습니다 | 관리자가 가입을 막음 | 관리자에게 계정 요청 |

## 제공하지 않는 기능

- 전송한 메시지를 수정해 재전송하는 기능. 프롬프트를 복사해 새로 전송하십시오. 생성에 실패한 답변에는 **다시 시도** 와 **다른 모델로** 가 제공됩니다.
- 여러 사용자가 대화를 공동 편집하는 기능. 공유는 읽기 전용입니다.
- 2단계 인증.
- 모바일 화면의 모델 비교와 단축키. 도구 버튼은 **도구 더보기**에 포함됩니다.

## 모델의 한계

모델은 알지 못하는 내용을 사실처럼 생성할 수 있습니다. 기관 정보, 날짜, 수치처럼 변동하거나 암기할 수 없는 정보는 웹 검색을 켜거나 근거 자료를 첨부하십시오. 출처가 표시되지 않은 답변은 검색을 거치지 않은 답변입니다. 보고서는 **팩트체크** 로 근거를 대조하고, 계산은 **코드 실행** 으로 검산할 수 있습니다.
