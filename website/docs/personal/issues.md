# 문의·신고

오류를 알리거나, 필요한 기능을 요청하거나, 궁금한 점을 관리자에게 묻습니다. 계정 메뉴 → **문의·신고**에서 보낸 내용과 처리 상태, 관리자 답변을 확인합니다.

## 보내기

- **문의·신고** 화면의 **새 신고**(오류 신고) 또는 **새 문의**를 누릅니다. 종류는 **오류 신고**, **기능 요청**, **문의** 중에서 고릅니다.
- 답변에 👎를 누르면 옆에 **신고하기**가 나타납니다. 누르면 그 답변과 답변이 만든 아티팩트가 **함께 볼 곳**으로 채워진 채 열립니다.
- 스크린샷을 한 장 붙일 수 있습니다(PNG, JPEG, GIF, WebP, 5MB 이하).

## 함께 보내는 정보

- 늘 함께 가는 것: 앱 빌드, 브라우저, 화면 크기, 언어. 대화에서 보낸 경우 대화 종류, 사용한 모델, 에이전트·진행 과정, 단계 상태와 실패 사유, 아티팩트 판 번호.
- **이 세션을 관리자에게 공유합니다**를 체크한 경우에만 대화 내용, 만든 아티팩트의 판, 단계 기록, 대화의 파일이 보낸 시점 그대로 복사됩니다. 이후 대화를 고치거나 지워도 사본은 바뀌지 않습니다.
- 내부 자료 보호 경로(strict-local)로 처리된 대화는 **내부 자료가 포함된 것을 알고 공유합니다**를 체크해야 사본을 보낼 수 있습니다.

## 처리 상태

상태는 **접수 · 확인 중 · 해결 · 보류** 순으로 바뀌며, 관리자가 답하면 계정 메뉴의 **문의·신고**에 **새 답변** 수가 표시됩니다. 관리자가 세션 사본을 열면 감사 기록에 남습니다.
