# 설정

계정 메뉴 → **설정**에서 다섯 개 탭을 제공합니다.

## 프로필

![프로필 탭](/img/guide/settings-profile.png)

이름과 비밀번호를 변경할 수 있습니다. 비밀번호를 변경하려면 현재 비밀번호와 10자 이상의 새 비밀번호를 입력해야 하며, 변경하면 다른 기기의 로그인이 해제됩니다. 역할과 가입일, 이번 달 남은 크레딧과 배정량, 다음 리필 일자를 확인할 수 있습니다. 크레딧은 매월 1일에 배정량으로 초기화되며 이월되지 않습니다. 이메일은 변경할 수 없습니다.

## 환경설정

![환경설정 탭](/img/guide/settings-preferences.png)

| 항목 | 설명 |
|---|---|
| 화면별 기본 모델 | 챗, 보고서, 슬라이드 등 화면마다 새 대화에 적용할 모델입니다. 계정에 저장되므로 모든 기기에서 동일하게 적용됩니다. |
| 개인정보 감지 기본 처리 | 매번 확인, strict-local로 전환, 마스킹, 원문 전송(관리자가 허용한 경우) 중에서 선택합니다. [개인정보 보호](../privacy) |
| 응답 스트리밍 | 끄면 답변이 완성된 후 한 번에 표시됩니다. |
| 메모리 자동 저장 | 답변마다 지속적으로 유효한 정보를 자동으로 저장합니다. |
| 토큰·크레딧 표시 | 답변 하단의 사용량 표시 여부를 설정합니다. |

테마와 언어는 이 탭이 아니라 화면 오른쪽 위의 버튼에서 전환합니다.

## 개인 맞춤 설정

![개인 맞춤 설정 탭](/img/guide/settings-personalization.png)

- **나에 대해 알아 두면 좋은 것**: 소속, 담당 업무, 이해 수준 등을 기술합니다. **대화에만** 적용되며 보고서와 슬라이드에는 전달되지 않습니다.
- **답변 방식**: 분량, 어조, 형식을 기술합니다. 대화와 문서 모두에 적용됩니다. "서론 없이", "예시를 반드시 포함", "영문 용어 병기"와 같이 작성합니다.

설정은 다음 대화부터 적용됩니다. 에이전트나 프로젝트의 지침이 있으면 그쪽이 우선합니다. `Ctrl+Shift+I` 로 바로 열 수 있으며, 적용되면 답변의 작업 단계에 **개인 맞춤 설정 적용**이 표시됩니다.

## API 키

![API 키 탭](/img/guide/settings-keys.png)

외부 도구나 스크립트에서 사용할 키를 발급합니다. 계정당 최대 10개까지 발급할 수 있으며, 키 값은 발급 시 한 번만 표시되므로 즉시 복사해야 합니다. 목록에서 발급일과 마지막 사용 시각을 확인하고 **폐기**하면 즉시 차단됩니다. 계정에 설정된 허용 모델 제한이 키에도 동일하게 적용됩니다. [API와 코딩 도구 연동](../api)

## 보안

![보안 탭](/img/guide/settings-access.png)

- **로그인된 기기**: 브라우저, IP, 마지막 사용 시각을 표시합니다. 현재 기기가 표시되며 개별 종료와 **다른 기기 모두 로그아웃**을 제공합니다. API 키를 통한 호출은 이 목록에 표시되지 않습니다.
- **접속 기록**: 최근 100건의 로그인, 로그인 실패, 비밀번호 변경, 키 발급 내역을 IP, 지역, 브라우저와 함께 표시합니다. 지역 정보는 관리자가 위치 데이터를 설정한 경우에만 표시되며 사설망은 "내부망"으로 표기됩니다.
- 2단계 인증은 제공하지 않습니다. 충분히 긴 비밀번호를 사용하고 확인되지 않은 기기는 종료하십시오.
