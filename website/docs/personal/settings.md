# 설정

계정 메뉴 → **설정**에서 일곱 개 탭을 제공합니다: 프로필, 환경설정, 개인 맞춤 설정, 메모리, 연결, API 키, 보안.

## 프로필

![프로필 탭](/img/guide/settings-profile.png)

이름을 변경할 수 있습니다(비밀번호는 **보안** 탭). 역할과 가입일, 이번 달 남은 크레딧과 배정량, 다음 리필 일자를 확인할 수 있습니다. 크레딧은 매월 1일에 배정량으로 초기화되며 이월되지 않습니다. 이메일은 변경할 수 없습니다.

## 환경설정

![환경설정 탭](/img/guide/settings-preferences.png)

| 항목 | 설명 |
|---|---|
| 화면별 기본 모델 | 챗, 보고서, 슬라이드 등 화면마다 새 대화에 적용할 모델입니다. 계정에 저장되므로 모든 기기에서 동일하게 적용됩니다. 챗·보고서·슬라이드는 Super Agent와 Super Agent (strict-local)도 고를 수 있습니다. 고르지 않으면 관리자가 정한 기본값을 따르며, 처음에는 Super Agent입니다. |
| 개인정보가 감지된 요청 → 기본 처리 방법 | 매번 확인, strict-local로 전환, 마스킹, 원문 전송(관리자가 허용한 경우) 중에서 선택합니다. [개인정보 보호](../privacy) |
| 개인정보가 감지된 요청 → strict-local 이미지 모델 | 내부 자료가 있는 대화나 문서의 그림을 strict-local로 그려야 하는데 고른 이미지 모델이 외부 모델일 때, 대신 그릴 모델입니다. strict-local 이미지 모델이 둘 이상일 때만 표시됩니다. 고르지 않으면 `strict-local/z-image-turbo`를 쓰고, 그 모델이 없으면 목록의 첫 모델을 씁니다. |
| 응답 스트리밍 | 끄면 답변이 완성된 후 한 번에 표시됩니다. |
| 메모리 자동 저장 | 답변마다 지속적으로 유효한 정보를 자동으로 저장합니다. |
| 스페이스로 말하기 | 빈 입력창에서 `Space` 를 누른 채 말하면, 떼는 순간 받아 적어 입력창에 넣습니다. 보내지는 않습니다. 음성 전사가 연결된 경우에만 보이며 기본은 꺼짐입니다. |
| 토큰·크레딧 표시 | 답변 하단의 사용량 표시 여부를 설정합니다. |

화면 밝기(시스템·밝게·어둡게)와 언어는 이 탭이 아니라 화면 오른쪽 위의 버튼에서 전환합니다.

## 글씨·글자 크기 키우기

KloudChat에는 글자 크기 설정이 따로 없습니다. 화면 글씨를 크게 보려면 브라우저 확대를 씁니다: Windows는 `Ctrl` + `+`(줄이기 `Ctrl` + `-`, 원래대로 `Ctrl` + `0`), Mac은 `Cmd` + `+`. 200%로 키워도 화면이 줄을 바꿔 맞추므로 그대로 쓸 수 있습니다. 휴대폰에서는 두 손가락으로 벌려 키웁니다.

## 개인 맞춤 설정

![개인 맞춤 설정 탭](/img/guide/settings-personalization.png)

- **나에 대해 알아 두면 좋은 것**: 소속, 담당 업무, 이해 수준 등을 기술합니다. **대화에만** 적용되며 보고서와 슬라이드에는 전달되지 않습니다.
- **답변 방식**: 분량, 어조, 형식을 기술합니다. 대화와 문서 모두에 적용됩니다. "서론 없이", "예시를 반드시 포함", "영문 용어 병기"와 같이 작성합니다.

설정은 다음 대화부터 적용됩니다. 에이전트나 프로젝트의 지침이 있으면 그쪽이 우선합니다. `Alt+Shift+P` 로 바로 열 수 있으며, 적용되면 답변의 작업 단계에 **개인 맞춤 설정 적용**이 표시됩니다.

## 메모리

대화를 넘어 기억할 정보를 보고 고칩니다. 자세한 내용은 [메모리](memory.md)를 보십시오.

## 문서 모양

설정에는 문서 모양을 정하는 탭이 없습니다. 보고서와 슬라이드의 색·글꼴·표 모양은 [프로젝트](projects.md#디자인-지침)나 에이전트의 **디자인 지침**에 말로 적거나, 회사 양식 파일을 첨부해 맞춥니다. 문서 하나의 모양은 보고서·슬라이드 패널의 **모양**에서 바꿉니다.

## 연결

내 Google 드라이브와 Slack 계정을 연결합니다. 관리자가 켠 서비스만 보이고, 연결은 내 계정에만 쓰입니다(개인 gmail.com 계정도 됩니다).

- **Google 드라이브**: 입력창의 **+ › 드라이브에서 가져오기**나 프로젝트 **지식 › 드라이브**에서 Google 파일 선택 창으로 고른 파일만 앱이 엽니다. 드라이브의 다른 파일은 보지 않습니다. 가져온 파일의 새로 고침 단추는 드라이브에서 바뀐 내용을 다시 가져옵니다.
- **드라이브에 저장**처럼 밖으로 쓰는 일은 답 아래 확인 카드에서 **확인**을 눌러야 보냅니다.
- 드라이브 내용은 내부 자료로 다룹니다. 관리자가 내부 자료를 strict-local로 두면 내부 모델만 읽습니다.
- **연결 해제**는 권한을 되돌리고 저장한 토큰을 지웁니다. 가져온 파일은 남습니다.

## API 키

![API 키 탭](/img/guide/settings-keys.png)

외부 도구나 스크립트에서 사용할 키를 발급합니다. 계정당 최대 10개까지 발급할 수 있으며, 키 값은 발급 시 한 번만 표시되므로 즉시 복사해야 합니다. 목록에서 발급일과 마지막 사용 시각을 확인하고 **폐기**하면 즉시 차단됩니다. 계정에 설정된 허용 모델 제한이 키에도 동일하게 적용됩니다. [API와 코딩 도구 연동](../api)

## 보안

![보안 탭](/img/guide/settings-access.png)

- **비밀번호 변경**: 현재 비밀번호와 10자 이상의 새 비밀번호를 입력합니다. 변경하면 다른 기기의 로그인이 해제됩니다.
- **로그인된 기기**: 브라우저, IP, 마지막 사용 시각을 표시합니다. 현재 기기가 표시되며 개별 종료와 **다른 기기 모두 로그아웃**을 제공합니다. API 키를 통한 호출은 이 목록에 표시되지 않습니다.
- **접속 기록**: 최근 100건의 로그인, 로그인 실패, 비밀번호 변경, 키 발급 내역을 IP, 지역, 브라우저와 함께 표시합니다. 지역 정보는 관리자가 위치 데이터를 설정한 경우에만 표시되며 사설망은 "내부망"으로 표기됩니다.
- 2단계 인증은 제공하지 않습니다. 충분히 긴 비밀번호를 사용하고 확인되지 않은 기기는 종료하십시오.

## 알림

오래 걸린 작업(보고서·슬라이드·문서·심층 조사·영상·스튜디오·체인)이 끝나면 알림으로 알려 줍니다. 처음 긴 작업을 시작할 때 한 번 묻고, **이 기기에서 알림 켜기**로 언제든 켭니다. 탭을 닫아도 알림이 옵니다. 알릴 일을 하나씩 켜고 끌 수 있고, 알림 받는 기기를 보고 지울 수 있습니다. 알림에는 대화 제목만 담기며, 내부 자료를 쓴 대화는 제목 없이 알립니다. iPhone·iPad는 홈 화면에 추가한 앱(iOS 16.4 이상)에서만 받습니다.

## 앱

**앱으로 설치**를 누르면 브라우저 탭 없이 따로 열리는 앱이 됩니다. Safari에서는 공유 메뉴의 「홈 화면에 추가」(Mac은 파일 메뉴의 「Dock에 추가」)로 설치합니다.
