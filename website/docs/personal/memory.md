# 메모리

메모리는 대화를 넘어 지속적으로 참조할 정보입니다. 소속, 진행 중인 과제, 표기 규칙 등을 저장합니다.

![메모리 화면](/img/guide/memory.png)

## 저장 방법

- **자동 저장**: 설정 → 환경설정의 **메모리 자동 저장**을 켜면 답변이 끝날 때마다 앞으로도 계속 유효한 내용을 선별해 저장합니다. 기본값은 꺼짐이며, 이미 저장된 내용은 중복 저장하지 않습니다. 저장 시 답변 하단에 "메모리 n건 저장"이 표시됩니다.
- **직접 추가**: 계정 메뉴 → **메모리** → 새 메모리에서 입력합니다.
- **프로젝트 메모리**: 프로젝트 상세의 메모리 탭에서 관리하며, 에이전트가 노트 공유로 남긴 결론도 이곳에 저장됩니다.

## 구성 항목

| 항목 | 설명 |
|---|---|
| 이름 | 영문 소문자와 하이픈으로 작성합니다. 다른 메모리에서 `[[이름]]` 형식으로 참조할 수 있습니다. |
| 유형 | 사용자, 피드백, 프로젝트, 참조 중에서 선택합니다. |
| 설명 | 어떤 상황에서 참조할지 한 줄로 기술합니다. |
| 범위 | 전역(모든 대화) 또는 프로젝트 단위로 지정합니다. |
| 고정 | 고정한 메모리는 모든 대화에 우선 전달됩니다. |

## 전달 방식

매 요청마다 고정된 항목과 최근 항목을 기준으로 최대 40건이 전달되며, 답변의 작업 단계에 "메모리 n건 참고"로 표시됩니다. 40건을 초과하면 오래된 항목이 제외되므로 사용하지 않는 메모리는 삭제하십시오.

잘못 저장된 정보는 메모리 화면에서 수정할 수 있습니다. 설정의 **나에 대해**와 메모리의 내용이 서로 다르면 답변이 일관되지 않을 수 있으므로 일치시키십시오. 메모리는 공유 링크에 포함되지 않습니다.
