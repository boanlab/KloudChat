# 사용량과 대화 기록

크레딧 사용 현황을 확인하고 지난 대화를 정리합니다.

## 사용량

계정 메뉴 → **사용량**에서 확인합니다.

![사용량 화면](/img/guide/usage.png)

- 이번 달 남은 크레딧과 배정량, 기간 선택, 일별 크레딧 또는 응답 수 추이를 제공합니다.
- **모델별**, **화면별**(챗, 보고서, 슬라이드, 이미지 등), **API 키별** 사용량을 구분해 표시합니다. API 키 사용량은 별도로 집계되지만 동일한 월 한도를 공유합니다.
- 음성 전사는 초 단위, 자료 색인은 청크 단위로 별도 표시됩니다.

## 크레딧

크레딧은 모델 사용량을 나타내는 단위이며 종류에 따라 기준이 다릅니다.

| 종류 | 과금 단위 |
|---|---|
| 텍스트 | 1,000 토큰당. 입력과 출력을 구분합니다. |
| 이미지 | 장당 |
| 오디오 | 회당 |
| 동영상 | 초당 × 해상도·소리 조합. 생성이 완료된 경우에만 차감합니다. |

**무료**로 표시된 모델은 크레딧을 소모하지 않습니다. 대부분 기관이 직접 운영하는 모델이지만 외부 서비스가 무료로 제공하는 모델도 동일하게 표시되며, 이 경우 요청은 기관 밖으로 전송됩니다. 모델 목록의 데이터 경계 표시를 함께 확인하십시오.

크레딧은 매월 1일에 배정량으로 초기화되며 이월되지 않습니다. 모두 소진하면 다음 리필까지 새 요청을 전송할 수 없으나 이미 생성된 결과물은 유지됩니다. 생성을 중지한 요청은 추정치로 기록됩니다.

## 대화 기록

계정 메뉴 → **대화 기록**에서 확인합니다.

![대화 기록 화면](/img/guide/history.png)

- 전체 대화를 날짜별로 확인하고 제목으로 검색합니다.
- 표시된 항목을 **전체 선택**한 뒤 **선택 삭제**하거나 **모든 대화 삭제**를 실행할 수 있습니다. 실행 전에 확인 창이 표시됩니다.
- 대화를 삭제하면 해당 대화에서 생성된 결과물과 공유 링크도 함께 삭제됩니다. 프로젝트와 메모리는 유지됩니다.
- 관리자가 보존 기간을 설정한 환경에서는 기간이 지난 대화 본문이 자동으로 삭제됩니다. 접속 기록과 사용량 집계는 유지됩니다.
