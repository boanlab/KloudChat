# 프로젝트

프로젝트는 자료와 지침, 대화를 하나로 묶는 작업 공간입니다. 같은 자료를 여러 대화에서 참조하거나, 공통 규칙을 매번 입력하는 번거로움을 줄일 때 사용합니다.

![프로젝트 화면](/img/guide/projects.png)

## 생성

사이드바 → **프로젝트** → 새 프로젝트 순으로 진행하며 이름, 설명, **프로젝트 지침**을 입력합니다. 생성 후 상세 화면에서 아이콘, 디자인 시스템, 화면별 **기본 서식**(보고서, 슬라이드)을 지정할 수 있습니다.

## 탭 구성

| 탭 | 기능 |
|---|---|
| 작업 | 이 프로젝트에서 새 작업을 시작하고, 기존 대화를 프로젝트에 편입하거나 제외합니다. |
| 지식 | 파일을 추가하고 **웹 자료**로 주소를 등록합니다. 웹 자료는 등록 시점의 내용을 저장합니다. 파일별 토큰 수와 컨텍스트 점유 비율을 표시하며, 인식된 내용 확인과 원본 다운로드, 삭제를 지원합니다. |
| 스킬 | 추천 스킬을 지정하면 이 프로젝트의 입력창에서 우선 표시됩니다. |
| 메모리 | 프로젝트 단위로 공유하는 메모리입니다. 에이전트가 **노트 공유**로 남긴 결론도 이곳에 축적됩니다. |

## 지식 전달 방식

프로젝트 지식은 해당 프로젝트의 모든 대화에 자동으로 전달됩니다. 분량이 처리 범위 이내이면 전체를 전달하고, 초과하면 질문과 관련된 부분만 선별해 전달합니다. 선별한 분량도 범위를 넘으면 파일 목록만 전달합니다. 반영 정도는 답변의 작업 단계에서 확인할 수 있습니다. 보고서에서는 출처 번호로 인용됩니다.

## 지침

"답변은 존댓말로", "용어는 영문을 병기"처럼 모든 대화에 적용할 규칙을 기술합니다. 개인 맞춤 설정보다 우선 적용됩니다.

## 프로젝트 삭제

프로젝트를 삭제하면 지침과 지식 파일이 삭제됩니다. 대화는 프로젝트에서 분리되어 유지되며 결과물과 메모리도 남습니다.

## 대화 첨부와 비교

| 구분 | 대화 첨부 | 프로젝트 지식 |
|---|---|---|
| 적용 범위 | 해당 대화 | 프로젝트의 모든 대화 |
| 유지 기간 | 대화를 삭제할 때까지 | 파일을 삭제할 때까지 |
| 공유 링크 | 답변에 인용된 범위까지 노출 | 노출되지 않음 |
