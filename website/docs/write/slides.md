# 슬라이드 작성

홈에서 **슬라이드**를 선택하고 발표 주제와 대상을 입력합니다. 진행 절차는 보고서와 동일합니다. 확인 질문, **구성 확인**, **그림을 넣을까요?** 카드, 장 단위 작성 순으로 진행됩니다.

입력창 위의 **형식** 칩에서 **웹 슬라이드**나 **PowerPoint**를 고릅니다(새 대화, 프로젝트나 에이전트에서 연 대화, 기록에서 다시 연 대화 모두 같습니다). PowerPoint를 고르면 **빈 문서로 시작** 단추가 나타나고, PowerPoint 파일을 만들어 그 턴에 채웁니다. 파일은 [PowerPoint 편집기](pptx)에서 고칩니다. PowerPoint 양식(`.pptx`, `.potx`)을 첨부하거나 프로젝트·에이전트에 **기본 양식 파일**이 있으면 그 양식 위에 만듭니다([양식에 맞춰 쓰기](pptx#양식에-맞춰-쓰기)). 프로젝트의 양식은 형식 칩 옆에 **프로젝트 양식** 칩으로 보이고, ✕로 이 대화에서만 뺍니다. 덱의 용도 패턴(아래 [용도에 맞는 구성](#용도에-맞는-구성))은 요청의 말에서 자동으로 고릅니다. 주소 `/new/slides?format=pptx`로 열면 형식이 미리 골라져 있습니다. 아래는 웹 슬라이드의 진행입니다.

![작성된 슬라이드](/img/guide/slides.png)

## 구성 확인 항목

- 장 제목과 순서
- **어떻게 사용할 자료인가요?**: 발표하면서 설명 또는 자료만 전달

웹 슬라이드의 모양은 구성 카드에서 고르지 않습니다. 작성 후 패널에서 편집형, 미니멀, 포스터형, 분할형, 다크, 강철, 따뜻한, 파스텔, 숲, 학술, 흑백 중에서 선택합니다.

## 용도에 맞는 구성

요청에 쓴 말로 발표의 용도를 알아보고, 그 용도의 흐름과 확인 항목을 따릅니다. 고르는 화면은 없습니다.

| 용도 | 이런 말이 있으면 | 흐름 |
|---|---|---|
| 심사 발표 | 학위 논문 심사, 디펜스, 중간 평가 | 연구 질문 → 방법 → 결과 → 한계 → 다음 계획 |
| 연구·논문 발표 | 논문 발표, 랩 세미나, 저널 클럽, 학회 발표 | 논문 정보 → 문제 → 방법(논문의 그림·표) → 결과 → 한계 → 토론 질문 |
| 수업 과제 발표 | 과제 발표, 조별 과제, 팀플, 기말 발표 | 과목·조 → 질문 → 조사 → 분석 → 결론 → 참고 자료 |
| 투자 IR | 투자 유치, IR 자료, 피치덱, 시리즈 A | 문제 → 해결 → 시장 → 모델 → 지표 → 경쟁 → 팀 → 재무 → 요청 |
| 실적·성과 보고 | 분기 실적, 성과 보고, KPI, 목표 대비 | 핵심 숫자 → 목표 대비 → 추이(자료의 값으로 그린 차트) → 원인 → 다음 계획 |
| 프로젝트 결과 보고 | 결과 보고, 완료 보고, 회고, 사후 검토 | 목표·기간 → 결과 → 목표 대비 → 잘된 점·아쉬운 점 → 교훈 → 후속 조치 |
| 제품·서비스 소개 | 제품·솔루션 소개, 영업 자료, 고객사 미팅 | 고객의 문제 → 기능과 효과 → 작동 방식 → 사례 → 도입 절차 |
| 제안 발표 | 제안, 공모, 지원사업, 사업계획, 예산 승인 요청 | 현황 → 제안 → 근거 → 일정·예산 → 요청 |
| 정책·제도 안내 | 제도·정책 변경 안내, 설명회, 시행 안내 | 무엇이 바뀌나 → 이전·이후 → 대상·시행일 → 해야 할 일 → 문의처 |
| 교육·온보딩 | 신입·온보딩, 사내·직무 교육, 워크숍 | 학습 목표 → 개념 → 따라 하기 → 자주 하는 실수 → 확인 문제 |
| 강의 자료 | 강의, 수업 자료, 교안, ○주차 | 주제 → 개념과 예시 → 요점 → 다음 시간·과제 |
| 케이스 발표 | 대안 비교, 권고안, 경영진 보고 | 권고 → 현황 → 대안 비교 → 판단 기준 → 위험 → 요청 |
| 회의·브리핑 자료 | 회의 자료, 안건, 브리핑, 진행 현황 공유 | 오늘 정할 것 → 안건 → 진행 현황 → 막힌 일 → 담당과 기한 |

- 용도마다 쓰기 전에 물어볼 빈칸이 있습니다. 예를 들어 실적 보고는 기간과 목표치가 자료에 없으면 먼저 묻고, 답이 없으면 대괄호 빈칸으로 둡니다.
- 실적 보고, 연구·논문 발표, 프로젝트 결과 보고, 회의 자료는 주신 자료로만 만들고 요청에 「검색」, 「최신」 같은 말이 없으면 웹 검색을 하지 않습니다.
- 두 용도에 모두 맞으면 표의 위쪽 용도를 따르고, 진행 단계에 「구조: … 패턴」과 함께 맞은 패턴을 적습니다. 웹 슬라이드 카드 아래에도 같은 줄이 붙습니다.
- PowerPoint 양식을 붙였으면 모양은 양식을 따르고, 흐름은 용도를 따릅니다.

## 장 수 지정

| 입력 예시 | 반영 내용 |
|---|---|
| "6장", "20장짜리" | 지정한 장 수로 작성합니다. 최대 50장입니다. |
| "20분 발표" | 2분당 1장을 기준으로 최소 장 수를 산출합니다. 20분이면 최소 10장이며, 4분 미만이면 시간을 장 수에 반영하지 않고 5장 이상, 12장까지로 정합니다. |
| 지정하지 않음 | 주제에 맞춰 5~12장으로 작성합니다. |

6장을 초과하면 두 번째 장에 목차가 삽입됩니다.

## 장 유형

모델이 내용에 맞는 유형을 선택합니다. 표지, 목차, 항목 나열, 표(비교), 지표(핵심 수치), 차트(자료에 수치가 있는 경우), 도식(흐름과 구조), 마무리를 사용합니다. "비교는 표로", "흐름도를 포함해"와 같이 요청문에 지정할 수 있습니다. 도식은 서버가 도형으로 그리며, PPTX로 내보내면 편집할 수 있는 PowerPoint 도형으로 들어갑니다. 제목이 구조·관계·흐름을 말하는 장("전체 구조", "핵심 오브젝트 관계도", "요청 처리 흐름")은 요청에 "구조도"라는 말이 없어도 도식을 넣습니다. 관계도는 순서 화살표가 아니라 관계 이름을 단 선으로 그립니다. 다 만든 뒤 "4장을 구조도로 바꿔 줘"라고 하면 그 장을 도식으로 바꿉니다. 영어로 쓴 덱은 도식의 글자와 설명도 영어입니다.

## 모양 변경

패널 도구 막대의 **모양** 메뉴에서 모양과 강조색을 바꿉니다. ⋯ 메뉴의 **이 장 다시 만들기**는 선택한 장을 다시 만듭니다. 프로젝트나 에이전트에 [디자인 지침](../personal/projects.md#디자인-지침)이 있으면 그 색상과 서체를 따릅니다.

## 발표 모드

도구 막대나 ⋯ 메뉴의 **발표**로 전체 화면 발표 모드를 엽니다. `←` `→` 로 장을 이동하고 `Esc` 로 종료합니다. 발표 시간 타이머(누르면 0으로 되돌림), `N` 키로 표시하는 발표 노트, 장 목록을 제공합니다.

## 내보내기

**내려받기**에서 PowerPoint(PPTX), PDF(발표용), 텍스트(노트 포함)를 선택합니다. 내용이 잘릴 우려가 있는 장, 근거 확인이 필요한 장, 미해결 검토 메모가 있으면 내보내기 전에 안내합니다. 받은 `.pptx`나 회사 양식을 그대로 채우고 고치려면 [PowerPoint 문서](pptx)를 쓰세요.

## 수정

"2번 장을 더 간결하게"와 같이 요청하면 해당 장만 다시 작성합니다. "20장으로 늘려 주세요", "사례 장을 추가해 주세요"처럼 구성을 바꾸는 요청은 확인 질문이나 승인 없이 바로 새 구성으로 작성합니다. 자세한 내용은 [요청으로 수정](revise)을 참고하세요. 문장을 직접 고치거나 장 순서를 바꾸려면 [아티팩트 편집기](editor)를 사용하세요.
