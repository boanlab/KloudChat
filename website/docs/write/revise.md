# 요청으로 수정

작성이 끝난 보고서와 슬라이드 하단의 입력창에 수정할 내용을 입력합니다. 요청 내용을 분석해 수정할 부분과 방식을 자동으로 판단합니다. 문장 단위 수정이나 장 순서 변경은 [아티팩트 편집기](editor)를 사용하는 편이 빠릅니다.

| 요청 예시 | 처리 방식 |
|---|---|
| "2번 절을 절반으로 줄여 주세요", "결론에 일정 표를 추가해 주세요" | 해당 부분만 다시 작성합니다. 나머지는 유지됩니다. |
| "2절의 표는 빼고, 맨 앞에 3줄 요약을 넣어 주세요" | 요청마다 그 요청이 가리키는 절만 다시 작성합니다. 요약은 첫 절 맨 앞에 「핵심」 상자로 요청한 줄 수만큼 넣고, 제목·작성자 줄을 되풀이하지 않습니다. |
| "표 2와 그림 1은 빼 주세요" | 번호로 가리킨 표·그림을 다시 쓰지 않고 그대로 뺍니다. 그 표·그림을 가리키던 문장도 정리하고, 뒤의 표·그림 번호와 본문 속 번호를 당겨 맞춥니다. 같은 요청으로 그 절을 다시 쓸 때도 뺀 자리에 새 표·그림을 넣지 않습니다. 없는 번호는 찾지 못했다고 알려 드립니다. 영어로 쓴 문서는 표·그림 번호도 "Table 2"·"Figure 1"로 붙고, "remove table 2"처럼 영어로 요청해도 같게 뺍니다. |
| "전체적으로 더 간결하게", "말투를 존댓말로" | 모든 부분을 다시 작성합니다. |
| "20장으로 늘려 주세요", "3장 추가", "2번과 3번을 합쳐 주세요", "순서를 바꿔 주세요" | 구성을 다시 짜서 확인 질문이나 승인 없이 바로 작성합니다. 지금 문서가 자료이므로 되묻지 않습니다. 유지할 부분은 기존 제목과 내용을 그대로 사용합니다. |
| "몇 장으로 해 달라고 했죠?", "4장 수치는 어디서 나온 거야?"처럼 문서나 대화를 묻는 말 | 문서와 지금까지의 대화만 읽고 답하며, 문서는 바꾸지 않습니다. |
| "새로 써 주세요", "처음부터 다시", "다른 주제로" | 기존 문서를 유지한 채 새로 작성합니다. |

수정이 끝나면 요청마다 한 일을 알려 드리고(예: "2절의 표 2를 뺐습니다. 맨 앞에 3줄 요약을 넣었습니다. 1절을 고쳤습니다.") 패널에 바로 반영합니다. 찾지 못했거나 반영되지 않은 요청은 고쳤다고 하지 않고 따로 알려 드립니다. 영어로 요청하면 답도 영어로 드립니다. 수정할 때마다 이전 본문이 버전으로 저장됩니다.

## 요청별 동작

- **그림·차트 빼기**: "그림 빼 줘"는 자동으로 그린 도식까지 빼고 몇 장에서 무엇을 뺐는지 알려 드립니다. 뺄 그림이 없으면 바꾼 것이 없다고 알려 드리고, 차트만 있으면 차트가 있는 장을 알려 주며 무엇을 뺄지 되묻습니다. "4장 차트 빼 줘"는 차트를 빼고 그 수치를 글머리표로 남깁니다.
- **모양만 바꾸기**: "4장을 번호 목록으로", "3장을 표로"는 그 장의 항목·수치·제목을 그대로 옮겨 담습니다. 내용이 표의 칸으로 나뉘지 않으면 장을 그대로 두고 그렇다고 알려 드립니다.
- **항목 합치기·나누기**: "2장 항목을 하나로", "3장 항목을 두 개로 나눠줘"는 그 장만 고치고 덱을 새로 만들지 않습니다. 차트가 있는 장은 차트를 두고 옆의 항목만 고칩니다.
- **분량 줄이기**: "2절을 두 문장으로 줄여"처럼 문장 수를 정하면 그 수와 절의 수치·이름이 남았는지 확인해 한 번 더 고쳐 씁니다. 그래도 맞지 않으면 원래 절을 그대로 두고 몇 문장인지를 알려 드립니다. 줄이면서 빠진 수치·날짜·상자, 사라진 표·차트도 알려 드립니다. 절에 없던 날짜는 붙이지 않습니다.
- **카드가 열려 있을 때**: 되묻는 카드나 구성 제안이 열려 있어도 문서를 묻는 질문이나 "3장을 번호 목록으로"처럼 장 번호를 짚은 수정은 그 요청대로 처리합니다. 카드의 답으로 보지 않으며, 열려 있던 카드는 그대로 남습니다. "4장은 빼고 진행해 줘"처럼 구성을 바꾸는 말은 구성 제안을 고치라는 의견으로 봅니다.

부분 수정 시에도 최초 요청과 첨부 자료를 다시 참조합니다. 새로운 자료를 반영하려면 자료를 첨부한 상태에서 수정을 요청하세요.
