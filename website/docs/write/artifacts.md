# 아티팩트

보고서, 슬라이드, 차트, 코드, 웹 페이지, 이미지 등 대화에서 생성된 결과물을 아티팩트라고 하며, 사이드바의 **아티팩트** 화면에 모입니다.

![아티팩트 갤러리](/img/guide/artifacts.png)

## 결과물 패널

- 결과물이 생성되면 패널이 자동으로 열립니다. 닫은 경우 대화 화면 오른쪽 위의 **보고서 열기**, **덱 열기** 등의 버튼으로 다시 엽니다.
- 공통 기능으로 버전과 수정 시각 표시, 복사, 다운로드, 너비 조절(더블클릭 시 초기화), 좁게·넓게·문서만 보기, 닫기를 제공합니다. 화면이 좁으면 대화 위에 겹쳐서 표시됩니다.
- 코드와 웹 페이지는 **미리보기**와 **소스** 탭, 확대·축소를 지원합니다. 웹 페이지는 격리된 창에서 실행되므로 값을 저장하는 기능은 동작하지 않습니다.
- 챗에서도 "표로 정리해 문서로 만들어 주세요", "이 데이터로 차트를 그려 주세요"와 같이 요청하면 결과물이 패널에 생성됩니다.

## 내보내기 형식

| 종류 | 형식 |
|---|---|
| 보고서 | PDF, Word(DOCX), 한글(HWPX), 마크다운 원문, 인쇄 |
| 슬라이드 | PowerPoint(PPTX), PDF, 텍스트(노트 포함) |
| 서식을 적용한 문서 | PDF, DOCX/PPTX, HWPX, HTML, 텍스트 |

PDF는 디자인을 그대로 반영하고, DOCX와 PPTX는 편집 가능한 구조를 우선하므로 서식의 시각적 요소가 일부 달라질 수 있습니다.

## 갤러리

사이드바의 **아티팩트**에서 전체 목록을 확인합니다. 종류별 탭(전체, 코드, HTML, 보고서, 슬라이드, 차트, 이미지, 오디오, 동영상)과 제목 검색을 제공합니다. 카드를 선택하면 갤러리 안에서 패널로 열리고, 생성된 대화로 이동하려면 카드의 **원본 작업 열기**를 사용합니다. 갤러리에서 삭제하면 버전 기록까지 함께 삭제되지만 대화는 유지됩니다.
