# 아티팩트

대화에서 생성된 것을 아티팩트라고 합니다. 사이드바의 **아티팩트** 화면에는 바로 보거나 실행하는 것, 즉 HTML 페이지, 코드 파일, 차트, 도식이 모입니다. 보고서, 슬라이드, 시트(웹·한글·Word·PowerPoint·Excel)는 [파일함](../chat/files#파일함)의 **작업 문서**에, 생성한 이미지·오디오·동영상은 **만든 파일**에 모입니다. 답변 안의 짧은 코드 블록은 대화 내용의 일부라서 아티팩트로 따로 저장하지 않습니다. 복사와 실행은 대화 안에서 합니다.

![아티팩트 갤러리](/img/guide/artifacts.png)

## 아티팩트 패널

- 아티팩트가 생성되면 패널이 자동으로 열립니다. 닫은 경우 대화 화면 오른쪽 위의 **보고서 열기**, **덱 열기** 등의 버튼으로 다시 엽니다.
- 공통 기능은 버전과 수정 시각 표시, 복사, 다운로드, 닫기입니다. 너비는 끌어서 조절하고 두 번 누르면 기본값으로 돌아갑니다. **넓게 보기**·**문서만 보기**·**패널 좁히기**를 돌아가며 고르는 버튼도 있습니다. 화면이 좁으면 대화 위에 겹쳐서 표시됩니다.
- 코드와 웹 페이지는 **미리보기**와 **소스** 탭, 확대·축소를 지원합니다. 웹 페이지는 격리된 창에서 실행되므로 값을 저장하는 기능은 동작하지 않습니다. 웹 페이지의 머리에는 **검토**, 그림 넣기, 부분 **다시 쓰기**, 내려받기가 있습니다.
- 챗에서도 "표로 정리해 문서로 만들어 주세요", "이 데이터로 차트를 그려 주세요"와 같이 요청하면 아티팩트가 패널에 생성됩니다.

## 형식별 편집기

웹 보고서와 웹 슬라이드는 [아티팩트 편집기](editor)(리본)에서 엽니다. 한글, Word, PowerPoint, Excel 아티팩트는 각자의 편집기(HWP 편집기, 리본이 있는 Word 편집기, PowerPoint 편집기, 시트 편집기)에서 열립니다. 자세한 내용은 [한글(HWP) 문서](hwp), [Word 문서](docx), [PowerPoint 문서](pptx), [시트](sheet)를 참고하세요.

## 내보내기 형식

| 종류 | 형식 |
|---|---|
| 웹 보고서 | PDF, Word 문서(DOCX), 한글 문서(HWPX), 마크다운 원문, 인쇄 |
| 웹 슬라이드 | PowerPoint(PPTX), PDF(발표용), 텍스트(노트 포함) |
| 웹 페이지(HTML) | Word 문서, PDF, 한글 문서, 원본 HTML, 텍스트. 슬라이드 모양의 페이지는 PowerPoint, PDF, 원본 HTML, 텍스트 |
| 코드 파일 | 원본 파일 |
| 차트 | 이미지(PNG), 벡터(SVG), 데이터(CSV) |
| 한글·Word·PowerPoint·Excel 문서 | 편집기의 **내려받기**(HWPX·HWP, DOCX, PPTX, XLSX) |

PDF는 고른 모양을 그대로 반영하고, DOCX와 PPTX는 편집 가능한 구조를 우선하므로 화면의 시각적 요소가 일부 달라질 수 있습니다. 회사 양식 위에 쓴 Word·PowerPoint 파일은 양식의 모양을 그대로 따릅니다.

## 갤러리

사이드바의 **아티팩트**에서 전체 목록을 확인합니다. 탭은 **전체**, **HTML**, **코드 파일**, **차트**, **도식**이고 탭마다 개수가 보입니다. 제목으로 찾고, 열 제목(**제목·종류·판 수·마지막 수정**)을 눌러 정렬하며, 한 번 더 누르면 순서가 뒤집힙니다. 휴대폰에서는 목록 위의 정렬 기준과 화살표 버튼을 씁니다. 제목을 누르면 이 화면 안에서 패널로 열리고, **원래 대화로**는 그 아티팩트를 만든 대화로 이동합니다. 삭제하면 버전 기록까지 함께 삭제되지만 대화는 유지됩니다.
