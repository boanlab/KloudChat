# 아티팩트

보고서(웹·한글·Word), 슬라이드(웹·PowerPoint), 차트, 코드, 웹 페이지, 이미지 등 대화에서 생성된 것을 아티팩트라고 합니다. 아티팩트는 사이드바의 **아티팩트** 화면에 모입니다.

![아티팩트 갤러리](/img/guide/artifacts.png)

## 아티팩트 패널

- 아티팩트가 생성되면 패널이 자동으로 열립니다. 닫은 경우 대화 화면 오른쪽 위의 **보고서 열기**, **덱 열기** 등의 버튼으로 다시 엽니다.
- 공통 기능으로 버전과 수정 시각 표시, 복사, 다운로드, 너비 조절(더블클릭 시 초기화), 좁게·넓게·문서만 보기, 닫기를 제공합니다. 화면이 좁으면 대화 위에 겹쳐서 표시됩니다.
- 코드와 웹 페이지는 **미리보기**와 **소스** 탭, 확대·축소를 지원합니다. 웹 페이지는 격리된 창에서 실행되므로 값을 저장하는 기능은 동작하지 않습니다.
- 챗에서도 "표로 정리해 문서로 만들어 주세요", "이 데이터로 차트를 그려 주세요"와 같이 요청하면 아티팩트가 패널에 생성됩니다.

## 형식별 편집기

웹 보고서와 웹 슬라이드는 [아티팩트 편집기](editor)(리본)에서 엽니다. 한글, Word, PowerPoint 아티팩트는 각자의 편집기(HWP 편집기, 리본이 있는 Word 편집기, PowerPoint 편집기)에서 열립니다. 자세한 내용은 [한글(HWP) 문서](hwp), [Word 문서](docx), [PowerPoint 문서](pptx)를 참고하십시오.

## 내보내기 형식

| 종류 | 형식 |
|---|---|
| 웹 보고서 | PDF, Word(DOCX), 한글(HWPX), 마크다운 원문, 인쇄 |
| 웹 슬라이드 | PowerPoint(PPTX), PDF, 텍스트(노트 포함) |
| 한글·Word·PowerPoint 문서 | 편집기의 **내려받기**(HWPX·HWP, DOCX, PPTX) |
| 템플릿을 적용한 문서 | PDF, DOCX/PPTX, HWPX, HTML, 텍스트 |

PDF는 테마를 그대로 반영하고, DOCX와 PPTX는 편집 가능한 구조를 우선하므로 템플릿의 시각적 요소가 일부 달라질 수 있습니다.

## 갤러리

사이드바의 **아티팩트**에서 전체 목록을 확인합니다. 종류별 탭(전체, 코드, HTML, 보고서, 슬라이드, 차트, 이미지, 오디오, 동영상)과 제목 검색을 제공합니다. 탭은 계열로 묶입니다. **보고서** 탭에는 웹 보고서·한글·Word가, **슬라이드** 탭에는 웹 슬라이드·PowerPoint가 함께 나오며, 그 아래 형식 줄에서 **모든 형식**이나 형식별(개수 표시)로 좁힙니다. 한글·Word·PowerPoint 전용 탭은 없습니다. 카드를 선택하면 갤러리 안에서 패널로 열리고, 생성된 대화로 이동하려면 카드의 **원본 작업 열기**를 사용합니다. 갤러리에서 삭제하면 버전 기록까지 함께 삭제되지만 대화는 유지됩니다.
