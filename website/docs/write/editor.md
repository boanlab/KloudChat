# 아티팩트 편집기

웹 보고서와 웹 슬라이드는 오른쪽 패널에서 직접 편집할 수 있습니다. 두 패널 모두 머리에 제목, 판 번호(v), **저장 안 됨** 표시, **저장**, **내려받기**, 공유 아이콘, ⋯ 메뉴, 너비 조절·닫기 버튼이 있습니다. 화면이 좁으면 공유가 ⋯ 메뉴로 들어갑니다. 휴대폰 너비에서는 읽기만 되고, 고치기는 대화에서 요청합니다([요청으로 수정](revise)).

한글, Word, PowerPoint 아티팩트는 이 편집기가 아니라 각자의 편집기에서 열립니다. [한글(HWP) 문서](hwp), [Word 문서](docx), [PowerPoint 문서](pptx)를 참고하세요.

## 보고서 패널

머리의 **웹뷰**와 **페이지뷰**(A4 실제 쪽) 버튼으로 보기 방식을 바꿉니다. **검토** 버튼은 근거 패널을 열고 닫으며, **편집** 버튼은 편집 리본을 엽니다.

### 읽는 상태에서 고치기

- 절 제목 옆 **절 편집** 메뉴: 앞·뒤에 절 추가, 이 절 복제, 위·아래로 옮기기, 이 절 지우기, **이 절만 다시 쓰기**, **검토**. **검토**는 절의 주장을 근거와 대조하는 팩트체크입니다. 마지막 한 절은 지울 수 없습니다. **이 절만 다시 쓰기**에 지시문을 적으면 그 내용대로, 비워 두면 처음부터 다시 씁니다.
- 본문의 문장을 선택하면 **이 부분 고치기**가 나타나, 선택한 대목을 인용해 고칠 방법을 적어 요청합니다.
- ⋯ 메뉴: **목차**(절별 진행 상황), **원문 편집**, **버전 기록**.

### 편집 리본

**편집**을 누르면 **홈 · 삽입 · 레이아웃 · 검토 · 보기** 탭이 열립니다. 페이지에서 직접 입력하며 `Ctrl+S`(또는 **저장**)로 저장합니다.

| 탭 | 기능 |
|---|---|
| 홈 | 실행 취소·다시 실행, 굵게·기울임·취소선·코드·링크, 글머리 기호·번호 매기기·할 일 목록, 들여쓰기·내어쓰기, 인용, 스타일(본문·절 제목·소제목·작은 제목), 찾기 및 바꾸기, **Markdown 원문**(문서 전체를 마크다운으로 편집) |
| 삽입 | 표(행·열 추가·삭제), 그림 파일, 도식(mermaid), 코드 블록, 출처 인용 번호, 빈칸 넣기, 구분선, 쪽 나누기, **만든 그림** |
| 레이아웃 | **모양**(편집형·매거진형·미니멀), **강조색**, **페이지 설정**(머리말, 꼬리말, 쪽 번호, 여백) |
| 검토 | **문서 검사**, **근거**(출처 패널), **단계**, **버전**, 검토 메모(선택한 문장에 메모) |
| 보기 | **문서 개요**, **Markdown 원문** |

- **만든 그림**은 넣을 절과 그림 생성 방식(그림을 만들어 넣기 또는 이미 만든 이미지 고르기)을 정해 넣습니다. 그림은 파일에 포함되어 인쇄와 공유에도 함께 갑니다. 이미지 기능이 꺼져 있으면 새로 만들 수 없습니다.
- 프로젝트 전체의 모양은 [디자인 지침](../personal/projects.md#디자인-지침)에 적습니다.

### 내려받기

**내려받기**에서 PDF, Word 문서(DOCX), 한글 문서(HWPX), 마크다운 원문을 고르고, **인쇄**도 같은 메뉴에 있습니다. 근거가 확인되지 않은 항목이 있으면 메뉴에 **내보내기 전 근거 확인** 안내가 붙습니다.

## 슬라이드 패널

슬라이드 목록이 왼쪽에, 선택한 장이 가운데에, 발표 노트가 그 아래에 있고, 위쪽에 도구 막대가 있습니다.

### 도구 막대

실행 취소·다시 실행, 확대/축소, **레이아웃**, **이미지**, **표**, **차트**가 있습니다. 글꼴, 글꼴 크기, 굵게·기울임꼴·밑줄, 텍스트 색상, 서식 지우기, **모양**, **발표**도 있습니다.

- **레이아웃**: 장의 모양을 기본 모양과 용도별 패턴(격자·카드, 목록, 흐름·단계, 비교·분석, 수치·차트, 한 문장) 중에서 고릅니다. 바꾼 모양에 보이지 않게 된 내용은 지우지 않고 보관하며, **다음 장으로 옮기기**로 꺼낼 수 있습니다.
- **이미지**: **그림 올리기**(PNG, JPG, GIF, WebP, 5MB 이하)와 **그림 넣기·바꾸기**(이미지 모델)가 있습니다. 전체 표시·영역 채우기, 크기(작게·보통·크게), 왼쪽·오른쪽 배치, 그림 제거도 합니다. 자동 생성된 도식은 이미지 모델이 그린 그림으로 바꿀 수 있습니다(**그림 모델로 바꾸기**).
- **모양**: 편집형, 미니멀, 포스터형, 분할형, 다크, 강철, 따뜻한, 파스텔, 숲, 학술, 흑백 중에서 고릅니다. 강조색을 바꾸고, 선택한 장만의 강조색을 정하거나 **이 장 서식 초기화**를 할 수 있습니다. **여러 장 서식**은 여러 장을 골라 강조색과 글자 크기(80~120%)를 한 번에 바꿉니다.
- 슬라이드의 글자를 눌러 직접 고칩니다. 슬라이드 아래의 텍스트 상자는 한 번에 훑어 고칠 때 쓰며, 첫 줄이 제목, 나머지 줄이 항목이고 `|`로 나눈 줄은 표의 한 행입니다. 표·지표·카드 장은 데이터 편집 영역에서 행과 열을 고치고, 차트 장은 종류(막대·꺾은선), 단위, 계열을 고칩니다.
- 장 목록에서 끌어 순서를 바꾸고, 장 메뉴로 앞·뒤 추가, 복제, 이동, 삭제를 합니다. `Ctrl+S`로 저장합니다.

### 검토와 ⋯ 메뉴

**검토**(⋯ 메뉴 또는 도구 막대)는 검토 창을 엽니다. 창에는 **확인 필요 n장**, **잘림 위험 n장**, 자동 검사·검토 받기, 단계, 버전과 함께 장별 **검토 메모**가 있습니다. ⋯ 메뉴에는 그 밖에 **발표**, **이 장 다시 만들기**, **이 장 팩트체크**, **버전 기록**이 있습니다.

### 내려받기

**내려받기**에서 PowerPoint(PPTX), PDF(발표용), 텍스트(노트 포함)를 고릅니다. 잘림 위험, 근거 확인 필요, 미해결 검토 메모가 있으면 메뉴에 건수가 표시됩니다. **발표**는 [발표 모드](slides#발표-모드)로 들어갑니다.

## 검토

| 기능 | 내용 |
|---|---|
| 자동 검사 | 모델을 호출하지 않고 문서를 검사합니다. 반드시 고쳐야 할 항목(P0: 빈 내용, 작성되지 않은 블록, 자리표시자, 렌더되지 않은 마크다운, 한국어 문장에 섞인 한자, 근거 없는 수치, 산술 오류, 본문 대신 남은 작성 계획·지시문)이 있으면 **고칠 곳 n**, 살펴볼 항목(P1: 군더더기 표현, 이모지로 시작하는 문장, 반복된 줄, 한 장에 줄이 너무 많음, 두 행을 넘는 줄)만 있으면 **볼 곳 n**으로 표시합니다. 항목마다 **고치기**, 둘 이상이면 **모두 고치기**가 있습니다. |
| 검토 받기 | 모델을 한 번 호출해 문서를 읽고 10점 만점의 점수와 최대 6개의 지적 사항을 냅니다. 점수는 참고용이며 내보내기를 막지 않습니다. 산수는 지적하지 않습니다. |
| 팩트체크 | 보고서는 절 메뉴의 **검토**, 슬라이드는 **이 장 팩트체크**로 주장을 근거와 대조합니다. 근거 주소가 없는 판정은 **확인 필요**로 낮추고, 의견과 정의는 판정하지 않습니다. |
| 근거 패널 (보고서) | 출처 목록, 인용 점검, 인용 형식(APA, MLA, Chicago, IEEE), 참고 자료 직접 추가, 미사용 자료 삭제, 조사 기록(검색어·채택·제외)을 보여 줍니다. |
| 검토 메모 | 보고서는 문장을 선택해 메모를 남기고, 슬라이드는 장마다 메모를 달아 **해결로 표시**하거나 다시 엽니다. 미해결 메모는 개수가 표시됩니다. |

## 버전 관리와 충돌 처리

저장, 다시 쓰기, 복원이 실행될 때마다 이전 판이 저장됩니다. ⋯ 메뉴의 **버전 기록**(보고서는 리본 **검토 → 버전**)에서 이전 판의 내용과 변경 내역을 보고 되돌립니다.

다른 곳에서 같은 문서가 먼저 저장되었으면 저장하지 않고 알려 줍니다. **내 편집 내려받기**로 지금 편집을 받거나 **최신 판 불러오기**를 선택합니다.
