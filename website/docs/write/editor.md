# 결과물 편집기

보고서와 슬라이드는 오른쪽 패널에서 직접 편집할 수 있습니다. 상단 리본의 탭에 따라 기능이 구분됩니다.

## 보고서 패널

리본은 **홈 · 편집 · 삽입 · 레이아웃 · 검토 · 보기 · 파일** 로 구성됩니다.

### 편집

- **문서 수정**: 페이지에서 직접 편집합니다. 굵게, 기울임, 밑줄, 취소선, 글자색, 형광펜, 줄간격, 목록과 들여쓰기, 인용, 표 삽입 및 행·열 조작과 병합, 쪽 나누기, 출처 인용 삽입, 찾기 및 바꾸기, 실행 취소를 지원합니다.
- **원문**: 마크다운 전체를 편집합니다. `Ctrl+Enter` 로 저장합니다.
- 절 제목 옆 메뉴에서 앞·뒤 절 추가, 복제, 위·아래 이동, 삭제, **이 절만 다시 쓰기**, 검토를 수행합니다. 마지막 한 절은 삭제할 수 없으며, **이 절만 다시 쓰기**에 지시문을 입력하면 해당 절만 다시 작성합니다.
- 본문의 문장을 선택하면 **이 부분 고치기**가 표시됩니다. 선택한 문장을 인용해 수정을 요청합니다.

### 삽입

**그림 넣기**에서 삽입할 절, 그림 생성 방식(새로 생성 또는 기존 그림 선택), 캡션을 지정합니다. 삽입한 그림은 파일에 포함되므로 인쇄와 공유에도 함께 전달됩니다. 이미지 기능이 비활성 상태이면 새로 생성할 수는 없습니다.

### 레이아웃

페이지 설정(머리말, 꼬리말, 쪽 번호), 문서 디자인(편집형, 매거진형, 미니멀), 강조색, 양식(서식) 변경을 제공합니다.

### 보기

**웹뷰**와 **페이지뷰**(A4 실제 쪽)를 전환하고 목차 창에서 진행 상황과 단어 수를 확인합니다. 넓게 보기, 문서만 보기, 패널 닫기는 리본이 아니라 패널 오른쪽 위의 버튼에서 선택합니다.

### 파일

PDF, Word(DOCX), 한글(HWPX), 마크다운 원문, 인쇄로 내보냅니다.

## 슬라이드 패널

리본은 **홈 · 편집 · 삽입 · 검토 · 보기 · 슬라이드 쇼 · 파일** 로 구성됩니다.

### 홈

슬라이드 디자인을 편집형, 미니멀, 포스터형, 분할형, 다크, 강철, 따뜻한, 파스텔, 숲, 학술, 흑백 중에서 선택하고, 강조색을 변경하며, **이 장 다시 만들기**를 실행합니다.

### 편집

- 슬라이드의 문자를 클릭해 직접 수정합니다. 굵게, 기울임, 크기, 색상을 지정할 수 있습니다.
- 텍스트 상자 일괄 편집에서는 첫 줄이 제목, 각 줄이 항목이 되며 `|` 로 표의 행을 구분합니다.
- 발표 노트, 표 데이터 편집(행·열 추가·이동·삭제), 차트 편집(막대·꺾은선, 단위, 계열)을 제공합니다.
- 그림 도구에서 이미지를 업로드하고(PNG, JPG, GIF, WebP, 5MB 이하) 표시 방식, 크기, 좌우 배치를 지정합니다.
- 내용이 넘칠 때 자동 맞춤, 장 나누기, 레이아웃 변경, 글자 크기 조정, 실행 취소를 지원합니다. `Ctrl+S` 로 저장합니다.
- 장 메뉴에서 앞·뒤 추가, 복제, 이동, 삭제, 레이아웃, 글자 크기를 설정합니다. 여러 장을 선택해 강조색과 글자 크기를 일괄 변경하거나 서식을 초기화할 수 있습니다.

### 삽입

그림 넣기와 바꾸기, 자동 생성된 도식을 이미지 모델이 그린 그림으로 교체하는 기능을 제공합니다.

### 보기와 슬라이드 쇼

장 목록 창과 장 이동을 제공합니다. 발표 모드는 [슬라이드 작성](slides#발표-모드)을 참고하십시오.

### 파일

PowerPoint(PPTX), PDF, 텍스트(노트 포함)로 내보내며 대본 복사를 지원합니다.

## 검토

| 기능 | 내용 |
|---|---|
| 자동 검사 | **고쳐야 함**(빈 내용, 작성되지 않은 블록, 자리표시자, 근거 없는 수치, 산술 오류)과 **살펴볼 것**(군더더기 표현, 이모지로 시작하는 문장, 반복된 줄, 두 행을 넘는 줄)을 검출해 **고치기** 또는 **모두 고치기**로 수정합니다. 슬라이드는 **잘림 위험 n장**을 별도로 안내합니다. |
| 검토 받기 | 모델이 문서를 한 번 읽고 10점 만점의 점수와 최대 6개의 지적 사항을 제시합니다. 점수는 참고용이며 내보내기를 제한하지 않습니다. |
| 팩트체크 | 절 또는 장의 주장을 근거와 대조합니다. 근거 주소가 없는 판정은 **확인 필요**로 낮춥니다. 의견과 정의는 판정 대상에서 제외합니다. |
| 근거 패널 (보고서) | 출처 목록, 인용 점검, 인용 형식(APA, MLA, Chicago, IEEE), 자료 직접 추가, 미사용 자료 삭제, 조사 기록(검색어, 채택, 제외)을 제공합니다. |
| 검토 메모 (슬라이드) | 장별 메모를 추가하고 해결 또는 재개 처리합니다. 미해결 메모가 있으면 배지로 표시됩니다. |

## 버전 관리와 충돌 처리

저장, 다시 쓰기, 복원이 실행될 때마다 스냅샷이 저장됩니다. 리본 **검토 → 버전 기록**에서 이전 판의 내용을 확인하고 추가·삭제·수정 내역을 비교한 뒤 되돌릴 수 있습니다.

다른 창에서 같은 문서를 수정한 경우 **최신본 불러오기** 또는 **내 편집 내용 복사** 중에서 선택하도록 안내합니다.

## 서식 적용 문서의 편집 제한

서식을 적용한 보고서와 슬라이드는 블록 단위 다시 쓰기만 지원하며 마크다운 원문 편집은 제공하지 않습니다. 내보내기 형식은 PDF, DOCX/PPTX, HWPX, HTML, 텍스트입니다.
