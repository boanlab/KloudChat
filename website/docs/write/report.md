# 보고서 작성

홈에서 **보고서**를 선택하고 작성할 보고서의 주제를 입력합니다. 근거 자료가 있으면 입력창의 **+** → **파일·사진 첨부**로 올리십시오. 자료를 첨부하면 수치를 추정하지 않고 자료에 있는 값으로 채웁니다. 문서는 질문한 언어로 씁니다. 영어 메모만 붙여 넣으면 영어로, "아래 메모로 회의록을 만들어줘"처럼 한국어로 요청하면 자료가 영어여도 한국어로 쓰고, 마친 뒤의 답도 문서의 언어로 드립니다. 에이전트에 출력 언어를 정해 두었으면 그 언어를 따릅니다. 검색 서버가 연결된 환경에서는 작성 전에 웹을 검색해 출처를 인용합니다. 국내 연구 동향이나 KCI를 언급한 요청은 같은 검색으로 KCI·DBpia·RISS 논문도 찾아 저자·연도·학술지·DOI를 함께 적습니다.

## 형식과 템플릿 고르기

홈과 빈 보고서 대화(새 대화, 프로젝트나 에이전트에서 연 대화, 기록에서 다시 연 대화)에서는 입력창 위에 칩이 나타납니다.

- **형식** 칩: **웹 보고서**, **한글**, **Word** 중에서 고릅니다. 웹 보고서는 리본으로 고치는 HTML 문서입니다. 한글이나 Word를 고르면 그 파일을 대화 옆의 [한글](hwp)·[Word](docx) 편집기에 씁니다. 한글이나 Word를 고르면 **빈 문서로 시작** 단추가 나타납니다. 주소 `/new/report?format=hwp`로 열면 형식이 미리 골라져 있습니다.
- **템플릿** 칩: 고른 템플릿의 이름(없으면 **기본값**)을 보여 주고, 누르면 템플릿 갤러리가 열립니다. 칩의 × 를 누르면 템플릿 없이 시작합니다. 프로젝트의 기본 템플릿이 미리 골라집니다.

## 1단계: 구성 확인

문서를 바로 작성하지 않고 **구성**을 먼저 제시합니다. 작성에 필요한 정보가 부족하면 구성보다 앞서 **시작하기 전에** 카드가 나타나 확인 질문을 표시합니다. 답변하거나 **있는 자료로 진행**을 선택하면 구성 단계로 넘어갑니다.

![구성 확인 카드](/img/guide/proposal-card.png)

- 절 제목을 수정하고 순서를 변경하거나 절을 추가·삭제할 수 있습니다. 고친 뒤에는 **처음 제안으로**로 되돌릴 수 있습니다.
- 구성 카드의 **형식**에서 웹 보고서, 한글, Word 중 하나로 바꿀 수 있습니다. 바꾼 형식은 **이대로 생성**을 누를 때 적용됩니다. 웹 보고서의 테마는 작성 후 리본의 **편집 → 테마**에서 고릅니다.
- **이대로 생성** 또는 수정한 경우 **고친 대로 생성**을 누르면 작성이 시작됩니다.
- 카드 아래 입력창에 문장을 입력하면 그 내용을 조건으로 구성을 다시 제안합니다. 승인은 버튼으로만 가능합니다.
- 도식이나 그림이 필요한 주제이면 이어서 **그림을 넣을까요?** 카드가 표시됩니다. 장수와 예상 크레딧이 함께 안내되며, 도식(흐름도·구조도)은 텍스트 모델이 흐름을 쓰고 서버가 도형으로 그리므로 이미지 크레딧이 발생하지 않습니다. 그림은 이미지 모델이 그립니다.

## 2단계: 작성

절 단위로 순서대로 작성하며, 첫 절이 완성되는 즉시 오른쪽 패널에 표시합니다. 작성에 실패한 절은 실패로 표시하고 나머지 절의 작성을 계속합니다.

![작성된 보고서](/img/guide/report.png)

한글이나 Word를 고른 보고서는 완성된 파일이 대화 옆 편집기에 나타나며, 같은 편집기에서 이어서 고칩니다. 이하는 웹 보고서의 모습입니다.

기본 모양은 공식 문서 형식입니다. 본문은 양쪽 정렬, 강조색은 남색이며, 과장된 표현 없이 근거와 함께 씁니다. 수치는 그 수치를 쓰는 문장과 표에 두고, 끝에 따로 모은 수치 띠는 넣지 않습니다. 색과 테마는 리본의 **편집 → 테마**에서 바꿀 수 있습니다.

## 3단계: 수정

두 가지 방법을 제공합니다.

- **요청으로 수정**: 문서 하단 입력창에 "2번 절을 절반으로 줄여 주세요", "절을 하나 추가해 주세요"와 같이 입력합니다. [요청으로 수정](revise)
- **직접 편집**: 패널의 리본에서 문장을 수정하고, 절 순서를 바꾸고, 그림을 넣고, 검토를 받습니다. [아티팩트 편집기](editor)

## 요청문에 지정할 수 있는 항목

| 입력 예시 | 반영 내용 |
|---|---|
| "4개 절로" | 절 수를 지정합니다. 3~12절 범위입니다. |
| "검토 보고서", "주간 보고", "회의록", "장애 보고" | 문서 종류에 맞는 구성을 적용합니다. 판단을 요구하는 문서에만 요약과 권고 절이 포함됩니다. |
| **템플릿** 칩에서 템플릿 선택(메시지가 있는 대화에서는 **+** → 템플릿 고르기) | 해당 템플릿의 구성 규칙과 조판을 적용합니다. |

## 내보내기

리본의 **파일 → 내보내기**에서 PDF, Word(DOCX), 한글(HWPX), 마크다운 원문, 인쇄를 선택합니다. 근거가 확인되지 않은 항목이 있으면 내보내기 전에 안내합니다. PDF는 테마를 그대로 반영하고, DOCX는 편집하기 좋은 구조를 우선합니다.
