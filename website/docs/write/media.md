# 이미지와 오디오/동영상

관리자가 활성화한 경우에만 홈 화면에 **이미지**와 **오디오/동영상** 탭이 표시됩니다. 대부분 외부 생성 서비스를 사용하므로 크레딧이 소모되며, 전송 전에 예상 크레딧이 안내됩니다. 파일 첨부는 지원하지 않습니다.

## 이미지

입력창 아래의 옵션으로 지정합니다.

| 칩 | 선택지 |
|---|---|
| 비율 | 16:9 · 9:16 · 4:3 · 1:1 (모델이 지원하는 것만) |
| 스타일 | 자동 · 도식 · 인포그래픽 · 차트 · 사진 · 일러스트 · 미니멀 · 3D 렌더 · 수채화 · 없음 |
| 글자 | 자동 · 한국어 · 영어 · 없음 |
| 장수 | 1 · 2 · 4 |

결과 카드에서 확대 보기, 내려받기, **다시 만들기**, **프롬프트 고치기**, **보낸 프롬프트 보기**(실제 전송된 최종 문장)를 제공합니다. 도식 유형은 텍스트 모델이 생성하며 **그린 코드 보기** 와 **이 코드로 다시 그리기** 를 사용할 수 있습니다. 비율 지정을 지원하지 않는 모델을 선택하면 정사각형으로 생성된다는 안내가 표시됩니다.

**이미지 서식** 14종(도식, 표지, 포스터 등)은 항목만 입력하면 요청문과 옵션을 구성합니다. 프로젝트 디자인 시스템의 색상과 이미지 스타일이 요청문에 함께 반영됩니다.

## 오디오

내레이션(목소리 선택) 또는 음악을 15초, 30초, 60초, 120초 길이로 생성합니다. 결과는 재생기와 내려받기로 제공하며 내레이션은 대본이 함께 표시됩니다. 오디오는 생성 1회 단위로 과금됩니다.

## 동영상

비율, 해상도(720p 또는 1080p), 소리 유무, 길이(4~10초)를 지정합니다. 영상 생성은 시간이 오래 걸리므로 카드에 진행률이 표시되며, 화면을 새로 고치거나 다른 기기에서 접속해도 완료된 결과를 확인할 수 있습니다. 생성을 취소할 수 있으며 크레딧은 완료된 경우에만 차감됩니다. 모델이 가격을 산정하지 않는 조합을 선택하면 "이 모델은 이 조합을 만들지 않습니다"라는 안내가 표시되고 전송이 차단됩니다. 디자인 시스템은 오디오와 동영상에 적용되지 않습니다.
