# 이미지와 오디오/동영상

관리자가 활성화한 경우에만 홈 화면에 **이미지**와 **오디오/동영상** 탭이 표시됩니다. 대부분 외부 생성 서비스를 사용하므로 크레딧이 소모되며, 전송 전에 예상 크레딧이 안내됩니다. 파일 첨부는 지원하지 않습니다.

## 이미지

입력창 아래의 옵션으로 지정합니다.

| 칩 | 선택지 |
|---|---|
| 비율 | 16:9 · 9:16 · 4:3 · 1:1 (모델이 지원하는 것만) |
| 스타일 | **이미지**: 자동 · 사진 · 일러스트 · 인포그래픽 · 수채화<br/>**정확한 도식**: 구조도 · 흐름도 · 개념도 · 차트<br/>프롬프트 그대로 |
| 글자 | 자동 · 한국어 · 영어 · 없음 |

한 번에 한 장을 만듭니다. **이미지** 묶음은 이미지 모델이 그리고, **정확한 도식** 묶음은 이미지 모델을 쓰지 않고 도형이나 차트로 그려 글자가 정확합니다. **프롬프트 그대로** 는 입력한 문장을 고치지 않고 이미지 모델에 보냅니다.

이미지 모델은 입력창 오른쪽의 모델 이름에서 고릅니다. 목록은 모델 게이트웨이에 등록된 모델로 정해지며, 기본 구성의 외부 이미지 모델은 Seedream 5.0 Flash, Recraft V4.1, Grok Imagine Image 2.0, GPT-5.4 Image 2, Gemini 3 Pro Image입니다. 관리자가 자체 호스팅 이미지 모델을 연결하면 strict-local 이미지 모델도 나옵니다. 프로젝트 대화, 첨부가 있던 대화, strict-local 대화의 그림은 strict-local 모델로만 그립니다. [개인정보 보호](../privacy)

결과 카드에서 확대 보기, 내려받기, **다시 만들기**, **프롬프트 고치기**, **보낸 프롬프트 보기**(실제 전송된 최종 문장)를 제공합니다. 차트는 텍스트 모델이 코드로 그리며 **그린 코드 보기** 와 **이 코드로 다시 그리기** 를 사용할 수 있습니다. 비율 지정을 지원하지 않는 모델을 선택하면 정사각형으로 생성된다는 안내가 표시됩니다.

### 이미지 고치기

만든 이미지, 대화에 첨부한 이미지, 파일함의 이미지에서 **이미지 고치기** 를 누르면 그 이미지가 입력창에 붙습니다. 바꿀 내용을 적어 보내면 새 버전이 만들어지고 원본은 그대로 남습니다. 결과에서 **전후 비교** 로 원본과 겹쳐 보고, **버전** 에서 앞의 버전을 엽니다.

고치기는 이미지를 받아 고칠 수 있는 모델만 하며, 모델 목록에 **고치기 가능** 으로 표시됩니다. 기본 구성에서는 Gemini 3 Pro Image, GPT-5.4 Image 2, Seedream 5.0 Flash, Grok Imagine Image 2.0입니다. 그리기만 하는 모델(Recraft V4.1, strict-local 이미지 모델)을 고르면 버튼이 꺼지고 이유가 표시되며, **고칠 수 있는 모델로 바꾸기** 로 바꿀 수 있습니다. 원본 이미지는 첨부 파일처럼 외부 모델로 보내집니다. strict-local 대화의 이미지와, 관리자가 내부 자료를 strict-local로만 처리하게 한 경우의 올린 이미지는 고칠 수 없습니다. 크레딧은 이미지를 만들 때와 같이 차감됩니다. 영역을 골라 그 부분만 고치는 기능은 없습니다.

**구조도 · 흐름도 · 개념도** 는 이미지 모델을 쓰지 않습니다. 텍스트 모델이 설명을 흐름도로 쓰고, 서버가 보고서·슬라이드의 도식과 같은 도형으로 그려 그림으로 남깁니다. 단계가 너무 많거나 흐름도로 옮길 수 없는 내용이면 "이 도식은 그릴 수 없습니다. 단계를 줄여 다시 시도해 주세요." 라는 안내가 표시되고 그림은 만들어지지 않습니다.

이미지·오디오·동영상에는 양식이 없습니다. 입력창 위의 **형식** 칩은 보고서와 슬라이드에만 있습니다. 프로젝트나 에이전트의 [디자인 지침](../personal/projects.md#디자인-지침)에 적은 색과 스타일은 이미지 요청문에 함께 반영됩니다.

## 오디오

내레이션(목소리 선택) 또는 음악을 15초, 30초, 60초, 120초 길이로 생성합니다. 결과는 재생기와 내려받기로 제공하며 내레이션은 대본이 함께 표시됩니다. 오디오는 생성 1회 단위로 과금됩니다.

## 동영상

비율, 해상도(720p 또는 1080p), 소리 유무, 길이(4~10초)를 지정합니다. 영상 생성은 시간이 오래 걸리므로 카드에 진행률이 표시되며, 화면을 새로 고치거나 다른 기기에서 접속해도 완료된 결과를 확인할 수 있습니다. 생성을 취소할 수 있으며 크레딧은 완료된 경우에만 차감됩니다. 모델이 가격을 산정하지 않는 조합을 선택하면 "이 모델은 이 조합을 만들지 않습니다"라는 안내가 표시되고 전송이 차단됩니다. 디자인 지침은 오디오와 동영상에 적용되지 않습니다.
