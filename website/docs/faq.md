# 자주 묻는 질문

증상별로 원인과 조치를 정리했습니다. 화면에 표시된 오류 문구로 찾으려면 [제한 사항과 문제 해결](limits)을 참고하십시오.

### 가입 후 로그인되지 않습니다
승인 대기 상태입니다. 관리자가 승인하면 대기 화면이 자동으로 전환됩니다. 대기 화면의 **관리자에게 문의**를 사용해 문의하십시오.

### 챗에 입력했는데 보고서 화면으로 전환됩니다
"보고서를 작성해 주세요", "발표자료를 만들어 주세요"처럼 문서 작성을 요청하는 문장은 해당 화면의 새 대화로 자동 전환됩니다. 챗에서 이어가려면 "요약해 주세요"와 같이 기존 내용을 다루는 형태로 요청하거나 시작점을 사용하십시오.

### 첨부한 파일을 읽지 못한다고 표시됩니다
문자 정보가 없는 스캔 이미지이거나 구형 오피스 형식(.doc, .ppt, .xls)입니다. 문자가 포함된 PDF, Word, 한글, Excel, 텍스트 파일로 다시 첨부하십시오. [파일 첨부](chat/files)

### 첨부한 파일을 다음 질문에서 참조하지 못합니다
같은 챗 대화에서는 계속 참조됩니다. 답변의 작업 단계에 "이전 턴 첨부"가 표시되는지 확인하십시오. 다른 대화와 보고서·슬라이드 화면은 이전 첨부를 가져오지 않습니다. 파일 분량이 많으면 질문과 관련된 부분만 전달되므로 찾으려는 내용을 구체적으로 기술하십시오.

### 답변 내용이 사실과 다릅니다
모델이 알지 못하는 내용을 생성했을 수 있습니다. 웹 검색을 **켬**으로 설정하거나 근거 자료를 첨부하십시오. 답변에 출처가 표시되지 않았다면 검색을 거치지 않은 답변입니다. [모델의 한계](limits#모델의-한계)

### 답변이 너무 짧습니다
서론과 반복 설명을 생략하도록 설계되어 있습니다. 요청에 "자세히", "예시를 포함해"와 같은 조건을 덧붙이거나 설정의 **답변 방식**에 원하는 분량을 기술하십시오.

### 보고서 표에 (미정)이 표시됩니다
실험 기록, 주간 보고 등 일부 시작점은 자료에 없는 수치를 생성하지 않고 비워 둡니다. 근거 자료를 첨부해 다시 요청하거나 편집기에서 직접 입력하십시오.

### 장 수를 늘려 달라고 요청했으나 반영되지 않습니다
"20장으로 늘려 주세요"와 같이 요청하면 구성을 다시 제안한 뒤 승인을 받아 작성합니다. 반영되지 않으면 "20장으로 새로 만들어 주세요"와 같이 새로 요청하십시오.

### 다른 기기에서 로그인하면 모델이 다르게 표시됩니다
홈에서 선택한 모델은 계정에 저장되어 모든 기기에서 동일하게 적용됩니다. 대화 중에 선택한 모델은 해당 대화에만 적용됩니다. 설정 → 환경설정에서 화면별 기본 모델을 확인하십시오.

### 웹 검색을 껐는데 새 대화에서 자동으로 돌아옵니다
검색 모드는 요청 단위로 적용되므로 새 대화에서는 **자동**으로 초기화됩니다. 커넥터의 활성화 상태만 계정 전체에 유지됩니다.

### 공유 링크를 전달받은 사람이 열지 못합니다
**계정이 있는 사람**으로 생성한 링크는 로그인해야 열람할 수 있습니다. 외부 사용자에게 전달하려면 **링크가 있는 사람**으로 다시 생성하십시오. 철회했거나 대화를 삭제한 링크는 열리지 않습니다.

### 생성에 시간이 오래 걸립니다
보고서는 절 단위로, 슬라이드는 장 단위로 순차 작성합니다. 브라우저를 닫아도 서버에서 생성이 계속되므로 이후에 다시 접속해 결과를 확인할 수 있습니다.

### 크레딧은 무엇입니까
모델 사용량을 나타내는 단위입니다. **무료**로 표시된 모델은 크레딧을 소모하지 않습니다. [사용량과 대화 기록](personal/usage-history#크레딧)

### 관리자가 대화 내용을 볼 수 있습니까
대화 내용을 조회하는 관리자 화면은 제공하지 않습니다. 관리자는 사용량과 접속 기록만 확인할 수 있습니다. 공유 링크를 생성하면 설정한 범위의 사용자가 해당 대화를 열람할 수 있습니다.
