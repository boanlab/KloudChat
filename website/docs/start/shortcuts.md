# 키보드 단축키

화면 어디에서든 `Ctrl+/` 를 누르면 전체 목록을 확인할 수 있습니다. macOS에서는 `Ctrl` 대신 `⌘` 를 사용합니다. 모바일 화면에서는 단축키를 제공하지 않습니다.

![단축키 목록](/img/guide/shortcuts.png)

## 전역 단축키

| 기능 | 단축키 |
|---|---|
| 새 대화 열기 | `Ctrl+Shift+O` |
| 입력창으로 이동 | `Shift+Esc` |
| 대화 검색 | `Ctrl+K` |
| 사이드바 접기·펴기 | `Ctrl+Shift+S` |
| 마지막 답변 복사 | `Ctrl+Shift+C` |
| 마지막 코드 블록 복사 | `Ctrl+Shift+;` |
| 개인 맞춤 설정 열기 | `Ctrl+Shift+I` |
| 말로 쓰기 시작·종료 | `Ctrl+Shift+M` |
| 대화 삭제 | `Ctrl+Shift+⌫` |
| 단축키 목록 표시 | `Ctrl+/` |

## 입력창

| 기능 | 단축키 |
|---|---|
| 전송 | `Enter` |
| 줄 바꿈 | `Shift+Enter` |
| 말로 쓰기 | 빈 입력창에서 `Space` 를 누른 채 말하고, 떼면 즉시 전송 |

## 문서 편집기와 발표 모드

| 기능 | 단축키 |
|---|---|
| 저장 | `Ctrl+S` |
| 원문 편집 저장 | `Ctrl+Enter` |
| 장 이동 (발표 모드) | `←` `→` |
| 발표 노트 표시 | `N` |
| 발표 모드 종료 | `Esc` |
