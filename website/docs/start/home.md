# 홈 화면 구성

로그인하면 홈 화면이 열립니다. 왼쪽 사이드바에서 지난 대화를 찾고, 가운데 영역에서 새 작업을 시작합니다.

![홈 화면](/img/guide/home.png)

## 사이드바

| 영역 | 설명 |
|---|---|
| 검색 | 지난 대화를 **제목**으로 검색합니다. 단축키 `Ctrl+K`. |
| 새 대화 | 홈 화면으로 이동해 새 작업을 시작합니다. 단축키 `Ctrl+Shift+O`. |
| 프로젝트 · 아티팩트 | 자료를 묶어 둔 작업 공간과 생성된 아티팩트 갤러리로 이동합니다. |
| 대화 목록 | **고정됨**, **작업 목록**(최근 대화), **이전 대화 … 더 보기** 순으로 표시됩니다. 아이콘으로 종류를 구분하며, 항목의 `…` 메뉴에서 이름 바꾸기, 고정, 프로젝트에서 빼기, 삭제를 수행합니다. |
| 이번 달 크레딧 | 남은 사용량입니다. 누르면 사용량 화면으로 이동합니다. **무료**로 표시된 모델은 크레딧을 소모하지 않습니다. |
| 계정 메뉴 | 사용자 지정(에이전트·묶음, 스킬, 커넥터), 대화 기록, 계정(연동 안내, 사용량, 설정 — 메모리·테마 포함, 단축키), 관리자 메뉴, 로그아웃. |

## 화면 선택과 입력창

**챗 · 보고서 · 슬라이드** 중 사용할 화면을 선택하고 요청 내용을 입력합니다. 관리자가 활성화한 경우 **이미지**와 **오디오/동영상**도 선택할 수 있습니다. 챗은 질의응답이며, 보고서와 슬라이드는 구성을 먼저 확인한 뒤 문서를 작성합니다.

:::tip 챗에서 문서 작성을 요청한 경우
챗에서 "보고서를 작성해 주세요", "발표자료를 만들어 주세요"와 같이 문서 작성을 요청하면 **해당 작업의 새 대화로 자동 전환됩니다.** 에이전트 대화, 그리고 "요약해 주세요", "검토해 주세요"처럼 기존 내용을 다루는 요청은 챗에 그대로 남습니다.
:::

### 입력창의 기능과 적용 범위

![입력창](/img/guide/composer.png)

| 기능 | 설명 | 적용 범위 |
|---|---|---|
| **+** | 첨부, 템플릿 고르기, 스킬, 웹 검색, 커넥터, 에이전트를 한곳에 모은 메뉴입니다. 휴대폰에서는 아래쪽 시트로 열립니다. | — |
| 첨부 | 파일을 올립니다. 끌어다 놓기와 붙여넣기도 지원합니다. | 해당 대화 전체 |
| 템플릿 고르기 | 보고서·슬라이드의 결과 템플릿을 선택합니다. 챗·이미지·오디오/동영상에는 없습니다. | 해당 대화 |
| 스킬 | 요청에 적용할 스킬을 최대 3개까지 선택합니다. | 해당 요청 |
| 웹 검색: 자동 · 항상 · 끔 | 웹 검색 모드를 고릅니다. **항상**이나 **끔**이면 입력창에 칩으로 표시됩니다. | 해당 요청. 새 대화는 자동으로 초기화 |
| 커넥터 | 설치한 커넥터를 켜고 끕니다. | 계정 전체 |
| 에이전트 | 에이전트를 선택해 해당 에이전트와 새 대화를 시작합니다. | — |
| 🎤 말로 쓰기 | 음성을 문자로 변환합니다. 관리자가 음성 전사를 연결한 경우에만 표시됩니다. | 해당 입력 |
| 모델 이름 ▾ | 사용할 모델을 선택합니다. | 홈에서 선택하면 계정 기본값, 대화 중 선택하면 해당 대화 |
| ↑ · ■ | 전송하거나 생성을 중지합니다. | — |

입력창 위에는 현재 적용된 항목(프로젝트, 템플릿, 스킬, 첨부 파일, Auto 상태)이 칩으로 표시되며 × 로 해제합니다.

## 예시 요청과 진행 중인 작업

- **예시 요청**: 고른 화면(챗·보고서·슬라이드 등)에 맞는 예시 요청이 표시됩니다. 누르면 입력창에 채워지기만 하고 전송되지는 않습니다. 에이전트는 입력창의 **+** → **에이전트**에서 고릅니다. [에이전트와 스킬](../chat/agents)
- **진행 중**: 영상 생성처럼 시간이 오래 걸리는 작업이 실행 중일 때 표시됩니다.

## 오른쪽 위 버튼

**공유**(대화 화면), **앱 설치**(지원하는 브라우저에서 바로가기 앱으로 설치), **EN**(언어 전환), 테마 전환 버튼이 있습니다. 테마는 시스템, 밝게, 어둡게 순으로 전환됩니다.

## 모바일 화면

입력창의 **+** 를 누르면 첨부, 템플릿 고르기, 스킬, 웹 검색, 커넥터, 에이전트가 아래쪽 시트로 열립니다. 답변의 처리 내역은 "처리 내역 n건"으로 접혀 표시됩니다.
