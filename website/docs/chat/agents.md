# 에이전트와 스킬

에이전트는 역할, 지침, 도구, 자료가 미리 구성된 도우미입니다. 영어회화 튜터, 회의록 정리, 논문 리뷰어처럼 특정 업무에 맞춰 설계되어 있습니다.

![에이전트 선택 메뉴](/img/guide/at-menu.png)

## 에이전트로 대화 시작

홈의 **에이전트에게 맡기기** 카드, 입력창의 **@**, 에이전트 목록의 **실행** 중 어느 쪽을 선택해도 해당 에이전트와 새 대화가 시작됩니다.

- 대화 첫 화면에 에이전트의 **사용법**과 **시작 문장**(최대 6개)이 표시됩니다. 시작 문장을 누르면 그대로 전송됩니다.
- 에이전트 대화는 에이전트에 지정된 모델, 도구, 자료를 사용합니다. 자료가 등록되어 있으면 모델이 **자료 찾기** 도구로 검색합니다. 요청마다 자료 전체를 전달하지는 않습니다.
- 같은 프로젝트 안에서는 에이전트가 **노트 공유**로 남긴 결론을 다른 대화가 참조합니다.

기본으로 제공하는 에이전트는 다음과 같습니다.

| 분야 | 에이전트 |
|---|---|
| 학습·과제 | 학습 튜터, 과제 코치, 발표 코치, NCS 문제풀이 코치 |
| 연구 | 논문 리뷰어, 논문 집필 도우미, 연구 설계 조언자, 데이터 해석 도우미 |
| 업무 | 업무 보고서 작성자, 경영진 브리핑, 회의록 정리, 기술 컨설턴트, 장애 분석가 |
| 어학 | 영어회화 튜터, TOEIC 마스터, OPIc 마스터 |

## 에이전트 생성

계정 메뉴 → **에이전트** → 새로 만들기 순으로 진행합니다.

![에이전트 목록](/img/guide/agents.png)

1. 이름, 설명, **사용할 화면**(챗, 보고서, 슬라이드 등)을 지정합니다.
2. **시스템 프롬프트**에 수행할 역할과 방식을 기술하고, **사용법**과 **시작 문장**을 입력합니다.
3. 모델(화면 기본값 또는 지정), 온도(챗에만 적용), **도구 권한**(사용자 도구 상속 · 도구 없음 · 직접 선택), 연결할 스킬을 설정합니다.
4. **자료**에 파일을 올리거나 웹 주소를 등록합니다. 웹 주소는 등록 시점의 내용을 저장합니다. 색인 상태(벡터 또는 낱말)가 표시되며 **색인하기**로 다시 색인할 수 있습니다.
5. **공개 범위**를 **나만 쓰기** 또는 **모두에게 공개** 중에서 선택합니다. 공개하는 경우 **가져가서 편집할 수 있게** 와 **가져갈 수 있지만 내용은 비공개** 중 하나를 지정합니다.

활성화 토글로 일시적으로 사용을 중지할 수 있습니다. 삭제하면 자료와 색인이 함께 삭제되며 기존 대화는 유지됩니다.

## 워크스페이스 스토어

에이전트 목록의 **워크스페이스 스토어** 탭에서 다른 사용자가 공개한 에이전트를 확인할 수 있습니다. **공식** 배지는 관리자가 공개한 항목입니다. **가져오기**를 누르면 **사본**이 내 목록에 생성됩니다.

- 사본에는 원작자의 스킬과 지식 파일이 포함되지 않습니다.
- "내용은 비공개"로 공개된 에이전트의 사본은 편집할 수 없으며, 원본이 변경되면 사본에도 그대로 반영됩니다.
- 그 외의 사본은 독립적으로 관리되므로 원본이 변경되어도 영향을 받지 않습니다.

## 스킬

스킬은 **해당 요청에만** 적용하는 작업 방식입니다. 입력창의 ✦ 에서 최대 3개까지 선택하며, 전송하면 해제됩니다. 설치만 해서는 적용되지 않습니다. 인용 형식 맞추기, 계산·단위 검증, 비교표 만들기, NCS 조건·풀이 점검, 논문 구조, 한 장 요약 등이 제공됩니다.

![스킬 화면](/img/guide/skills.png)

- 계정 메뉴 → **스킬**에서 설치와 사용 중지, 직접 만들기(이름, 설명, 사용 시점, 절차, 필수 도구, 공개 범위)를 수행합니다. 공개한 스킬은 스토어에 등록되며 다른 사용자는 사본으로 가져갑니다.
- 도구가 필요한 스킬은 챗 화면에서, 모델 비교 중이 아니고, 도구 호출을 지원하는 모델을 사용하며, 해당 도구가 연결된 경우에만 활성화됩니다. 조건을 충족하지 못하면 사유가 표시됩니다.
- 프로젝트에 **추천 스킬**을 지정하면 해당 프로젝트의 입력창에서 우선 표시됩니다.
