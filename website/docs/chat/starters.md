# 시작점·서식·디자인

이름이 비슷한 세 가지 기능으로, 역할과 적용 범위가 각각 다릅니다.

| 구분 | 역할 | 선택 위치 | 적용 범위 |
|---|---|---|---|
| **시작점** | 반복 업무에 필요한 항목을 묻는 카드입니다. 입력한 내용으로 요청문을 구성합니다. | ▦ 작업 시작하기, 홈의 "자주 하는 일로 시작하기" | 해당 요청 |
| **서식** | 결과물의 형식입니다. 보고서 11종, 슬라이드 7종, 이미지 14종 등이 제품에 내장되어 있습니다. | ▦ 작업 시작하기 → 결과 서식, 계정 메뉴 → 디자인 → 서식 탭 | 해당 대화. 칩의 × 로 해제 |
| **디자인 시스템** | 색상, 서체, 문체를 묶은 설정입니다. 프로젝트에 연결합니다. | 계정 메뉴 → 디자인 | 해당 프로젝트의 모든 결과물 |

## 시작점

카드를 선택하면 입력창 위에 제목, 대상, 자료 등의 항목이 표시됩니다. 입력한 내용이 요청문 앞에 추가되며, 웹 검색이나 파일이 필요한 시작점을 선택하면 해당 기능이 자동으로 켜지거나 첨부하라는 안내가 표시됩니다. 양식 파일이 포함된 시작점은 선택 시 그 파일이 자동으로 첨부됩니다.

- 챗, 보고서, 슬라이드에 걸쳐 78개의 시작점이 내장되어 있습니다. 개념 정리, 자료 검토, 원인 분석, 주간 보고, 회의록 등이 포함됩니다.
- **내 시작점 만들기**에서 이름, 설명, 분류, 입력 항목, 예시, 필요한 기능, 모델에게만 전달할 지시문, 양식 파일을 설정할 수 있습니다.
- 관리자가 등록한 시작점은 **공용**으로 표시됩니다.
- 실험 기록, 주간 보고 등 일부 시작점은 자료에 없는 수치를 생성하지 않고 **(미정)** 으로 표시합니다.

## 서식

보고서와 슬라이드의 구성 규칙과 조판을 정의합니다. 선택하면 **이 서식이 확인하는 것** 점검 항목이 표시됩니다. 서식을 적용한 문서는 블록 단위로 다시 쓰는 방식으로 편집하며 PDF, DOCX/PPTX, HWPX, HTML, 텍스트로 내보낼 수 있습니다. 서식은 제품에 내장되어 있어 새로 만들 수는 없습니다.

## 디자인 시스템

계정 메뉴 → **디자인**에서 관리합니다.

![디자인 시스템 화면](/img/guide/designs.png)

- 이름, 강조색·본문색·보조색, 서체(고딕 또는 명조), 문체 규율, 이미지 스타일, 함께 적용할 규칙을 설정합니다.
- **문서에서 가져오기**를 사용하면 기존 hwpx, docx, pdf 파일이나 웹 주소에서 초안을 추출합니다. 모델을 한 번 호출하며, 저장 전에 내용을 확인할 수 있습니다.
- 문체는 대화·보고서·슬라이드에, 색상과 서체는 슬라이드와 보고서 표지에, 이미지 스타일은 이미지에 적용됩니다. 오디오와 동영상에는 적용되지 않습니다.
- 디자인 설정은 생성 시점에 결과물에 복사됩니다. 이후 디자인을 변경해도 이미 생성된 결과물은 바뀌지 않습니다.
- 관리자는 **모든 사용자에게 제공**으로 읽기 전용 공용 디자인을 배포할 수 있습니다.
