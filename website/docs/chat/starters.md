# 양식·디자인

이름이 비슷한 두 가지 기능으로, 역할과 적용 범위가 다릅니다. 자주 하는 일은 [에이전트](agents.md)와 워크플로에 맡깁니다.

| 구분 | 역할 | 선택 위치 | 적용 범위 |
|---|---|---|---|
| **양식** | 결과물의 형식입니다. 보고서 8종과 슬라이드 7종이 제품에 내장되어 있습니다. | 입력창 **+** → 양식 고르기, 사용자 지정 → 양식 탭 | 해당 대화. 칩의 × 로 해제 |
| **디자인** | 색상, 서체, 문체를 묶은 설정입니다. 프로젝트에 연결합니다. | 사용자 지정 → 디자인 탭 | 해당 프로젝트의 모든 결과물 |

## 양식

보고서와 슬라이드의 구성 규칙과 조판을 정의합니다. 선택하면 **이 양식이 확인하는 것** 점검 항목이 표시됩니다. 양식을 적용한 문서는 블록 단위로 다시 쓰는 방식으로 편집하며 PDF, DOCX/PPTX, HWPX, HTML, 텍스트로 내보낼 수 있습니다. 양식은 제품에 내장되어 있어 새로 만들 수는 없습니다. 이미지·오디오·동영상에는 양식이 없습니다.

## 디자인

**사용자 지정** → **디자인** 탭에서 관리합니다. 다른 사람이 공유한 디자인은 같은 탭의 **탐색**에 나옵니다.

![디자인 화면](/img/guide/designs.png)

- 이름, 강조색·본문색·보조색, 서체(고딕 또는 명조), 문체 규율, 이미지 스타일, 함께 적용할 규칙을 설정합니다.
- **문서에서 가져오기**를 사용하면 기존 hwpx, docx, pdf 파일이나 웹 주소에서 초안을 추출합니다. 모델을 한 번 호출하며, 저장 전에 내용을 확인할 수 있습니다.
- 문체는 대화·보고서·슬라이드에, 색상과 서체는 슬라이드와 보고서 표지에, 이미지 스타일은 이미지에 적용됩니다. 오디오와 동영상에는 적용되지 않습니다.
- 디자인 설정은 생성 시점에 결과물에 복사됩니다. 이후 디자인을 변경해도 이미 생성된 결과물은 바뀌지 않습니다.
- 관리자는 **모든 사용자에게 제공**으로 읽기 전용 공용 디자인을 배포할 수 있습니다.
