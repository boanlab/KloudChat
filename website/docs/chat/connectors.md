# 커넥터

커넥터는 모델이 호출할 수 있는 외부 도구(MCP 서버)입니다. 계정 메뉴 → **커넥터**에서 설치하고, 입력창의 🔌 에서 켜고 끕니다. 켜고 끈 상태는 **계정 전체**에 적용됩니다.

![커넥터 화면](/img/guide/connectors.png)

## 기본 제공 커넥터

| 커넥터 | 기능 |
|---|---|
| 시간 | 현재 시각과 날짜를 조회합니다. 챗, 보고서, 슬라이드에서 사용할 수 있습니다. |
| YouTube 전사 | 영상의 자막을 가져옵니다. 자막이 없으면 음성을 전사합니다. |
| 심층 리서치 | 검색과 페이지 읽기를 반복하며 조사합니다. 수 분에서 수십 분이 소요되며, 관리자가 심층 조사 서버를 연결한 경우에만 제공됩니다. |

## 서버 직접 추가

사용 중인 MCP 서버가 있으면 **서버 직접 추가**로 연결합니다. 이름, 전송 방식(stdio · http · sse), 실행 명령 또는 엔드포인트 주소, 환경 변수, 인증 방식을 입력합니다. 환경 변수와 자격증명은 저장 후 다시 표시되지 않습니다.

## 도구 권한

커넥터 상세 화면에서 도구별로 사용 여부를 설정합니다. 데이터를 변경하는 **쓰기** 도구는 실행 전에 확인을 요청합니다. 커넥터가 반환한 내용은 외부 입력으로 취급하므로 그 안에 포함된 지시문은 실행하지 않습니다.

활성화한 도구가 많을수록 모델이 적절한 도구를 선택할 확률이 낮아지므로, 실제로 사용하는 도구만 활성화하십시오.
