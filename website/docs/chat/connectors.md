# MCP 서버

MCP 서버는 모델이 호출할 수 있는 외부 도구입니다. **사용자 지정** → **MCP 서버**에서 설치하고, 입력창의 **+** → **MCP 서버**에서 켜고 끕니다. 켜고 끈 상태는 **계정 전체**에 적용됩니다.

![MCP 서버 화면](/img/guide/connectors.png)

## 기본 제공 MCP 서버

관리자가 **기본 제공**으로 정한 MCP 서버는 모든 사용자에게 미리 설치되어 **내 MCP 서버**에 「기본 제공」 배지와 함께 나옵니다. 쓰지 않으려면 스위치로 끄거나 도구별로 끕니다. 기본 제공 MCP 서버는 지울 수 없고, 끈 MCP 서버는 다시 켜면 그대로 돌아옵니다.

| MCP 서버 | 기능 |
|---|---|
| 시간 | 현재 시각과 날짜를 조회합니다. 챗, 보고서, 슬라이드에서 사용할 수 있습니다. |
| YouTube 전사 | 영상 주소를 주면 자막을 가져오고, 자막이 없으면 음성을 전사합니다. 챗, 보고서에서 사용할 수 있습니다. |
| 심층 리서치 | 웹을 여러 번 검색하고 읽어 조사 결과를 정리합니다. 수 분이 걸릴 수 있습니다. 챗, 보고서에서 사용할 수 있습니다. |

## 스토어에서 가져오기

**탐색**에는 다른 사람이 공유한 MCP 서버가 나옵니다. 관리자가 공유한 서버에는 「공식」 배지가, 그 밖의 서버에는 공유한 사람의 이름이 붙습니다. **추가**를 누르면 내 MCP 서버에 들어옵니다. 서버가 자격(키나 토큰)을 요구하면 설치하기 전에 입력 창이 열리고, 각자 자기 값을 넣습니다. 값은 서버에만 보관하며 다시 보여 주지 않습니다.

가져온 서버는 사본이 아니라 **공유한 서버를 가리키는 연결**입니다. 주소와 도구는 공유한 서버를 그대로 따르므로, 상세 화면에는 주소 대신 「○○님이 공유한 서버」가 나옵니다. 도구를 켜고 끄는 것과 내 자격 수정은 내 몫입니다. 공유한 사람이 공유를 끊으면 「공유가 끝나 쓸 수 없습니다」로 바뀌며, 이때는 **제거**만 할 수 있습니다. 관리자가 스토어 목록에서 숨긴 서버도 이미 가져온 사람에게는 그대로 동작합니다.

## 서버 직접 추가

사용 중인 MCP 서버가 있으면 **서버 직접 추가**로 연결합니다. 이름, 전송 방식(http · sse), 엔드포인트 주소, 환경 변수, 인증 방식을 입력합니다. 환경 변수와 자격증명은 저장 후 다시 표시되지 않습니다. 명령으로 실행하는 서버(stdio)는 API 서버에서 돌기 때문에 관리자만 등록할 수 있습니다. 관리자가 아닌 사람이 추가하는 서버는 인터넷에 공개된 주소여야 합니다. `localhost`·`127.0.0.1`, 사설 대역(`10.x`, `172.16~31.x`, `192.168.x`), 클라우드 메타데이터 주소, 배포 내부 서비스 이름처럼 내부 네트워크를 가리키는 주소는 저장할 때와 호출할 때 모두 거절됩니다.

## 내 MCP 서버 공유하기

내가 추가한 서버는 상세 화면의 **공유**에서 **공유 안 함** 또는 **우리 조직과 공유**를 고릅니다. 공유하면 스토어(**탐색**)에 올라가 다른 사람이 가져다 씁니다. http · sse 서버만 공유할 수 있습니다.

- 공유해도 내 환경 변수 값은 다른 사람이 쓰지 않습니다. 받는 사람이 각자 자격을 넣도록 **받는 사람이 직접 넣을 자격**에 키 이름, 화면에 보일 이름, 설명, 비밀 값 여부를 적어 둡니다(최대 8개).
- 공유한 서버를 쓰는 사람이 있으면 상세 화면에 사용하는 사람 수가 나옵니다. 공유를 끊으려 하면 「○명이 쓰고 있어, 끊으면 그분들의 이 서버가 멈춥니다」라고 먼저 묻습니다.
- 공유한 서버는 공유를 끊은 뒤에만 삭제할 수 있습니다.

관리자가 추가한 서버에는 공용 환경 변수 값, 도구 주소 키, **모두에게 기본 제공**, **스토어에 보이기**를 정하는 칸이 더 있습니다.

## 도구 권한

MCP 서버 상세 화면에서 도구별로 사용 여부를 설정합니다. 데이터를 변경하는 **쓰기** 도구는 실행 전에 확인을 요청합니다. MCP 서버가 반환한 내용은 외부 입력으로 취급하므로 그 안에 포함된 지시문은 실행하지 않습니다.

활성화한 도구가 많을수록 모델이 적절한 도구를 선택할 확률이 낮아지므로, 실제로 사용하는 도구만 활성화하세요.
