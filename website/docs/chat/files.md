# 파일 첨부

입력창의 📎 로 파일을 첨부하면 모델이 파일 내용을 근거로 답변합니다. 여러 파일을 한 번에 첨부할 수 있으며 끌어다 놓기와 붙여넣기를 지원합니다. 이미지와 오디오/동영상 화면에서는 첨부를 제공하지 않습니다.

![첨부 문서를 근거로 답변한 대화](/img/guide/chat-with-file.png)

## 첨부 가능한 형식

| 분류 | 형식 | 조건 |
|---|---|---|
| 문서 | PDF, Word(.docx), 한글(.hwp, .hwpx), PowerPoint(.pptx), Excel(.xlsx) | 텍스트가 포함된 파일이어야 합니다. 스캔 이미지는 인식하지 못합니다. |
| 텍스트·코드 | .txt, .md, .csv, .tsv, .json 및 대부분의 코드 파일 | 텍스트로 읽습니다. |
| 이미지 | PNG, JPG, GIF, WebP | **4MB 이하**이며 이미지 인식을 지원하는 모델(목록의 👁)에서만 전달됩니다. |
| 음성·영상 | mp3, wav, mp4 등 | **25MB 이하**이며 관리자가 음성 전사를 연결한 경우 문자로 변환해 읽습니다. |

파일 하나의 최대 크기는 200MB입니다. 구형 오피스 형식(.doc, .ppt, .xls)은 지원하지 않습니다. 읽지 못한 파일은 답변의 작업 단계에 **읽지 못한 첨부**로 표시됩니다.

## 첨부 파일의 참조 범위

첨부한 파일은 해당 대화의 이후 요청에서도 계속 참조됩니다. 작업 단계에 **이전 턴 첨부**로 표시됩니다.

- 파일 분량이 한 번에 처리할 수 있는 범위를 넘으면 **질문과 관련된 부분**을 선별해 전달합니다. "제7조의 내용을 알려 주세요"와 같이 요청하면 해당 조항 주변이 전달됩니다.
- 전달된 범위에 답이 없으면 모델이 **자료 찾기** 도구로 파일 내부를 검색합니다.
- 반영 정도는 작업 단계의 첨부 파일 항목에 반영, 잘림, 빠짐으로 표시됩니다.

보고서와 슬라이드 화면은 이전 요청의 첨부를 가져오지 않으므로, 문서 작성에 사용할 자료는 해당 요청에 직접 첨부해야 합니다. 다른 대화에 첨부한 파일도 참조되지 않습니다. 여러 대화에서 동일한 자료를 사용하려면 [프로젝트](../personal/projects)에 등록하십시오.

## 인식 정확도 향상 요령

- 찾으려는 내용을 구체적으로 지정하십시오. "이 파일을 요약해 주세요"보다 "이 파일에서 재택근무 신청 절차만 정리해 주세요"가 정확합니다.
- 표가 많은 자료는 PDF보다 Excel이나 CSV 형식으로 첨부해야 정확하게 인식됩니다.
- 첨부한 한글 파일(.hwpx)은 파일 칩의 **문서로 열기**를 누르면 편집 가능한 보고서로 바로 변환됩니다. 변환할 때 모델을 호출하지 않으므로 크레딧도 소모되지 않습니다.

## 이미지 첨부

이미지는 이미지 인식을 지원하는 모델에만 전달됩니다. 이미지 인식을 지원하지 않는 모델을 선택하면 파일은 첨부되지만 모델이 내용을 확인하지 못합니다. 이전 요청의 이미지는 다시 전송되지 않으므로, 같은 이미지에 대해 추가로 질문하려면 다시 첨부하십시오.
