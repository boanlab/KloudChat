# 챗봇 공개

대화로 답하는 에이전트를 **챗봇**으로 공개하면 다른 사람이 그 에이전트에게 물어볼 수 있습니다. 챗봇은 공개한 때의 지시·자료·검사로 고정되고, 이 기관의 내부 모델로만 답합니다. 답하는 데 드는 크레딧은 공개한 사람의 크레딧에서 나가며, 질문은 공개한 사람이 입력한 것과 같은 정책으로 처리됩니다.

## 공개하기

내 에이전트 화면 위쪽의 **챗봇으로 공개** 버튼. 공개 전에 다음을 확인합니다.

- 답할 내부 모델. 이 기관에 쓸 수 있는 내부 모델이 없으면 공개할 수 없습니다.
- 챗봇에서는 쓰지 않는 것: 내 메모리, 개인 맞춤 설정, 다른 파일·프로젝트, 커넥터, 웹 검색, 문서·발표 만들기, 스킬. 챗봇은 **자료 찾기**와 **계산**만 씁니다.
- 자료에서 개인정보로 보이는 값(휴대전화 번호, 이메일 등). 공개하기 전에 지우거나 확인합니다.

## 공개 범위

| 범위 | 누가 쓰나 | 열리는 때 |
|---|---|---|
| 구성원 공개 | 이 기관 구성원(로그인한 사람). 구성원에게는 **공유된 에이전트**로 보입니다 | 바로 |
| 링크 공개 | 주소를 아는 사람 누구나, 로그인 없이. 어떤 목록에도 나오지 않습니다 | 관리자가 승인한 뒤 |
| 외부 공개 | 누구나, 로그인 없이. 공개 챗봇 목록(`/b`)에 나오고 검색에도 잡힐 수 있습니다 | 관리자가 승인한 뒤 |

- 링크 공개나 외부 공개를 고르면 **하루 최대 크레딧**을 정해야 합니다. 그날 쓴 크레딧이 이 값에 이르면 챗봇은 다음 날까지 멈춥니다.
- 승인을 기다리는 동안에도 구성원은 바로 쓸 수 있습니다. 관리 화면 위쪽에 요청 상태가 보이고 **요청 취소**로 거둘 수 있습니다.
- 반려되면 관리자가 적은 사유가 관리 화면에 보입니다. 챗봇은 그 전 범위로 계속 답합니다.
- 범위를 좁히는 것(외부 공개 → 링크 공개 → 구성원 공개)은 승인 없이 바로 됩니다.

## 판과 승인

에이전트를 고친 뒤 관리 화면의 **버전** → **새 판 공개**를 눌러야 챗봇에 반영됩니다. 문제가 있으면 이전 판으로 되돌립니다.

로그인하지 않은 사람에게도 열린 챗봇은 새 판도 관리자가 확인한 뒤 답합니다. 그동안에는 승인된 판이 계속 답하고, 버전 목록에 새 판이 **승인 대기**로 보입니다. 승인된 적 있는 판으로 되돌리는 것은 바로 됩니다.

## 채널: 다른 사이트·API·MCP

로그인하지 않은 사람에게도 열린 챗봇은 챗봇 페이지 말고도 다음 채널로 쓸 수 있습니다. 관리 화면 **개요**의 **채널**에서 켜고 끕니다. 켜는 것은 관리자가 승인하면 열리고, 끄는 것은 바로 적용됩니다.

| 채널 | 무엇을 하나 | 쓸 수 있는 공개 범위 |
|---|---|---|
| 다른 사이트에 넣기 | 기관 홈페이지 같은 내 사이트에 대화창을 넣습니다 | 외부 공개 |
| API | 내 서비스나 프로그램에서 OpenAI 호환 방식으로 부릅니다 | 링크 공개, 외부 공개 |
| MCP | Claude 같은 AI 도구에 이 챗봇을 도구로 연결합니다 | 링크 공개, 외부 공개 |

- **다른 사이트에 넣기**: 넣을 사이트 주소(`https://`로 시작, 최대 10개)를 적어 요청합니다. 승인되면 나오는 삽입 코드 한 줄을 사이트의 `</body>` 앞에 붙이면 오른쪽 아래에 말풍선 버튼이 생기고, 누르면 대화창이 열립니다(휴대전화에서는 전체 화면). 승인된 사이트에서만 대화창이 보입니다. 사이트 안의 대화창은 늘 로그인하지 않은 방문자로 동작합니다.
- **API·MCP**: 관리 화면 **API** 탭에서 이 챗봇만 부를 수 있는 키를 만듭니다. 키는 만들 때 한 번만 보이니 바로 보관합니다. 쓰지 않는 키는 **폐기**하면 바로 막힙니다.
  - API는 `/api/bots/v1/chat/completions`에 `model`로 챗봇 주소를 넣어 부릅니다. 검사를 마친 답만 보내므로 `stream`을 켜도 답이 다 만들어진 뒤에 이어서 옵니다. 인용한 자료는 응답의 `kloudchat.citations`에 있습니다.
  - MCP는 `/api/bots/mcp/<챗봇 주소>`에 같은 키로 연결하고, `ask` 도구 하나를 씁니다.
  - 키로 부르는 질문은 키마다 분·하루 한도가 있고, 하루 최대 크레딧과 챗봇 전체 한도도 그대로 적용됩니다.
- **API** 탭과 **통계**에서 채널별 질문 수(챗봇 페이지, 다른 사이트, API, MCP)를 봅니다.
- 관리자가 외부 공개를 닫거나 공개 범위를 좁히면, 그 범위에서 쓸 수 없는 채널도 함께 닫힙니다.

## 만든 사람이 보는 것

관리 화면(내 에이전트 화면의 **챗봇** → **관리**)에는 다음이 보입니다.

- **통계**: 질문 수, 대화 수, 방문자 수, 자주 나온 주제, 답하지 못한 질문(개인정보를 가린 문장), 👍👎.
- **보낸 대화**: 방문자가 **만든 사람에게 보내기**로 보낸 대화만, 개인정보를 가린 채. **대화 열람**을 켠 챗봇은 방문자가 동의한 뒤의 대화도 보입니다. 상담·민원처럼 대화 기록이 업무인 챗봇에만 켭니다.
- 방문자는 이름 대신 「방문자 ABC123」처럼 보이고, 로그인했는지만 표시됩니다. 보낸 대화에서 **이 방문자 차단**을 누르면 그 방문자는 더 이상 질문할 수 없습니다. **설정**의 **차단한 방문자**에서 풉니다.

관리자가 남용 확인을 위해 대화를 열람하면 **개요**의 **관리자 열람 기록**에 날짜와 사유가 남습니다.

챗봇이 멈추거나(크레딧 소진, 관리자 중지 등) 관리자가 요청을 결정하면 사이드바 **사용자 지정**에 숫자가 붙습니다.

## 구성원 쪽에서

구성원 공개(외부 공개 포함)한 챗봇은 다른 구성원에게 에이전트로 보입니다. 따로 챗봇 메뉴는 없습니다.

- **사용자 지정** → **에이전트** → **탐색**의 **공유된 에이전트**에 만든 사람의 이름과 함께 나옵니다. 모두에게 공개한 에이전트도 같은 곳에 있고, 둘 다 해당하는 에이전트는 한 번만 나옵니다.
- 입력창 **+** → **에이전트**에서도 내 에이전트 아래 **공유된 에이전트**로 고릅니다.
- **체험**이나 이름을 누르면 챗봇 페이지에서 대화합니다. 답하는 데 드는 크레딧은 공개한 사람의 것입니다.
- **추가**를 누르면 공개된 판의 지시와 설정이 내 에이전트로 복사됩니다. 자료(지식 파일)는 오지 않습니다. 만든 사람이 지시를 비공개로 둔 에이전트는 복사할 수 없습니다.

## 방문자 쪽에서

- 첫 질문 전에 이용 안내를 읽고 시작합니다. 안내에는 대화 보관 기간과 대화 열람 여부가 적혀 있습니다.
- 로그인하지 않은 방문자는 이 브라우저의 쿠키로만 자기 대화를 이어 봅니다. 쿠키를 지우면 지난 대화를 다시 열 수 없습니다. 파일을 올리거나 아티팩트를 내려받을 수 없습니다.
- 질문 수는 한 사람당, 같은 주소(로그인하지 않은 방문자)당, 챗봇 전체로 분·하루 단위 한도가 있습니다. 한도는 관리 화면의 **설정** → **한도**에서 낮출 수 있습니다.
- 대화는 마지막 질문 뒤 보관 기간(기본 30일)이 지나면 지워집니다.
