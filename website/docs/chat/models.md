# 모델 선택

입력창 오른쪽의 모델 이름을 누르면 목록이 열립니다. 등록된 모델이 8개 이상이면 **모델 찾기** 검색창이 함께 표시됩니다.

![모델 선택 목록](/img/guide/model-picker.png)

## 모델 목록의 표시 항목

| 표시 | 의미 |
|---|---|
| **strict-local** | 기관 서버에서만 처리되며 외부로 전달되지 않는 것이 확인된 모델입니다. 선택하면 웹 검색, 페이지 읽기, 커넥터가 비활성화됩니다. |
| **self-hosted · strict 미확인** | 기관 서버에서 동작하지만 외부 대체 경로가 없다는 점이 확인되지 않은 모델입니다. |
| **외부 전환 가능** | 평소에는 기관 서버에서 처리하지만 장애 시 외부 서비스로 전환될 수 있습니다. |
| **외부 제공** | 외부 서비스가 제공하는 모델로, 요청이 기관 밖으로 전송됩니다. |
| **경계 미확인** | 처리 위치 정보가 제공되지 않은 모델입니다. |
| 가격 | 1,000 토큰당 입력·출력 크레딧 또는 **무료** |
| 컨텍스트 | 한 번에 처리할 수 있는 분량 |
| 👁 · 🔧 | 이미지 인식 지원 · 도구 호출 지원 |

게이트웨이 등록 방식에 따라 이름이 같은 모델이 데이터 경계 표시만 다른 두 항목으로 나타날 수 있습니다. 표시를 확인한 뒤 선택하십시오.

**외부 전환 가능** 모델이 장애로 응답하지 못해 게이트웨이의 대체 모델이 대신 답하면, 그 답 위에 **외부 대체로 답함** 배지가 붙습니다(대체 모델도 기관 서버의 모델이면 **대체 모델로 답함**). 배지에 마우스를 올리면 요청한 모델과 실제로 답한 모델이 보입니다. 같은 일은 관리자 감사 로그에 **대체 모델이 답함**으로 남습니다.

## Super Agent

목록 맨 위에 늘 두 항목이 있습니다. 모델이 아니라 대화에 적용하는 모드이며, 챗·보고서·슬라이드의 새 대화는 Super Agent로 시작합니다(관리자가 다른 기본값을 정했거나, 홈에서 모델을 골랐거나, 모델이 정해진 에이전트의 대화는 그 모델로 시작). 이 계정에서 쓸 수 있는 모델이 표에 없으면 그 항목은 보이지 않고 새 대화는 기본 모델로 시작합니다.

| 항목 | 동작 |
|---|---|
| Super Agent | 질문마다 작업 종류(간단한 질문, 번역·요약, 계산, 코드, 최신 정보 검색, 복잡한 추론 등)를 가려 알맞은 모델과 추론 강도를 고릅니다. 개인정보나 내부 자료가 있으면 기관 안의 모델을 씁니다. |
| Super Agent (strict-local) | 같은 방식으로 고르되 기관 안의 strict-local 모델만 씁니다. 질문과 자료가 밖으로 나가지 않으며 웹 검색은 쓰지 않습니다. |

각 항목 아래에 답 하나에 보통 드는 크레딧 범위가 표시됩니다. 답마다 「이번 답: 모델 · 작업 종류」와 그 이유가 처리 내역에 표시됩니다. 「다시」, 「더 자세히」라고 하면 더 강한 설정으로 다시 답하고, 같은 대화의 짧은 후속 질문과 같은 문서의 수정은 같은 모델이 이어 씁니다.

## 추론 칩

모델 이름 왼쪽의 **추론** 칩으로 답하기 전에 얼마나 생각할지 고릅니다. 챗, 보고서, 슬라이드에서 쓸 수 있습니다.

| 선택 | Super Agent | 직접 고른 모델 |
|---|---|---|
| **자동** (기본) | 질문마다 추론 강도를 정합니다. 계산·코드·최신 정보·긴 자료·복잡한 추론은 추론에 강한 모델이 높은 강도로 답합니다. | 모델에 설정된 기본 추론으로 답합니다. |
| **빠르게** | 추론 없이 바로 답합니다. 보고서와 슬라이드는 쓰던 모델 그대로 추론만 끕니다. 계산이나 복잡한 질문도 추론 모델로 올리지 않습니다. 그림이 있으면 그림을 읽는 모델처럼 다른 조건에 맞는 모델은 그대로 고릅니다. | 추론을 끕니다. 추론을 끌 수 없는 모델은 가장 낮은 강도로 답합니다. |
| **깊게** | 추론에 강한 모델이 높은 강도로 답합니다. Super Agent (strict-local)과 내부 자료가 있는 대화에서는 기관 안의 모델 중에서 고릅니다. 보고서와 슬라이드는 쓰던 모델을 그대로 쓰고 그 모델의 가장 높은 강도로 씁니다. | 모델이 낼 수 있는 가장 높은 강도로 답합니다. |

- 고른 값은 그 대화에 남습니다. 다시 열거나 다른 기기에서 열어도 같은 값으로 시작하고, **다시 생성**은 그 질문을 보낼 때의 값으로 다시 답합니다.
- 홈 화면에서 고르면 그 화면에서 새로 시작하는 대화에 적용됩니다.
- 추론 강도를 바꿀 수 없는 모델을 고르면 칩이 흐리게 표시되고 **모델 기본**으로 답합니다. 칩에 마우스를 올리면 이유가 보입니다.
- 답 아래 사용량 줄에 고른 값과 실제로 보낸 강도가 「깊게 · high」처럼 표시됩니다. **추론 켬**은 기관 서버 모델의 추론을 켠 경우, **모델 기본**은 강도를 따로 보내지 않은 경우입니다.
- 보고서와 슬라이드는 칩을 바꿔도 쓰는 모델이 바뀌지 않습니다. 처음 쓴 모델이 수정도 이어 쓰고, 그 모델이 추론을 조절할 수 없으면 사용량 줄에 「이 모델은 조절 불가」로 표시됩니다.
- **깊게**는 답이 늦어지고 외부 모델이면 크레딧이 더 들 수 있습니다. 보고서와 슬라이드는 여러 번 나눠 쓰므로 그 차이가 더 큽니다.

## 모델 선택의 적용 범위

- **홈에서 선택**하면 해당 화면(챗, 보고서, 슬라이드 등)의 **기본 모델**로 계정에 저장됩니다. 다른 기기에서 로그인해도 동일하게 적용되며, 설정 → 환경설정에서도 변경할 수 있습니다. Super Agent나 Super Agent (strict-local)도 모델처럼 고를 수 있으며, 고르면 새 대화가 그 항목으로 시작합니다.
- **대화 중에 선택**하면 해당 대화에만 적용됩니다.
- 에이전트 대화는 에이전트에 지정된 모델을 사용합니다. 모델을 지정하지 않은 에이전트(**기본 모델**)는 그 화면의 기본 모델을 따릅니다.
- 관리자가 계정별 허용 모델을 제한한 경우 허용된 모델만 표시됩니다.
