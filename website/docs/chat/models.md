# 모델 선택

입력창 오른쪽의 모델 이름을 누르면 목록이 열립니다. 등록된 모델이 8개 이상이면 **모델 찾기** 검색창이 함께 표시됩니다.

![모델 선택 목록](/img/guide/model-picker.png)

## 모델 목록의 표시 항목

| 표시 | 의미 |
|---|---|
| **strict-local** | 기관 서버에서만 처리되며 외부로 전달되지 않는 것이 확인된 모델입니다. 선택하면 웹 검색, 페이지 읽기, 커넥터가 비활성화됩니다. |
| **self-hosted · strict 미확인** | 기관 서버에서 동작하지만 외부 대체 경로가 없다는 점이 확인되지 않은 모델입니다. |
| **외부 전환 가능** | 평소에는 기관 서버에서 처리하지만 장애 시 외부 서비스로 전환될 수 있습니다. |
| **외부 제공** | 외부 서비스가 제공하는 모델로, 요청이 기관 밖으로 전송됩니다. |
| **경계 미확인** | 처리 위치 정보가 제공되지 않은 모델입니다. |
| 가격 | 1,000 토큰당 입력·출력 크레딧 또는 **무료** |
| 컨텍스트 | 한 번에 처리할 수 있는 분량 |
| 👁 · 🔧 | 이미지 인식 지원 · 도구 호출 지원 |

게이트웨이 등록 방식에 따라 이름이 같은 모델이 데이터 경계 표시만 다른 두 항목으로 나타날 수 있습니다. 표시를 확인한 뒤 선택하십시오.

**외부 전환 가능** 모델이 장애로 응답하지 못해 게이트웨이의 대체 모델이 대신 답하면, 그 답 위에 **외부 대체로 답함** 배지가 붙습니다(대체 모델도 기관 서버의 모델이면 **대체 모델로 답함**). 배지에 마우스를 올리면 요청한 모델과 실제로 답한 모델이 보입니다. 같은 일은 관리자 감사 로그에 **대체 모델이 답함**으로 남습니다.

## Super Agent

관리자가 켜 두면 목록 위쪽에 두 항목이 보입니다. 모델이 아니라 대화에 적용하는 모드입니다.

| 항목 | 동작 |
|---|---|
| Super Agent | 질문마다 작업 종류(간단한 질문, 번역·요약, 계산, 코드, 최신 정보 검색, 복잡한 추론 등)를 가려 알맞은 모델과 추론 강도를 고릅니다. 개인정보나 내부 자료가 있으면 기관 안의 모델을 씁니다. |
| Super Agent (strict-local) | 같은 방식으로 고르되 기관 안의 strict-local 모델만 씁니다. 질문과 자료가 밖으로 나가지 않으며 웹 검색은 쓰지 않습니다. |

각 항목 아래에 답 하나에 보통 드는 크레딧 범위가 표시됩니다. 답마다 「이번 답: 모델 · 작업 종류」와 그 이유가 처리 내역에 표시됩니다. 「다시」, 「더 자세히」라고 하면 더 강한 설정으로 다시 답하고, 같은 대화의 짧은 후속 질문과 같은 문서의 수정은 같은 모델이 이어 씁니다.

## 모델 선택의 적용 범위

- **홈에서 선택**하면 해당 화면(챗, 보고서, 슬라이드 등)의 **기본 모델**로 계정에 저장됩니다. 다른 기기에서 로그인해도 동일하게 적용되며, 설정 → 환경설정에서도 변경할 수 있습니다.
- **대화 중에 선택**하면 해당 대화에만 적용됩니다.
- 에이전트 대화는 에이전트에 지정된 모델을 사용합니다. 모델을 지정하지 않은 에이전트(**기본 모델**)는 그 화면의 기본 모델을 따릅니다.
- 관리자가 계정별 허용 모델을 제한한 경우 허용된 모델만 표시됩니다.
