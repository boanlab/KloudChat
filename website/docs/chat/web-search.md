# 웹 검색과 도구

입력창의 **+** 버튼에서 **웹 검색**을 **자동**, **항상**, **끔** 중 하나로 고릅니다. 기본은 **자동**이며, **항상**이나 **끔**을 고르면 입력창에 칩으로 표시됩니다. 설정은 해당 요청에만 적용되고 새 대화에서는 **자동**으로 초기화됩니다.

![입력창의 웹 검색 설정](/img/guide/composer.png)

| 모드 | 동작 |
|---|---|
| 자동 | 뉴스, 가격, 일정, 최신 버전, 날씨처럼 시간에 따라 변하는 정보와, 전화번호·상담 번호, 법·세율·기준 금액·지원 제도, 요금·금리·한도, 행사 일정, 판매·운영 여부, 기관, 통계처럼 정확해야 하는 정보를 물으면 먼저 검색합니다. 법률·세금·금융·건강 상담도 먼저 검색합니다. 그 외에는 모델이 필요하다고 판단한 경우에만 검색합니다. |
| 항상 | 해당 요청에 대해 반드시 검색을 수행합니다. |
| 끔 | "검색해서", "찾아봐"처럼 명시적으로 요청하지 않는 한 검색하지 않습니다. |

검색을 수행하면 답변에 `[n]` 형식의 번호와 출처 목록이 표시됩니다. 한 요청에서 검색은 최대 3회, 페이지 읽기는 최대 6회까지 수행합니다. 날씨는 검색 대신 전용 도구를 사용합니다. strict-local 모델을 선택하면 웹 검색을 고를 수 없습니다.

글쓰기, 번역·교정, 코드·엑셀 수식, 역할극, 개념 설명, 첨부하거나 붙여 넣은 자료에 대한 질문은 자동 모드에서 먼저 검색하지 않습니다. 회의 안건, 메일 초안, 교정·번역, 붙여 넣은 코드의 버그 수정처럼 내가 준 내용으로 만드는 일은 「최신」, 환율, 날씨처럼 찾아볼 것을 적지 않으면 자동 모드에서 검색하지 않습니다(그래도 검색하려면 **항상**). 앞선 대화에서 이어지는 질문(예: 투자 질문 뒤 「1년 안에 쓸 3천만 원이야」)은 대화 전체를 보고 판단합니다. "검색하지 마"라고 쓰거나 **끔**을 고르면 검색하지 않습니다.

최신 정보를 다루는 요청에는 검색이 필요합니다. "이번 분기 환율 추이", "Python 3.14의 변경 사항"이 이에 해당합니다. 계산, 번역, 첨부한 글의 요약, 코드 수정에는 검색이 필요하지 않으므로 **끔**으로 설정하면 응답이 빨라지고 불필요한 출처가 표시되지 않습니다.

## 법률·세금·금융·건강 질문의 근거 확인

법률, 세금, 금융, 건강·의료 상담에는 **근거 대조** 검사가 기본으로 적용됩니다. 답의 금액·비율·기준 금액, 전화번호·상담 번호, 약 용량, 처벌·벌금 같은 법적 결과가 이번 검색 결과나 사용자가 준 내용에 없으면 그 자리에 **(확인 필요)**가 붙습니다. 표시가 많으면 본문에서 빼고 답 끝에 「확인 필요: …」 한 줄로 모읍니다. 해야 할 일, 준비할 서류, 전문가에게 상담할 때 같은 안내는 그대로 둡니다. 검사 결과는 작업 단계의 **근거 확인(법률)** 같은 항목에 표시됩니다.

## 모델이 사용하는 도구

도구 호출을 지원하는 모델(목록의 🔧)은 요청에 따라 다음 도구를 사용합니다. 사용 내역은 작업 단계에 표시됩니다.

| 도구 | 기능 |
|---|---|
| 웹 검색 · 페이지 읽기 · 날씨 | 검색을 수행하고 필요한 페이지의 본문을 읽습니다. |
| 코드 실행 | 계산, 표 처리, 그래프 생성을 실제 코드로 수행합니다. 큰 수의 계산은 이 경로가 정확합니다. |
| 수치 검산 | 사칙연산과 거듭제곱을 서버에서 정확히 계산하고, 선지나 제출한 답과 대조합니다. 별도 서버 연결 없이 동작하며, 계산이 필요한 요청에서는 이 도구를 먼저 사용합니다. |
| 자료 찾기 | 첨부한 파일과 에이전트 자료 내부를 검색합니다. |
| 아티팩트 · 차트 만들기 | 결과를 오른쪽 패널의 문서나 차트로 생성합니다. |
| 노트 공유 | 같은 프로젝트의 다른 대화가 참조할 메모를 남깁니다. |
| 커넥터 | 사용자가 설치한 외부 도구입니다. [커넥터](connectors) |

관리자가 검색 서버나 코드 실행 서버를 연결하지 않은 환경에서는 해당 도구가 제공되지 않습니다.
