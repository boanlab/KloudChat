# 스킬로 일하고 에이전트 짜기

회의록·개조식 보고·비교·결정 같은 일은 **공식 스킬**로 합니다. 대화에서 스킬을 켜면 바로 그 일을 하고, 자주 하는 일은 스킬을 몇 개 묶어 내 에이전트로 만들어 둡니다. 따로 마련된 기본 에이전트는 없습니다.

## 공식 스킬

관리자가 모두에게 공개한 스킬입니다. 입력창의 **+** → **스킬** 아래 **공식 스킬**에 보이고, 고르면 내 스킬에 추가되면서 바로 켜집니다.

| 스킬 | 쓰는 화면 | 하는 일 |
|---|---|---|
| 회의록 작성 | 보고서 | 녹음 전사본·메모·후속 메일로 결정·실행 항목(할 일·담당·기한·출처·비고)·미결을 남깁니다. **회의록** 템플릿에 씁니다. 자료에 없는 회의 시간·기간·오전/오후·질문·추측·다음 회의 안건·「확정되는 대로 안내」 같은 약속, 메모가 열어 두지 않은 「담당자가 지정되지 않았습니다」·「배포 방법은 확인 필요」 같은 미결, 「…하는 것이 좋습니다」 같은 권고, 「미제출 시 …」 같은 결과, 다음 회의 안건 표, 표에 미정이 있는데 모두 정해졌다는 말과 아무에게도 맡겨지지 않은 할 일 행은 한 번 고치게 하고, 남으면 빼거나 「(확인 필요)」로 표시합니다. 메모의 「10시」 앞에 붙인 「오전」은 코드가 지웁니다. 자료에 없는 까닭·「알 수 없습니다」 같은 판단·작성 방식 메모도 고치게 하고, 남으면 빼거나 표시합니다. 메모가 준 일시·장소·참석자를 「자료에 없음」·「미정」이라 하면 메모의 값으로 채우고, 머리의 빈 칸은 메모의 값이나 「[장소]」 같은 빈칸으로 채우며, 결정 표에 빠진 결정은 행으로 더합니다. 열린 회의는 지난 일로 쓰고, 표가 메모의 날짜를 준 기한을 본문이 「미정」이라 하면 표의 날짜로 맞춥니다. |
| 개조식 보고 | 보고서 | 메모·메일을 윗사람이 한 장에서 판단할 □ ○ - ㆍ 개조식으로 바꿉니다. **개조식 보고서** 템플릿, 기본 1쪽. |
| 비교·결정 보고 | 보고서 | 대안 2~5개를 요청한 기준 그대로 견주고 하나를 권고합니다. **비교·분석 보고서** 템플릿. |
| 공문·기안 초안 | 보고서 | 계획서·결과 보고·기안·안내문 초안. 검색하지 않고, 그림은 요청할 때만 넣습니다. |
| 발표 자료 구성 | 슬라이드 | 한 장에 주장 하나, 결론을 맨 앞에 두는 발표 슬라이드. |
| 자료 추출·집계 | 대화 | 엑셀·CSV를 코드로 읽어 열을 뽑고 항목별로 집계한 표·차트를 만들고, 지우거나 바꾼 행을 남깁니다. |
| 규정 근거 답변 | 대화 | 규정·지침에서 근거 조항을 [n]으로 달아 답하고, 자료에 없으면 담당 부서로 안내합니다. |
| YouTube 영상 전사·요약 | 대화 | **YouTube 전사** 커넥터로 자막(없으면 음성 전사)을 받아 그 내용만으로 요약합니다. |
| 심층 조사 | 대화 | **심층 리서치** 커넥터로 웹·논문을 여러 번 찾아 출처가 달린 결과를 정리합니다. 몇 분 걸립니다. 요청에 「심층 리서치로」라고 적으면 자세한 조사(5~15분)로 돌고, 진행 단계에 빠른 조사·자세한 조사 중 어느 것이 돌았는지 표시됩니다. |
| 번역 | 대화·보고서 | 한국어↔영어(요청하면 다른 언어도)로 빠짐없이 옮깁니다. 이름·숫자·단위·표·목록·코드는 그대로, 같은 용어는 끝까지 같은 말로, 두 뜻으로 읽히는 곳만 「번역 메모」로 적습니다. 「직역」·「의역」, 「격식체」·「평어체」를 요청에 적으면 그대로 씁니다. |
| 보도자료 | 대화·보고서 | 제목·부제, 육하원칙 리드, 중요한 것부터 내려가는 본문, 기관 소개와 문의까지 갖춘 보도자료. 인용은 자료에 있는 사람의 발언만 쓰고(이름만 있으면 「가안」으로 표시한 인용문), 자료에 없는 수치는 넣지 않습니다. 배포일·보도 시점·문의처만 대괄호로 남겨 직접 채웁니다. 「A4 1장」·「800자 이내」처럼 분량을 적으면 맞춥니다. |
| 엑셀 파일 만들기 | 대화 | 붙여 넣은 표, 첨부한 CSV·엑셀, 계산한 표를 내려받을 수 있는 엑셀(.xlsx) 파일로 만듭니다. 합계 행과 합계·비율 같은 열은 수식으로 들어가고, 요청하면 엑셀 차트도 붙습니다. |
| 차트 만들기 | 대화 | 표의 숫자로 막대·선·누적 막대 차트를 만들어 대화 옆에 띄웁니다. 값은 자료에 있거나 코드로 계산한 것만 씁니다. |

## 그 밖의 스킬과 스킬이 가져오는 것

이 밖에 날짜 계산(**시간** 커넥터가 있으면 오늘 날짜를 거기서 읽습니다), 견적 계산, 엑셀 정리, PDF 표 → 엑셀, 근거 대조, 빠진 정보 묻기, 계산·단위 검증, 개인정보 가리기가 있습니다.

스킬은 자기 템플릿·검사·빠진 정보 질문을 함께 가져옵니다. 예를 들어 보고서 화면에서 **회의록 작성**을 켜면 템플릿이 **회의록**으로 잡히고(다른 템플릿을 골라 두었으면 그 템플릿에 씁니다), 쓰기 전에 회의 날짜·참석자를 묻고, 다 쓴 뒤 근거와 형식을 확인합니다. 켠 스킬은 그 대화가 끝날 때까지 켜져 있고, 개요를 승인할 때도 그대로 씁니다.

## 대화에서 바로 쓰기

1. 홈에서 **보고서**를 고릅니다.
2. 입력창의 **+** → **스킬** → **회의록 작성**을 고릅니다. 템플릿 칸에 **회의록**이 보입니다.
3. 회의 메모나 전사본을 붙이고 「정식 회의록으로 만들어 줘」라고 보냅니다.

챗에서 켠 스킬도 「…보고서 써 줘」처럼 문서를 부탁해 보고서·슬라이드로 넘어갈 때 함께 갑니다. 도구가 필요한 스킬은 그 화면에서 쓸 수 없어 빠지고, 빠진 스킬은 알림으로 알려 줍니다.

같은 방법으로 **개조식 보고**(「과장님께 올릴 1쪽 보고로」), **비교·결정 보고**(「세 제품을 연간 비용과 필수 조건으로 비교해서 하나 골라 줘」)를 씁니다.

## 번역·보도자료·엑셀 파일·차트

- **번역**: 대화에서 켜고 글을 붙인 뒤 「영어로, 의역, 격식체로」처럼 보냅니다. 용어를 정해 두려면 「용어: 학생지원팀 = Student Support Office」처럼 함께 적습니다. 긴 문서를 문서째 옮기려면 보고서 화면에서 켭니다. 원문의 절 제목과 순서를 그대로 따르고 요약·권고 절은 붙이지 않습니다.
- **보도자료**: 행사 결과·협약·수상 자료를 붙이고 「보도자료로, A4 1장」이라고 보냅니다. 자료에 인용할 발언이 없으면 인용 문단을 만들지 않고 답 끝에 그렇다고 알려 줍니다. 대표처럼 이름만 주고 발언이 없으면 자료의 목적·계획만 담은 그 사람의 인용문 가안을 쓰고 「(가안, 본인 확인 필요)」를 붙입니다. 보고서 화면에서 요청에 「보도자료」라고 적으면 문서 머리에 배포일·보도 시점·문의처 칸이 생깁니다.
- **엑셀 파일 만들기**: 표를 붙이거나 CSV·엑셀을 첨부하고 「엑셀 파일로, 합계 행과 증감률 열은 수식으로」라고 보냅니다. 만든 파일은 답 아래에 내려받기 단추로 붙습니다. 지저분한 표는 먼저 **엑셀 정리**를, 집계가 필요하면 **자료 추출·집계**를 함께 켜면 계산한 표를 파일로 받습니다. 코드 실행(샌드박스)이 켜져 있어야 합니다.
- **차트 만들기**: 표를 붙이고 「지점별 월 매출을 막대 차트로」라고 보내면 차트가 대화 옆에 열립니다. 엑셀 안에도 차트를 넣으려면 **엑셀 파일 만들기**를 함께 켜고 「엑셀 차트도」라고 적습니다.

## 회의 전에는 회의 안건

회의록의 짝인 **회의 안건** 템플릿이 있습니다. 보고서 화면에서 **+** → 템플릿 고르기 → **회의 안건**을 고르고(또는 요청에 「회의 안건」·「안건지」라고 적고) 다룰 안건과 담당을 보냅니다. 회의록과 같은 머리(회의명·일시·장소·참석자·작성자)에 안건 표(순서·안건·담당·시간·목표), 안건별 검토 사항, 사전 자료, 결정 필요 사항을 씁니다. 목표는 보고·논의·결정 중 하나이고, 담당이 자료에 없으면 「미정」으로 두고 확인할 것을 한 줄로 적습니다. 회의 날짜나 참석자가 자료에 없으면 쓰기 전에 묻습니다.

## 스킬로 에이전트 짜기

**사용자 지정** → **에이전트** → **추가** → **에이전트 만들기**에서 **스킬과 도구** › **스킬**의 **+ 스킬 추가 (스토어 포함)**로 스킬을 더하고 **항상 적용**으로 두면, 그 에이전트의 모든 대화에서 그 스킬이 켜집니다(여섯 개까지). 더하는 목록에는 내 스킬과 함께 스토어의 스킬도 보이고, **설치하고 추가**를 누르면 내 스킬에 사본이 생깁니다. 스킬 하나로 시작하려면 스킬 상세의 **이 스킬로 에이전트 만들기**를 누릅니다. 보고서·슬라이드에서만 작동하는 스킬을 **항상 적용**으로 두면 처음 여는 화면이 그 화면으로 정해집니다. 스킬의 템플릿·검사·빠진 정보 질문도 함께 따라오고, 에이전트에서 따로 정한 템플릿·세부 설정이 있으면 그것이 먼저입니다. **필요할 때**로 둔 스킬은 매 턴 넣지 않고 모델이 필요할 때 꺼내 씁니다. **직접 고르기**로 바꾸면 목록에 있는 스킬만 쓰고, 입력창에서도 그 스킬만 고를 수 있습니다([에이전트의 스킬](agents#에이전트의-스킬)).

## 회의록 에이전트

| 칸 | 넣을 값 |
|---|---|
| 이름 | 우리 팀 회의록 |
| 지시 | 작성자는 「기획팀 [이름]」으로 적는다. 실행 항목은 담당 팀 순서로 정렬한다. (팀 사정만 적고, 회의록 쓰는 법은 스킬이 맡습니다) |
| 항상 적용 스킬 | 회의록 작성 |
| 추가로 할 일 | 쓰기 전에 준비하기 · 다 쓴 뒤 검토하기 · 마무리하기(다 쓰면 파일로 내보내기: HWPX) |
| 템플릿·테마 › 테마 | 문서용 명조 |
| 고급 › 사용할 화면 | 보고서 |

## 개조식 보고 에이전트

항상 적용 스킬 **개조식 보고**, 테마 **문서용 명조**, 사용할 화면 **보고서**. 지시에는 보고 대상(「시설과장님」)과 결재선처럼 늘 같은 것만 적습니다.

## 구매 검토 에이전트

항상 적용 스킬 **비교·결정 보고** + **견적 계산**, 사용할 화면 **보고서**. 지시에 「판단 기준은 3년 총비용, 유지보수, 도입 일정 순서」처럼 우리 기관의 기준을 적어 두면 요청마다 쓰지 않아도 됩니다.

## 자료 집계 에이전트

항상 적용 스킬 **자료 추출·집계**, 스킬과 도구 › 도구에서 **파일 작업**, **차트 그리기**, **수치 계산**, 사용할 화면 **대화**. 엑셀을 올리고 「부서별 합계와 비율을 표로」라고 하면 기한·기간·분모 기준이 자료에 없을 때 먼저 묻습니다.

## 규정 안내 챗봇

1. 에이전트를 만들고 항상 적용 스킬 **규정 근거 답변** + **날짜 계산**을 고릅니다.
2. **자료**에 학칙·규정 파일을 올리고, **담당 부서·연락처**를 적습니다.
3. **추가로 할 일**에서 **공개 전 점검**(근거 없는 답 보류 · 담당 부서 안내 · 개인정보 가리기)을 체크합니다.
4. 시험해 본 뒤 [챗봇으로 공개](bots.md)합니다. 챗봇은 스킬 지시를 공개한 판에 함께 담아 답합니다.

## 영상·조사 에이전트

- **강의 영상 정리**: 항상 적용 스킬 **YouTube 영상 전사·요약**, 사용할 화면 **대화**. 지시에 「핵심 다섯 줄과 용어 풀이 표」처럼 원하는 모양을 적습니다. **YouTube 전사** 커넥터가 켜져 있어야 합니다.
- **동향 조사**: 항상 적용 스킬 **심층 조사** + **근거 대조**, 사용할 화면 **대화**. **심층 리서치** 커넥터가 켜져 있어야 하며, 한 번에 몇 분 걸립니다.

## 내 스킬로 같은 것 만들기

공식 스킬과 같은 것을 내 스킬로 만들 수 있습니다. **사용자 지정** → **스킬** → **추가**에서 절차를 적고, **서버가 돌리는 점검**에서 **쓸 템플릿**, **켜면 붙는 검사**, 검사 강도, **웹 검색**·**그림**, **빠진 정보 질문**을 고릅니다. SKILL.md로 올릴 때는 머리에 `template`, `checks`, `check_options`, `questions`, `process`를 적습니다.
