# KloudChat 사용자 가이드

KloudChat은 기관이 직접 운영하는 인공지능 어시스턴트입니다. 질문에 답하고, 첨부한 문서를 읽고, 보고서와 발표자료를 작성합니다. 답변을 생성하는 모델이 어디에서 동작하는지는 모델 목록의 **데이터 경계** 표시로 확인할 수 있습니다.

![홈 화면](/img/guide/home.png)

## 목적별 안내 문서

| 목적 | 사용하는 기능 | 참고 문서 |
|---|---|---|
| 질문과 답변, 코드 검토, 문장 교정 | 홈 → **챗** | [대화 기본](chat/basics.md) |
| 문서를 첨부해 내용에 근거한 답변 받기 | 입력창 📎 | [파일 첨부](chat/files.md) |
| 최신 정보를 근거로 답변 받기 | 입력창 🌐 | [웹 검색과 도구](chat/web-search.md) |
| 보고서 작성 | 홈 → **보고서** | [보고서 작성](write/report.md) |
| 발표자료 작성 | 홈 → **슬라이드** | [슬라이드 작성](write/slides.md) |
| 작성된 문서를 직접 편집하고 검토받기 | 결과물 패널의 리본 | [결과물 편집기](write/editor.md) |
| 이미지·음성·영상 생성 | 홈 → **이미지**, **오디오/동영상** | [이미지와 오디오/동영상](write/media.md) |
| 결과물을 링크로 전달 | 대화 상단 **공유** | [공유](write/share.md) |
| 자료와 지침을 묶어 반복 활용 | 사이드바 → **프로젝트** | [프로젝트](personal/projects.md) |
| 역할이 정해진 도우미에게 위임 | 홈 **에이전트에게 맡기기**, 입력창 @ | [에이전트와 스킬](chat/agents.md) |
| 반복 업무를 정해진 양식으로 시작 | 입력창 ▦ **작업 시작하기** | [시작점·서식·디자인](chat/starters.md) |
| 반복해서 알려야 할 정보를 기억시키기 | 계정 메뉴 → **메모리** | [메모리](personal/memory.md) |
| 외부 도구·코드에서 모델 호출 | 계정 메뉴 → **API 연동** | [API와 코딩 도구 연동](api.md) |
| 사용량 확인과 대화 정리 | 계정 메뉴 → **사용량**, **대화 기록** | [사용량과 대화 기록](personal/usage-history.md) |

## 읽는 순서

처음 사용한다면 [가입과 로그인](start/signup.md), [홈 화면 구성](start/home.md), [대화 기본](chat/basics.md) 순서로 읽으십시오. 문제가 생기면 [제한 사항과 문제 해결](limits.md)에서 화면에 나타난 문구로 원인을 찾을 수 있습니다. 처음 보는 용어는 [용어](glossary.md)에 정리해 두었습니다.

:::info 설치 환경에 따라 달라지는 항목
본 가이드는 제품의 전체 기능을 다룹니다. 다음 항목은 기관의 설정에 따라 달라지므로, 실제 화면과 다르면 관리자에게 확인하십시오.

- **사용할 수 있는 화면**: 챗은 항상 제공되며 보고서, 슬라이드, 이미지, 오디오/동영상은 관리자가 활성화한 경우에만 표시됩니다.
- **모델 목록과 과금**: 운영하는 모델의 종류, 이름, 데이터 경계, 크레딧 단가는 기관마다 다릅니다.
- **가입 방식과 이메일 도메인**: 승인 절차와 허용 도메인은 관리자가 지정합니다.
- **연동 기능**: 웹 검색, 코드 실행, 말로 쓰기, 자료 검색은 관리자가 서버를 연결한 경우에만 동작합니다.
- **서비스 이름과 로고**: 관리자가 변경할 수 있으므로 화면에 표시되는 명칭이 이 가이드와 다를 수 있습니다.
:::
