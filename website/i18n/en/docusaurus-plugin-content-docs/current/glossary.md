# Glossary

| Term | Meaning |
|---|---|
| Screen (Chat · Report · Slides · Image · Audio/Video) | The screen you choose on the home page. Administrators turn each one on and off |
| Conversation (대화) | The record of one piece of work. One row in the sidebar |
| Artifact (결과물) | A result produced in a conversation. The right-hand panel and the gallery |
| Template (템플릿) | The structure and shape of the result (built in; formerly 양식). It stays for the whole conversation |
| Theme (테마) | A bundle of colors, typefaces, and tone (formerly 디자인). Attached to an agent or a project, kept in Settings › Themes |
| Project (프로젝트) | A workspace that groups material, instructions, and conversations |
| Agent (에이전트) | A helper with set instructions, process, tools, and material. Start one from **+** → **Agents** in the composer |
| How it works (진행 과정) | The order an agent works in: Answer directly · Start from a base process · Set it up yourself (advanced) |
| Base process (기본 과정) | The order a built-in agent (Summary, Records, …) works in. Your own agent can follow it as it is |
| Bundle (묶음) | A group of things an agent does before and after writing. Ticked under Extra work in the agent settings |
| Skill (스킬) | A way of working that you turn on for this request only. Up to 3 |
| Connector (커넥터) | An external tool the model uses (MCP). Turned on and off for the whole account |
| Memory (메모리) | A fact remembered beyond one conversation. Settings › Memory |
| strict-local | A mark on a model confirmed not to send anything outside |
| Auto | A conversation mode that changes the model to suit the request (quality first or cost saving) |
| Credit (크레딧) | The unit of usage. Free models do not use it |
| Processing steps (작업 단계) | The "Done · N steps" line above an answer. It shows the items used |
| Turn (턴) | One question and its answer. Shown on the screen in forms such as "Attachment from an earlier turn" |
| Image · picture · diagram | An image file you attach or generate · a picture you place in a document (UI label) · a flow chart or structure chart a text model draws |
| Outline card (개요 카드) | The card that confirms the structure before a report or slide deck is written |
| Masking (마스킹) | Replacing personal data with a placeholder before sending |
