# KloudChat User Guide

KloudChat is an AI assistant that your organisation runs itself. It answers questions, reads the documents you attach, and writes reports and slide decks. To see where the model that generates an answer runs, check the **data boundary** label in the model list.

![Home screen](/img/guide/home.png)

## Reading order

If you are new to the product, read [Signing up and signing in](start/signup.md), [Home screen layout](start/home.md) and [Conversation basics](chat/basics.md) in that order. If something goes wrong, [Limits and troubleshooting](limits.md) helps you trace the cause from the message shown on screen. Terms you have not seen before are collected in [Glossary](glossary.md).

:::info Items that depend on your installation
This guide covers the full feature set of the product. The following items depend on your organisation's settings, so check with your administrator if the screen differs from this guide.

- **Available screens**: Chat is always provided. Report, Slides, Image and Audio/Video appear only when the administrator enables them.
- **Model list and charging**: The models on offer, their names, data boundaries and credit rates differ between organisations.
- **Sign-up method and email domains**: The administrator sets the approval procedure and the permitted domains.
- **Integrated features**: Web search, code execution, dictation and file search work only when the administrator has connected a server.
- **Service name and logo**: The administrator can change these, so the names on screen may differ from this guide.
:::
