# Knowledge shelf

The knowledge shelf is for asking about, summarising and studying a project's sources. Pick sources and get answers from those sources only; click an answer's source number to open the passage it came from. From the same sources you can make a study guide, FAQ, quiz or flashcards in one click.

Project sources are treated as internal material. Under your administrator's rule, internal material is read only by models running inside your organisation (strict-local), and the screens show a **strict-local** mark when that applies.

## Sources

Files, web material, pasted text, notes made into sources, and videos or recordings in the project's **Knowledge** tab are all sources. The **Text** button adds copied text as a source directly.

In a conversation inside a project, the **Sources** button at the top opens the sources panel.

- A check box per source turns it on or off for this conversation's questions. All start on; the choice is kept per conversation. A source added later starts on.
- **Select all**, **Select none**, a search box and the number of sources in use are provided. With all off, the next question is answered without sources.
- A source that is off is used neither as context nor by the source search tool.

## Source guide

Click a source's name, or **Source guide** in the Knowledge tab, for its summary, key topics and suggested questions. A strict-local model writes it the first time it is opened, and it stays until the source changes. A suggested question goes into the input box; it is not sent.

**Whole-project source guide** in the Knowledge tab summarises all sources together and suggests questions that draw on more than one.

## From a citation to the source

An answer grounded in project sources ends its statements with numbers such as **[1]** and lists the source names under the answer. A number is taken out when the sentence citing it is not in that source. Clicking a number opens the source viewer.

| Source | Source viewer |
|---|---|
| Documents, text, web material | Highlights the passage closest to the cited sentence. |
| PDF | Opens that page beside the passage. On a phone, switch with **Show the PDF page**. |
| Video, recordings | Shows that part of the transcript and its time; **Play from …** starts there. |

When no passage matches the cited sentence exactly, the closest one is shown, with a note saying so.

## Studio

In the project's **Studio** tab, pick the sources to use, then what to make.

| Output | Contents |
|---|---|
| Study guide | Overview, key concepts, review questions with answers |
| FAQ | Questions the sources answer, with the answers |
| Briefing doc | Summary, key points, evidence and figures, implications, open questions |
| Timeline | Dated events from the sources in order (dates as the sources write them) |
| Glossary | Terms the sources use and what they mean |
| Mind map | The structure of the subject on one diagram |
| Quiz, flashcards | See “Learning tools” below |

Before anything is made you see how many sources are read, the model, the tokens read and written, and the expected credits. Models running inside cost no credits. Sources too long to read whole are read in parts spread across them, and you are told which. You can choose the format (web report, Hangul, Word), the language and a focus (e.g. “focus on lectures 5–8”).

Documents cite a source number for each statement; numbers not in the source list are removed. Afterwards every sentence, question and card is checked: are its content and figures in the sources it cites, and is it free of foreign script, misspelt terms and garbled wording? What fails is rewritten once, and left out if the sources still do not back it. Suggested questions in source guides are kept only when the sources answer them. A document is saved as an artifact in a conversation of its own, so **Open as a document** edits and exports it in the editor. Reading it in the studio, a source number opens the source too. **Make again** makes it anew with the same sources and settings.

## Learning tools

- **Quiz**: multiple-choice and short-answer questions with explanations and sources. Answer one at a time, see your score, and use **Only the wrong ones again** and **Shuffle**. Short answers are compared ignoring spaces and punctuation; an answer written differently but right can be marked with **Count it as correct**.
- **Flashcards**: front-and-back cards. Click a card or press Space to flip it, and review **Only the cards not known yet**.
- **Export**: CSV (Excel), text for Anki import, and for quizzes a Hangul, Word or web-report quiz sheet (questions, then answers and explanations).

## Notes

The project's **Notes** tab collects notes.

- Save a whole answer with the note button under it, or a passage you select in an answer with **Save to Notes**. **New note** writes one by hand.
- Changes made in **Edit** are kept only when you press **Save** (Ctrl+S). Closing with unsaved changes asks Save, Discard or Cancel. If the note was saved elsewhere first, you can download your edit and load the latest version.
- **Make it a source** turns a note into a source that is searched and cited like a file. Later edits of the note update that source.
