# Frequently asked questions

This page lists causes and actions by symptom. To look something up by the error message shown on the screen, see [Limits and troubleshooting](limits).

### I signed up but I cannot sign in
Your account is waiting for approval. The waiting screen switches over automatically once an administrator approves it. Use **Contact the administrator** on the waiting screen to get in touch.

### I typed in Chat but it switched to the report screen
A sentence that asks for a document, such as "Write a report" or "Make a slide deck", switches automatically to a new conversation on that screen. The document is written with that screen's default model; when it differs from the model picked in Chat, a note above the input box says so. Short pieces such as a press release, notice or email stay in Chat and are written there (to get one as a report, ask on the report screen). To continue in Chat, phrase the request around existing content, such as "Summarize this".

### It says the file I attached could not be read
The file is an older Office format (.doc, .ppt, .xls), or a scan while text from scans (OCR) is not connected. Attach it again as a PDF, Word, Hangul, Excel, or text file that contains text, or ask the administrator to connect text from scans. [Attaching files](chat/files)

### My next question does not refer to the file I attached
The attachment stays available throughout the same Chat conversation. Check whether the processing steps of the answer show "Attachment from an earlier turn". Other conversations and the report and slide screens do not carry earlier attachments over. If the file is long, only the parts related to your question are passed, so describe what you are looking for in detail.

### The answer does not match the facts
The model may have generated something it does not know. Set web search to **Always** or attach source material. If the answer shows no sources, it did not go through search. [Model limitations](limits#model-limitations)

### The answer is too short
The product is designed to leave out introductions and repeated explanations. Add conditions to your request, such as "in detail" or "with examples", or describe the length you want under **Answer style** in the settings.

### My report table shows (TBD)
A report leaves a figure blank rather than generating one that is not in the material. Attach source material and ask again, or type the value directly in the editor.

### I asked for more slides but nothing changed
If you ask "Please make it 20 slides", the product proposes the structure again and writes it after you approve. If that does not take effect, ask again from scratch, such as "Create it again with 20 slides".

### A different model appears when I sign in from another device
The model you choose on the home page is saved to your account and applies the same way on every device. A model you choose during a conversation applies only to that conversation. Check the default model per screen under Settings → Preferences.

### I turned web search off but it comes back in a new conversation
The search mode applies per request, so it resets to **Auto** in a new conversation. Only whether a connector is turned on is kept for the whole account.

### The person I sent a share link to cannot open it
A link created for **People with an account** can only be opened after signing in. To send it to an external user, create it again as **Anyone with the link**. A link you have revoked, or one whose conversation you deleted, does not open.

### Generation takes a long time
Reports are written section by section and slide decks slide by slide, in order. Generation continues on the server even if you close the browser, so you can come back later and check the result.

### What is a credit
It is the unit that represents model usage. A model marked **Free** does not consume credits. [Usage and conversation history](personal/usage-history#credits)

### Can administrators see my conversations
There is no administrator screen that shows conversation content. Administrators see a conversation in three cases: a copy you sent with [Feedback and issues](personal/issues) after ticking **Share this session with the administrators**, a link or external chatbot's conversations opened with a stated reason to check abuse (recorded in the audit log), and a share link. Otherwise they see only usage and sign-in history.
