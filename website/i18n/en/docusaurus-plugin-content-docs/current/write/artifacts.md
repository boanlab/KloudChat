# Artifacts

What a conversation generates is called an artifact. The **Artifacts** screen in the sidebar holds what you view or run directly: HTML pages, code files, charts and diagrams. Reports and slide decks (web, HWP, Word, PowerPoint) are under **Working documents** in [Files](../chat/files#files), and generated images, audio and video under **Generated**. A short code block inside an answer is part of the conversation and is not saved as an artifact of its own; copy and run it in the chat.

![Artifact gallery](/img/guide/artifacts.png)

## Artifact panel

- The panel opens automatically when an artifact is generated. If you closed it, reopen it with a button such as **Open the report** or **Open the deck** at the top right of the conversation screen.
- Every panel shows the version and the edit time, and lets you copy, download, adjust the width (double-click to reset), switch between narrow, wide, and document-only views, and close the panel. If the screen is narrow, the panel is shown over the conversation.
- Code and web pages support the **Preview** and **Source** tabs and zooming in and out. A web page runs in an isolated frame, so features that save values do not work.
- In Chat too, a request such as "organize this into a table and turn it into a document" or "draw a chart from this data" generates an artifact in the panel.

## Editors by format

Web reports and web slides open in the [artifact editor](editor) (the ribbon). HWP, Word and PowerPoint artifacts open in their own editors: the HWP editor, the Word editor with its ribbon, and the PowerPoint editor. See [HWP documents](hwp), [Word documents](docx) and [PowerPoint documents](pptx).

## Export formats

| Type | Formats |
|---|---|
| Web report | PDF, Word (DOCX), Hangul (HWPX), the Markdown source, print |
| Web slides | PowerPoint (PPTX), PDF, text (with notes) |
| HWP, Word and PowerPoint documents | **Download** in the editor (HWPX or HWP, DOCX, PPTX) |

PDF reproduces the chosen look as it is, and DOCX and PPTX put an editable structure first, so some visual elements on screen may differ. A Word or PowerPoint file written on a company form keeps the form's look.

## Gallery

See the full list under **Artifacts** in the sidebar. The tabs are **All**, **HTML**, **Code files**, **Charts** and **Diagrams**, each with its count. Search by title, and click a column heading (**Title**, **Kind**, **Versions**, **Last edited**) to sort by it; click it again to reverse the order. On a phone, use the sort field and the arrow button above the list. Click a title to open it as a panel on this screen; **Back to the chat** goes to the conversation that made it. Deleting removes the version history as well, but the conversation is kept. An older artifact link to a report or deck opens its editor or Working documents, and one to an image, audio or video opens that file in Files.
