# Images and audio/video

The **Image** and **Audio/Video** tabs appear on the home screen only when the administrator has enabled them. Most of them use external generation services, so they consume credits, and the estimated credits are shown before you send. Attaching files is not supported.

## Images

Set them with the options below the composer.

| Chip | Choices |
|---|---|
| Ratio | 16:9 · 9:16 · 4:3 · 1:1 (only the ones the model supports) |
| Style | Auto · diagram · infographic · chart · photo · illustration · minimal · 3D render · watercolour · none |
| Text | Auto · Korean · English · none |
| Count | 1 · 2 · 4 |

The result card provides enlarged view, download, **Generate again**, **Fix the prompt**, and **View the prompt sent** (the final sentence that was actually sent). The diagram type is generated by the text model, and you can use **View the drawing code** and **Redraw with this code**. If you choose a model that does not support ratio settings, a message tells you that the image is generated as a square.

The 14 **image formats** (diagram, cover, poster, and so on) build the request and the options once you enter the items. The colours and the image style of the project design system are applied to the request as well.

## Audio

Generates narration (with a voice choice) or music at 15, 30, 60, or 120 seconds. The result comes with a player and a download, and narration also shows the script. Audio is charged per generation.

## Video

Set the ratio, the resolution (720p or 1080p), whether there is sound, and the length (4 to 10 seconds). Video generation takes a long time, so the card shows the progress, and you can still see the finished result after refreshing the screen or connecting from another device. You can cancel a generation, and credits are deducted only when it completes. If you choose a combination that the model does not price, a message saying "This model does not produce this combination" appears and sending is blocked. The design system does not apply to audio and video.
