요약

현재 문서 검색은 파일명 일치에만 의존한다. 본문을 읽지 못하므로 담당자가 아는 문서만 찾히고, 인수인계 시점마다 같은 자료를 다시 만든다. 이 검토는 세 가지 후보를 같은 기준으로 비교한다.

  • 도입 비용과 운영 부담
  • 사내망 밖으로 나가는 데이터의 범위
  • 기존 결재 시스템과의 연동 가능성
