컴퓨터공학과 운영체제 실습 · 수요일 3교시 · 실습 과제 2 전에 다루는 마지막 개념

1

페이지 폴트는 언제 생기나

  • 참조한 페이지가 메모리에 없을 때
  • 프레임이 차 있으면 하나를 내보낸다
  • 무엇을 버릴지 정하는 규칙이 교체다
2

FIFO는 오래된 것을, LRU는 안 쓰인 것을 버린다

둘은 같은 질문에 다르게 답한다. 들어온 순서만 보는가, 최근에 쓴 기록으로 다음에 쓸 것을 추측하는가.

프레임 3개, 참조열 7 0 1 2 0 3 0 4

  1. 7 0 1 로 프레임을 채운다
  2. FIFO 는 0 을 버리고 다시 읽는다
  3. LRU 는 0 을 남겨 폴트가 준다
3

두 규칙이 보는 것

구현 비용큐 하나참조마다 갱신
수업에서는 참조열 하나로 비교했다. 실제 성능은 참조열의 성격에 따라 뒤집힌다. 4
