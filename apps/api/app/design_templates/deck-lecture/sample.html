2

왜 데이터를 모을 수 없나

학습할 데이터가 여러 곳에 흩어져 있고, 밖으로 내보낼 수 없을 때가 많다.

세 병원이 폐렴 판독 모델을 함께 만들고 싶다.

  • 환자 영상은 병원 밖으로 나갈 수 없다
  • 한 병원 자료만으로는 사례가 모자란다
3

한 바퀴가 도는 방식

  1. 서버가 현재 모델을 보낸다
  2. 각 병원이 자기 데이터로 학습한다
  3. 바뀐 가중치만 서버로 보낸다
  4. 서버가 평균을 내 새 모델을 만든다
4

평균을 내는 법

FedAvg는 데이터가 많은 곳의 갱신에 더 큰 무게를 준다.

  • 병원 A 6,000장 · B 3,000장 · C 1,000장
  • 무게는 0.6 · 0.3 · 0.1 (합계 10,000장)
  • 새 가중치 = 0.6·A + 0.3·B + 0.1·C
5
