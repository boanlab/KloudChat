7주차 · 페이지 교체 알고리즘

컴퓨터공학과 운영체제 · 수요일 3교시 · 실습 과제 2 전에 다루는 마지막 개념

1

페이지 폴트는 언제 생기나

  • 참조한 페이지가 물리 메모리에 없을 때
  • 프레임이 다 차 있으면 하나를 내보내야 한다
  • 무엇을 내보낼지 고르는 규칙이 교체 알고리즘이다
2

FIFO는 오래된 것을, LRU는 안 쓰인 것을 버린다

둘은 같은 질문에 다르게 답한다. 들어온 순서만 보는가, 최근에 쓴 기록으로 다음에 쓸 것을 추측하는가.

프레임 3개, 참조열 7 0 1 2 0 3 0 4

  • FIFO — 먼저 들어왔다는 이유로 0 을 내보내고 바로 다음에 다시 읽는다
  • LRU — 방금 쓴 0 을 남겨 두어 폴트가 한 번 줄어든다
