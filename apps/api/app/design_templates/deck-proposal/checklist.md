- 첫 장을 보고 무엇을 제안하는지, 누구에게 내는 자료인지 알 수 있는가.
- 문제가 먼저 서 있는가. 해결책부터 나오는 제안은 심사자가 왜 필요한지 모른 채 듣는다.
- 제안 쪽만이 아니라 현행 쪽도 사실대로 적혀 있는가.
- 근거로 세운 값마다 무엇을 세었는지, 언제 것인지 말할 수 있는가.
- 반대할 사람이 물을 것 — 비용, 인원, 되돌릴 수 있는지 — 이 자료 안에 답이 있는가.
- 마지막 장이 요청인가. 누가, 무엇을, 언제까지 정해야 하는지 세 가지가 다 있는가.
- 승인이든 반려든 이 자료만으로 결정할 수 있는가. 더 물어야 끝나면 아직 모자란다.
