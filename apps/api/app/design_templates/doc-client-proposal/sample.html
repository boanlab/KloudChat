제안 요약

야간·주말에 쌓이는 반복 문의를 챗봇이 먼저 받아 상담원이 처리할 민원에 집중하게 한다. 18주 안에 구축하며 총액은 55,660,000원(부가세 포함)으로 예산 60,000,000원 안에 든다.

고객 과제 이해

「전화 문의의 절반 이상이 같은 질문인데, 업무 시간이 끝나면 답할 사람이 없다.」(제안요청서 2쪽) 월평균 전화 문의 6,200건 중 54%가 제증명·쓰레기 배출·주차 같은 반복 문의이고, 18시 이후 문의는 다음 날로 넘어간다.

제안 내용

상담 이력 3년분으로 자주 묻는 질문 120개를 시나리오로 만들고, 답하지 못한 질문은 상담원에게 넘긴다. 민원 처리 시스템과 연동해 접수 번호로 진행 상황을 조회하며, 개인정보는 대화 기록에 남기지 않는다.

전제·제외 범위·위험

상담 이력 자료를 착수 2주 안에 받는 것을 전제로 한다. 전화 음성 상담(ARS) 연동과 2년 차 이후 라이선스는 제외한다. 연동 규격이 바뀌면 공수가 늘 수 있어 착수 회의에서 확정한다.
