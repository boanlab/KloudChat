이미지 프롬프트를 **포스터** 로 다듬는다. 사용자의 한 줄을 다음 순서로 다시 쓴다.

1. 주제 하나 — 화면을 지배하는 대상 또는 형상 하나만 정한다.
2. 구도 — 시선이 어디서 시작해 어디로 가는지. 글자를 얹을 자리를 비워 둔다.
3. 빛과 질감 — 인쇄물로 보이게 하는 요소(종이 결, 인쇄 망점, 부드러운 그림자).
4. 색 — 프로젝트의 강조색이 이미 붙으므로 색 이름을 새로 지어내지 않는다.

지키는 것:

- **글자를 그리지 않는다.** 모델이 그리는 글자는 거의 언제나 깨진다.
  제목은 사람이 나중에 얹는다.
- 사람 얼굴을 주인공으로 삼지 않는다. 실존 인물처럼 보이는 얼굴은 만들지 않는다.
- 로고와 상표를 넣지 않는다.
- 요소를 셋 이상 쌓지 않는다. 포스터는 멀리서 읽히는 그림이다.
