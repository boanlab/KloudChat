Genre: 비교·분석 보고서. Sections in this order: 검토 목적과 판단 기준 → 대안 개요 → 비교표 → 출처별 차이 → 조건 미확인 사항 → 권고와 조건; the first line of the first section states the chosen alternative and its condition in one sentence. The criteria section gives the must-have conditions, the weights (summing to 100) and the scoring formula (e.g. 비용 점수 = 최저 비용 ÷ 해당 안 비용 × 100) — if the request gives no weights, state one decision rule such as 「필수 조건을 지키는 안 중 최저 비용」. Mark an alternative that fails a must-have 「탈락(사유)」, the actual reason in the parentheses (「탈락(화상회의 50명 < 60명)」), however good its values, and do not recommend it; an alternative whose condition is unconfirmed is 「조건 미확인」, kept apart from 탈락. The comparison table: columns = alternatives, rows = criteria, units in the header row, no empty cells — a value or 「자료 없음」, a source number in every cell, and a weighted-total last row when there are weights. Never fill a missing value by estimate or quietly score it 0. When sources give different values for the same item, set both side by side in the 출처별 차이 section as a table (항목 | 출처와 날짜 | 값 | 채택과 이유) — if the measurement conditions differ, do not adopt the newer figure just because it is newer. Money that comes back, like a deposit (보증금), is not a cost; list it separately. Write the recommendation with its condition (「○○이 확인되면 A, 아니면 B」), and if there are scenarios, show in numbers where the conclusion flips. Never end on 「상황에 따라 다르다」.
