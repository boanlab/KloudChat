Genre: 비교·분석 보고서. Sections in this order: 검토 목적과 판단 기준 → 대안 개요 → 비교표 → 출처별 차이 (only when sources disagree) → 조건 미확인 사항 (only when something is unconfirmed) → 권고와 조건; the first line of the first section states the chosen alternative and its condition in one sentence. The criteria are exactly the ones the request names, in its order and words — add none. Mandatory conditions only when the request or material states something as required; otherwise write none and eliminate nothing. Weights, points and a scoring formula (e.g. 비용 점수 = 최저 비용 ÷ 해당 안 비용 × 100) only when the request gives weights; without weights never invent weights, scores or pass marks — state the decision rule the request implies (「필수 조건을 지키는 안 중 최저 비용」 or 「기준별로 견주어 판단」) and compare criterion by criterion in words and the material's numbers. Mark an alternative that fails a stated must-have 「탈락(사유)」, the actual reason in the parentheses (「탈락(화상회의 50명 < 60명)」), however good its values, and do not recommend it; an alternative whose condition is unconfirmed is 「조건 미확인」, kept apart from 탈락 — but settle every condition a calculation can settle first (× 1.1 only for a price the material marks 「부가세 별도」 — no VAT words in the material, no VAT note; a discount on the amount it names, extra items added, one total per alternative against the budget; a lead time as a date against the deadline), so only facts no calculation settles stay unconfirmed. The comparison table: columns = alternatives, rows = criteria, units in the header row, no empty cells — a value or 「자료 없음」, and a weighted-total last row only when there are weights. Cost over time: the first year includes one-time costs, later years do not — show 첫해 and 이듬해부터(연) and the difference; a discount applies only to the price it names. Never fill a missing value by estimate or quietly score it 0. When sources give different values for the same item, set both side by side in the 출처별 차이 section as a table (항목 | 출처와 날짜 | 값 | 채택과 이유) — if the measurement conditions differ, do not adopt the newer figure just because it is newer. Money that comes back, like a deposit (보증금), is not a cost; list it separately. No outside laws, cases or references the person did not give. Always recommend one alternative, with its condition when one is open (「추천: A, 단 ○○ 확인 — 확인되지 않으면 B」), and if there are scenarios, show in numbers where the conclusion flips. Never end on 「상황에 따라 다르다」.
