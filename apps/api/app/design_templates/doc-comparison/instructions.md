Build this document with the **비교·분석 보고서** format. It compares 2–5 alternatives on the
same criteria and recommends one, with conditions. The layout adds the head
(검토 대상·판단 기준·작성일·작성자) and the section numbers.

- Order the sections 검토 목적과 판단 기준 → 대안 개요 → 비교표 → 출처별 차이 → 조건 미확인 사항 →
  권고와 조건. Leave out 출처별 차이 when no two sources disagree, and 조건 미확인 사항 when
  nothing is unconfirmed.
- Put the chosen alternative and its condition in one sentence on the first line of the
  first section; on the second line, what it costs against the next alternative (first-year and
  later-year difference) when cost is a criterion.

## 판단 기준 — only the person's

- The criteria are the ones the request names, in the order and with the names it uses. Do
  not add criteria, and do not turn a criterion into a mandatory condition.
- Mandatory conditions are only the ones the request or the material states as required
  (「필수」「반드시」「~이상이어야」). None stated: write no mandatory conditions and no 탈락.
- Weights and a score only when the request gives weights. Then state them (summing to 100)
  and the scoring formula (e.g. 비용 점수 = 최저 비용 ÷ 해당 안 비용 × 100). Without weights,
  never invent weights, points, ranks or pass marks: state the one decision rule the request
  implies (「필수 조건을 지키는 안 중 최저 비용」, or 「기준별로 견주어 판단」) and compare
  criterion by criterion in words and the material's numbers.
- Mark an alternative that fails a stated mandatory condition as 「탈락(사유)」, with the actual
  reason in the parentheses (「탈락(화상회의 50명 < 60명)」), even if its values are good, and do
  not recommend it. Keep an alternative whose condition is not confirmed as 「조건 미확인」,
  distinct from elimination.
- Settle every condition you can by calculation before calling it unconfirmed: a price
  부가세 별도 × 1.1, a discount on the amount it names, extra items (보증 연장, 수거, 설치)
  added, so each alternative has one 「부가세 포함 총액」 set against the budget; a lead time
  turned into a date set against the deadline. Only what no calculation settles (a service the
  quote does not mention) is 「조건 미확인」.

## 비교표

- Columns = alternatives, rows = criteria. Put units in the header row.
- No empty cells: a value or 「자료 없음」. A source number in every cell when sources are
  numbered. With weights, a weighted total in the last row.
- Cost over time: the first year includes one-time costs (전환·설치·컨설팅), later years do
  not; show both rows (첫해 / 이듬해부터(연)) and the difference between alternatives. A
  discount applies only to the price it names. Totals come from the 확정 수치 block; when the
  block gives none, write each cost in its cell as one formula of the material's own numbers
  with its result (「14,000원 × 40명 × 12개월 × 0.85 = 5,712,000원」) instead of a blank.
- Do not estimate values missing from the material, or quietly score them 0.
- Money that is returned, such as a deposit, is not a cost; list it separately.

## 출처와 권고

- When sources give different values for the same item, put both side by side in the
  출처별 차이 section as a table (항목 | 출처와 날짜 | 값 | 채택과 이유). If measurement
  conditions differ, do not adopt even the newest source outright.
- List the unconfirmed conditions together with what, once confirmed, settles the conclusion.
- Always recommend one alternative. When it has an unconfirmed condition, write 「추천: A, 단
  ○○ 확인」 (and what changes if it fails: 「확인되지 않으면 B」). If there are scenarios, show
  in numbers where the conclusion changes. Do not end with 「상황에 따라 다르다」.
- Use only the material: no outside laws, market figures, vendor cases or references the
  person did not give.
- Wrap anything whose meaning survives only when copied character for character — product setting names, identifiers — in `<code>`.

## 모양 — 가중치 없이 기준만 준 요청의 예 (다른 요청; 형식만 따르고 내용은 쓰지 않는다)

검토 목적과 판단 기준
- 결론: 복합기 임차(B안) — 고장 수리가 임차료에 포함되어 지난해 수리 대기 9일이 사라짐.
- 비용: 첫해 B안이 1,100,000원 덜 들고, 이듬해부터는 연 900,000원 더 듦.
