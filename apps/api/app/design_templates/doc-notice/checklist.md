- 수신·시행일·담당이 문서 머리에 다 있는가. 받는 사람이 자기가 대상인지 첫 줄에서 알 수 있는가.
- 첫 절을 읽고 무엇이 언제부터 달라지는지 알 수 있는가.
- 이 안내가 무엇에 근거한 것인지 밝혔는가.
- 절이 근거 → 내용 → 협조 요청 → 붙임 순서로 놓여 있는가.
- 받는 사람이 할 일에 기한과 제출처가 함께 적혀 있는가. 할 일이 없다면 없다고 말하는가.
- 날짜·시간·장소·대상이 본문과 목록에서 서로 어긋나지 않는가.
- 되물을 곳이 있는가. 담당과 연락 수단이 문서 안에 있는가.
- 아직 정해지지 않은 것을 정해진 것처럼 쓰지 않았는가.
- 붙임에 적은 자료가 본문에서 실제로 쓰이는 자료인가. 마지막에 "끝." 으로 닫혔는가.
- 인사말이나 수식 없이, 흑백으로 복사해도 그대로 읽히는 문서인가.
