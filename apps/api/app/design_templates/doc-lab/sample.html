목적

1차 RC 저역통과 필터의 차단 주파수(출력이 입력의 1/√2가 되는 주파수)를 재고, 소자값으로 계산한 이론값과 견준다.

장비·설정값·반복 횟수

  • 함수 발생기 정현파 1.0 Vpp, 100 Hz~10 kHz를 50 Hz 간격으로 훑음
  • 오실로스코프 2채널, 입력·출력 동시 측정
  • R = 1.0 kΩ(±1%), C = 0.10 µF(±5%), 같은 소자로 3회 반복

절차

  1. 브레드보드에 R과 C를 직렬로 꽂고 C 양단을 출력으로 잡는다.
  2. 주파수를 바꿀 때마다 입력과 출력의 진폭을 기록한다.
  3. 출력/입력이 0.707에 가장 가까운 두 점 사이를 선형 보간해 f_c를 구한다.

표 1. 같은 소자로 3회 측정한 차단 주파수. 편차 = (측정 − 이론) ÷ 이론 × 100.

계산

f_c = 1 / (2π · R · C)

= 1 / (2π · 1.0×10^3 Ω · 0.10×10^-6 F)

≈ 1591.5 Hz

해석

세 번 모두 측정값이 이론값보다 1~3% 낮았다. 커패시터 허용 오차(±5%)가 C를 약 1.9% 크게 만들었다면 이 차이가 모두 설명된다. 실제 C 값은 재지 않았으므로 이 설명은 확인되지 않았다.

한계

  • 50 Hz 간격으로 훑어 보간 오차가 최대 약 ±25 Hz 남는다.
  • 소자 한 벌만 써서, 소자 간 편차는 이 결과로 말할 수 없다.
